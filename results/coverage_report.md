# まだ探していない組はどこにあるか

2026-11-10。再現は `python coverage.py`。一覧は `results/coverage.csv`（型ごと）と
`results/coverage_roi.csv`（領域ごと）。

## 0. 結論

**未探索の宝庫は「まだ見ていない領域」ではない。領域はすべて 1 度は見ている。
取りこぼしているのは次の 3 つ。**

| 宝庫 | 規模 | 実験に使えるか |
|---|---|---|
| **① しきい値で落とした細胞** | hemibrain の型の **35%**（1,985 型） | ✕ ほぼ使えない。ドライバーがあるのは 82 型だけ |
| **② 領域をまたぐ組** | ドライバーつきの型の組の **93%** が未評価 | ◎ **ここが本命** |
| **③ 別のデータセット** | MANC（腹髄）は手つかず | ○ 下行ニューロンの先 |

**いちばん効くのは ②。** これまでの探索は領域ごとにデータを取ったので、
**別々の領域データに入った 2 つの型は、たとえ接していても 1 度も比較されていない。**

### なぜ取りこぼしたか — しきい値

**領域はすべて 1 度は取りに行っている。** 落ちたのは取得時のしきい値のせい。

| 領域の取得 | その領域でのシナプス数の下限 | 1 型あたりの細胞数 |
|---|---|---|
| smp（SMP・SIP・SLP） | **800** | 2 |
| vlp（AVLP・PLP） | **700** | 2 |
| cre（CRE・ATL・IB・SCL・ICL） | **700** | 2 |
| ps（SPS・IPS・EPA・GNG） | 400 | 2 |
| wed（WED・SAD・CAN） | 400 | 2 |
| lal（LAL・VES・GOR） | 300 | 3 |
| lh / al / vis | 200 | 3 |
| cx（EB・FB・PB・NO） | 100 | 5 |

SLP の未探索率が 60% と高いのは、**SMP・SIP・SLP をまとめて「800 シナプス以上」で
切ったから**。SLP は小さな細胞が多いので、ここで大量に落ちている。

## 2. ただし、未探索の型はほとんど実験に使えない

**ここが肝心。** 未探索 1,985 型のうち、

|---|---|
| ドライバーが 1 本でもある | **82** |
| 特異性 1 以上のドライバーがある | **69** |

**未探索の型に LexA は 1 つも無い。** つまり「しきい値を下げて拾い直す」だけでは、
発現系が 2 つそろう組はほとんど増えない。

しかもここは MBON04 の候補が出た領域でもある。やるならここ。

## 3. 本命は「領域をまたぐ組」

特異性 1 以上のドライバーがある型は **362**（hemibrain にあるのは **323**）。
この 323 型だけで考えうる向きつきの組は **104,006**。
そのうち、これまでの探索で 1 度でも評価された組は **7,609（7.3%）** しかない。

```
ドライバーつきの型どうしの組    104,006
  これまでに評価した組            7,609  （7.3%）
  未評価                         96,397  （92.7%）
```

**なぜこうなるか**: 探索を領域ごとに行ったので、
「SMP のデータ」に入った型と「LAL のデータ」に入った型は、
**実際には接していても 1 度も比較されていない**。
MBON04 → FB4N が見つかったのは、たまたま両方が SMP のデータに入っていたから。

### どうするか

**領域で区切るのをやめ、ドライバーがある 323 型だけを 1 つのデータセットにして、
全組を一度に評価する。**

- 細胞数は数千のオーダー（KC など細胞数の多い型を除けばさらに減る）。
  これまでの領域データ（1 つ 200〜800 MB）より小さく収まる見込み。
- 接触の計算はペア数に効くが、近接判定は KD-tree なので
  「接する可能性のある組」だけに絞られる。
- **この 1 回で、ドライバーがある型どうしの組を網羅できる。**

```
python fetch_data.py neuprint --types <323 型> --dataset hemibrain:v1.2.1 \
    --out data/hemibrain_drivers.pkl --max-per-type 4
./run_screen.sh drivers
```

型の一覧は `results/coverage.csv` の `good_driver` 列が True の行。

## 4. 別のデータセット

| データセット | 中身 | Traced な型 | 細胞 | 状況 |
|---|---|---|---|---|
| hemibrain:v1.2.1 | 雌・右半球 | 5,620 | 22,656 | 探索の母体として使用 |
| **male-cns:v1.0** | 雄・全中枢神経系（脳＋視葉＋腹髄） | **11,751** | **162,517** | **照合にしか使っていない** |
| **manc:v1.2.3** | 腹髄のみ | **4,081** | **23,546** | **完全に手つかず** |
| FlyWire 783 | 雌・全脳（両半球） | — | 約 13 万 | **照合にしか使っていない** |

**male-CNS は細胞数が hemibrain の 7 倍ある。** 視葉と腹髄を含むので、
hemibrain には無い回路がそのまま未探索として残っている。
MANC だけでも hemibrain と同じ規模（型 4,081・細胞 23,546）がある。

- **MANC（腹髄）** は下行ニューロンの先にある運動回路。
  行動の読み出しが直接とれるので、読み出しの弱さという本プロジェクトの
  弱点を埋められる可能性がある。ただしドライバーの整備状況は未調査。
- **FlyWire を母体にする** と左半球・両側性の細胞が入る。
  hemibrain は右半球だけなので、対側に投射する細胞の接触を取りこぼしている。
- **male-cns を母体にする** と雌雄差のある回路に触れる。

## 5. やる順番（有望な順）

1. **ドライバーがある 323 型を 1 つにまとめて全組を評価**（上記 3 節）。
   領域の区切りを外すだけで、未評価の 92.7% に手が届く。いちばん費用対効果が高い。
2. **SMP・SIP・SLP を低いしきい値で取り直す**（800 → 200）。
   ドライバーつきの未探索 37 型が入る。候補が出た実績のある領域でもある。
3. **MANC（腹髄）の下調べ** — 型の数とドライバーの整備状況を見てから決める。
4. FlyWire / male-cns を母体にした探索。計算量が大きいので最後。

**いずれにせよ、増えるのは「シナプス 0 の組」であって「使える組」ではない。**
これまでの絞り込みで効いた制約は一貫して**ドライバー、とくに LexA** だった。
`results/hemidriver_lexa_report.md` のヘミドライバー変換のほうが、
候補を増やす手段としては確度が高い。
