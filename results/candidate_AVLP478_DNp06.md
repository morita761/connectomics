# 候補の検討: AVLP478 → DNp06

2026-11-10。「両方 GAL4 しかない」32 組のうち、行動の読み出しと膜の密着が
いちばんそろっていた組（`results/gal4only_candidates.md`）を詰めた。

- **AVLP478** = 前腹外側前大脳の **GABA 作動性**ニューロン（左右 1 個ずつ、細胞体繊維 PVL03）
- **DNp06** = **下行ニューロン**（アセチルコリン、左右 1 個ずつ、PVL15）
- **接触** hemibrain で 95.4 µm、別個体（male-CNS）の左右で 28 / 39 µm
- **シナプス** 3 個体・両方向すべて 0（期待値 7.04、Poisson 検定 **p = 0.00088**）

## 0. 結論を先に

**行動の読み出しという一点で、これまでのどの候補より強い。**
下行ニューロンに抑制シナプスを 1 本足すので、効果がそのまま運動として出る。

| 条件 | 判定 |
|---|---|
| 3 個体・両方向でシナプス 0 | ◎ |
| 別個体での接触の再現 | ◎ 28〜39 µm |
| 膜の密着（EM） | **◎ 714 シナプスある対照と同等** |
| 上流がその領域で出力する | **◎ 出力の 90% が接触領域にある** |
| 下流に受容体があるか | ◎ GABA 入力 21.2%（8,841 シナプス） |
| 混同（U × D） | **◎ 4 組すべて 2 個体で 0** |
| 発現系が 2 つ | △ LexA が無い。変換か断片 LexA が要る |
| 行動の読み出し | **◎ 熱回避のナビゲーション（Jouandet 2023）** |
| 上流が下行ニューロンと結合する実績 | **✕ ほとんど無い（後述）** |

## 1. なぜこの組か

### DNp06 は AVLP の細胞から大量に入力を受けている

| | hemibrain | male-CNS |
|---|---|---|
| AVLP\* → DNp06 の合計 | **3,212 シナプス / 184 タイプ** | **8,666 シナプス / 173 タイプ** |
| **うち AVLP478 から** | **0** | **0** |

接触の長さで割った密度で並べると、AVLP478 だけが 0 になる。

| 組 | 接触 | シナプス | 1 µm あたり |
|---|---|---|---|
| AVLP201 → DNp06 | 322.9 µm | 112 | 0.347 |
| AVLP435 → DNp06 | 265.3 µm | 92 | 0.347 |
| AVLP488 → DNp06 | 302.3 µm | 101 | 0.334 |
| AVLP542 → DNp06 | 412.6 µm | 111 | 0.269 |
| AVLP170 → DNp06 | 374.3 µm | 91 | 0.243 |
| AVLP076 → DNp06 | 814.2 µm | 179 | 0.220 |
| AVLP166 → DNp06 | 349.7 µm | 60 | 0.172 |
| **AVLP478 → DNp06** | **95.4 µm** | **0** | **0.000** |

ほかの AVLP が 0.02〜0.35 シナプス/µm で結合しているので、95.4 µm の接触なら
**2〜33 シナプスできていておかしくない**。解析の期待値は 7.04、Poisson 検定で **p = 0.00088**。
統計的にも有意な欠落である。

### ただし正直に言うと、上流側の対照は弱い

**AVLP478 自身は、下行ニューロンとほとんど結合していない。**

| | hemibrain | male-CNS |
|---|---|---|
| AVLP478 → 下行ニューロン全般 | **7 シナプス / 5 タイプ** | **105 シナプス / 20 タイプ** |

AVLP478 の主な出力先は AVLP082 (1,418)、AVLP001 (1,229)、AVLP079 (588) といった
**同じ AVLP の仲間**であって、下行ニューロンではない。

つまりこの組の欠落は、
**「DNp06 の側から見れば異常（184 タイプが結合しているのに 1 つだけ 0）」**だが、
**「AVLP478 の側から見れば普通（もともと DN に出さない細胞）」**である。
強制形成が成功した場合、それは **AVLP の局所介在ニューロン → 下行ニューロン**という
本来ほとんど存在しない種類の結合を作ることになる。
これは弱点でもあり、**この実験でしか作れない結合という意味では面白い点でもある**。

## 2. 伝達物質がかみ合う

| | 伝達物質 | 根拠 |
|---|---|---|
| AVLP478 | **GABA** | male-CNS の consensusNt（予測も一致） |
| DNp06 | アセチルコリン | 同上 |

**DNp06 は入力の 21.2%（8,841 シナプス）を GABA から受けている**（male-CNS、入力の総数 41,753）。
GABA 受容体がある状態なので、新しくできたシナプスは機能しうる。

DNp06 の主な入力:

| 相手 | シナプス | 正体 |
|---|---|---|
| LPLC1 | 2,773 | ルーミング（接近刺激）検出の視覚投射ニューロン |
| LPLC2 | 1,719 | 同上 |
| PVLP123 | 1,528 | 腹外側前大脳 |
| LC4 | 1,152 | ルーミング検出 |
| PVLP122 | 1,018 | 腹外側前大脳 |

**DNp06 は視覚的な接近刺激に対する回避の出口にあたる。**
そこに GABA を 1 本足すことになるので、「逃避・回避が出にくくなる」方向の変化を予想する。

## 3. 接触部位

### 細胞ごと

hemibrain では AVLP478_R (5813098368) と DNp06_R (5813023322) の 1 組だけが接している（95.4 µm）。
hemibrain は右半球のみなので、左側は male-CNS で確認した（L 39 µm / R 28 µm）。

### 領域の内訳

```
接触の場所        AVLP(R) 74%, PVLP(R) 25%, WED(R) 1%
AVLP478 の出力    AVLP(R) 1,667, PVLP(R) 153, ICL(R) 33     （全 1,859 のうち約 90% が AVLP(R)）
AVLP478 の入力    AVLP(R) 6,324, PVLP(R) 557
DNp06 の入力      PVLP(R) 5,546, AVLP(R) 3,169, PLP(R) 1,456, WED(R) 1,370
DNp06 の出力      PVLP(R) 61, WED(R) 31, AVLP(R) 14         （脳内では受け手。出力は腹髄）
```

**AVLP478 は出力の 90% を接触領域で出している。** これはこれまでの候補で最高
（MBON04 ↔ PPL105 は 53%、ExR2 → LAL098 は 14%）。
DNp06 側も AVLP(R) に 3,169 の後シナプス部位がある。
**両者が「出す側」「受ける側」として働いている場所で接している。**

## 5. ドライバー — ここが唯一の弱点

| 役割 | 系統 | 発現系 | 標識する型 | 特異性 | 構成 |
|---|---|---|---|---|---|
| 上流 AVLP478 | **SS01181** | split-GAL4 | MBON11, AVLP478（+MBON31, MBON32?） | **0** | VT049125(DBD) ∩ R52H01(AD) |
| 下流 DNp06 | **SS02256** | split-GAL4 | **DNp06 のみ** | **2** | VT017411(DBD) ∩ **VT019018**(AD) |
| 下流 DNp06（代替） | SS01047 | split-GAL4 | DNp06 のみ | 1 | VT017647(DBD) ∩ **VT019018**(AD) |
| 下流 DNp06（代替） | SS02292 | split-GAL4 | DNp04, DNp06 | 1 | VT017647(DBD) ∩ VT017411(AD) |

**AVLP478 を標識する系統は SS01181 ただ 1 本で、特異性 0。**
MBON11 を一緒に標識し、Shuai 2024 の記載では MBON31・MBON32 も入る可能性がある。

### 混同の確認 — それでも U × D はすべて 0

U = {AVLP478, MBON11, MBON31, MBON32}、D = {DNp06} として両方向を数えた。

| 組 | hemibrain | male-CNS |
|---|---|---|
| AVLP478 ↔ DNp06 | 0 / 0 | 0 / 0 |
| **MBON11 ↔ DNp06** | **0 / 0** | **0 / 0** |
| **MBON31 ↔ DNp06** | **0 / 0** | **0 / 0** |
| **MBON32 ↔ DNp06** | **0 / 0** | **0 / 0** |

**4 組すべてが 2 個体で完全に 0。** SS01181 の特異性が低くても、
**この実験に関しては基準値が汚れない。**

### どう LexA をそろえるか

2 つの道があり、**前者を強く勧める**。

| 案 | 構成 | U × D | 判定 |
|---|---|---|---|
| **① SS02256 を split-LexA に変換** | 上流 SS01181-GAL4 ／ 下流 split-LexA(DNp06) | **4 組。すべて 0 と確認済み** | **◎** |
| ② VT019018-LexA をそのまま使う | 上流 SS01181-GAL4 ／ 下流 VT019018-LexA | VT019018 が何を標識するか未確定 | △ |

①は Shuai 2024 の変換法（34 系統中 22 系統成功）で SS02256 を split-LexA にするだけ。
**D が DNp06 単独のままなので、上の表で混同の判定が完結している。**
②は断片 1 つなので D が広がり、FlyLight の画像で中身を確定し直す必要がある。

なお AVLP478 側を LexA にする道は無い。SS01181 の断片
（VT049125・R52H01）にはどちらも LexA 版が存在しない。

## 6. 読み出し

### DNp06 の行動

- **熱回避のナビゲーション**。
  Jouandet GC, et al. (2023) Rapid threat assessment in the Drosophila thermosensory system.
  *Nat Commun* 14:7067 [10.1038/s41467-023-42864-5](https://doi.org/10.1038/s41467-023-42864-5)
  — 温度受容の TLHON の下流として DNp06 を遺伝的に抑えると、熱回避の
  ナビゲーションに表現型が出る。
- **ルーミングへの応答**。DNp06 の最大の入力は LPLC1・LPLC2・LC4 という
  接近刺激の検出器で、視覚的な回避・逃避の出口にあたる。
- 下行ニューロンの一般論として、Cande J, et al. (2018) *eLife* 7:e34275
  [10.7554/eLife.34275](https://doi.org/10.7554/eLife.34275) が
  個々の DN の光遺伝学的活性化で歩行中の行動がどう変わるかを体系的に測っている。
  同じ枠組みがそのまま使える。
- 形態と命名: Namiki S, et al. (2018) *eLife* 7:e34272
  [10.7554/eLife.34272](https://doi.org/10.7554/eLife.34272)

### 予想される向き

新しくできるのは **GABA（抑制）→ 下行ニューロン**。

- 熱・接近刺激に対する**回避の出にくさ**として読める。
- 読み出しは逃避の潜時・成功率、熱勾配でのナビゲーション、歩行の速度と旋回。
- **効果が運動として直接出るので、シナプス 1 本の影響を見るには最も素直な構成**。
  FB4N（行動の前例なし）や LAL098（文献なし）とは対照的。

## 8. ほかの候補との比較

| | AVLP478 → DNp06 | MBON04 ↔ PPL105 | MBON04 → FB4N |
|---|---|---|---|

| 混同（U × D） | **4 組すべて 0・確認済み** | 6 組・最大 3 | 3 組すべて 0 |

**読み出しと膜の密着では最良。** 足りないのは発現系（変換 1 回で解決）と、
「上流がそもそも下行ニューロンに出力しない細胞である」という点。

## 9. 残っている確認事項

1. **SS02256 の split-LexA 化**。Shuai 2024 の方法。成功率は 22/34。
2. SS01181 が MBON31・MBON32 を本当に標識するかを標本で確認する
   （コネクトーム上はどちらも DNp06 と 0 なので、標識していても基準値は汚れない）。
3. AVLP478 が DN にほとんど出力しない細胞であることを踏まえ、
   **前側の分子を AVLP478 の軸索終末に届けられるか**（AVLP478 の出力部位は
   AVLP(R) に 1,667 あるので、場所の問題は無い）。
4. 導入する分子の向き。GABA 作動性 → 下行ニューロンなので、
   抑制性シナプスとして機能させるには GABA-A（Rdl）の局在も見る。
