# 匂いだけで記憶を作る: MBON07 → PPL106 の設計

2026-11-23。`results/plan_three_pairs.md` で第一候補に決まった組の実験設計。
解剖・遺伝学・EM の根拠は [candidate_MBON07_PPL106.md](candidate_MBON07_PPL106.md) にある。
ここは**何をどう測るか**だけを書く。

## 0. この組で何を主張するか

> **匂いを嗅がせるだけで、電気ショックも砂糖も与えずに、24 時間残る記憶を作る。**

これが成立すれば、人工シナプスが**感覚入力を教師信号に変換した**ことになる。
強制活性ではなく自然な刺激で動くので、「配線を足したら脳が新しい計算をした」と言える。

| | |
|---|---|
| **上流** | MBON07 = MBON-α1。グルタミン酸。**入力の 86% が KC** |
| **下流** | PPL106 = PPL1-α3。ドーパミン。α3 区画に 1,955 の出力 |
| **接触** | SLP(R) 70%、SIP(R) 30%。37 µm（hemibrain）、左右とも 19 µm（male-CNS） |
| **シナプス** | **3 個体で両方向 0** |
| **膜** | **6,333 voxel / 72%。結合している対照の 2.44 倍** |
| **系統** | **MB319B〈GAL4〉× SL86050〈LexA〉。U × D = 1 組** |

## 1. なぜこの組か — 鎖の最初の環が他より強い

新しい基準は、**匂い → 上流 → 人工シナプス → 下流 → 記憶**という鎖を要求する。
鎖の最初の環（匂いが上流を駆動するか）は、**上流の入力のうち KC が占める割合**で見られる。

| 上流 | KC 入力 / 全入力 | KC 率 |
|---|---|---|
| **MBON07** | 25,650 / 29,682 | **86%** |
| MBON02 | 16,964 / 36,085 | 47% |
| MBON04 | 6,649 / 33,084 | 20% |

**MBON07 の発火は、ほぼそのまま「いま何の匂いがしているか」である。**
しかも入力は α1(R) に 28,927 と、ほぼ 1 区画に集中している。
ノイズの少ない匂い信号を人工シナプスに乗せられる。

## 2. 回路としての意味 — 区画をまたぐフィードバックを作る

キノコ体の区画には、**その区画の MBON が、その区画の DAN に返す**ループがある。

| 既存のループ | シナプス | 働き |
|---|---|---|
| MBON07(α1) → **PAM11(α1)** | **75**（male-CNS 74） | 報酬性 LTM の固定化（Ichinose 2015） |
| MBON14(α3) → **PPL106(α3)** | 47 | α3 区画内のフィードバック |
| MBON07(α1) → **PPL106(α3)** | **0** | **無い。これを作る** |

**区画内のフィードバックは普通にあるのに、区画をまたぐものは無い。**
作ろうとしているのは、**α1 の読み出しが α3 の教師に口を出す経路**である。

意味が通る。α1 は報酬性 LTM の区画、α3 は長期記憶そのものに関わる区画なので、
**「報酬記憶の読み出しが、別の長期記憶系に書き込む」**ことになる。

**MBON07 が DAN を駆動できること自体は既に分かっている。** PAM11 に 75 シナプス作っている。
「この細胞は DAN とシナプスを作れないから 0 なのだ」という逃げ道は無い。

## 3. 符号は読めない。読めなくても実験は立つ

**不確実性が 2 つ重なっている。正直に書く。**

### 不確実性 1 — グルタミン酸の符号

PPL106 は既に 1,960 シナプス（11.6%）のグルタミン酸入力を受けているので**受容体はある**。
だが GluClα（抑制性）か Nmdar・KaiR1D（興奮性）かは分からない。

### 不確実性 2 — PPL1-α3 自体の価数が単純でない

| 報告 | 内容 |
|---|---|
| Takemura 2017 | **PPL1-α3 単独の光活性化が、匂い提示なしで接近反応を生じる** |
| Tsao 2018 | PPL1-α3 の活性化が酵母探索を**促進** |
| Jacob 2021 | PPL1-α3 の阻害が pre-exposure 由来の**忌避を接近に反転**させる |

**「PPL1 だから罰」ではない。** α3 は γ1pedc や α'2α2 とは違う。
長期記憶が残るかどうかの**ゲート**に近い働きをしている可能性がある。

### だから主張を「記憶ができる」に置く

| 人工シナプスが | 匂い提示中の PPL106 | 予想される結果 |
|---|---|---|
| 興奮性 | 発火が増える | 提示した匂いに 24 時間の記憶がつく |
| 抑制性 | 発火が減る | 同じく記憶がつく（符号は逆） |

**どちらでも「本来つかないはずの記憶がつく」。符号が変わるだけである。**
PPL1-DAN は自発発火しているので（Huang 2018 が PPL105 で 6〜10 Hz を実測）、
**発火が下がること自体が信号になる。**

**予測を「嫌悪記憶ができる」と書いてはいけない。**
**「提示した匂いへの選好が、対照の匂いに対して動く」**と書く。
動く向きは結果である。

## 4. 構成 — 系統とコンストラクト

### 系統（この組の最大の長所）

| 役割 | 系統 | 発現系 | 標識する型 |
|---|---|---|---|
| 上流 MBON07 | **MB319B** | split-GAL4 | **MBON07 のみ** |
| 上流（代替） | MB319C / MB323B | split-GAL4 | MBON07 のみ |
| 下流 PPL106 | **SL86050** | split-LexA | **PPL106 のみ**（1 細胞、特異性 2） |
| 下流（代替） | SL86062 | split-LexA | PPL106 のみ。**ただし「発現が弱い」と注記あり** |

**U × D = 1 組。混同が原理的に存在しない。** 本計画の候補でここまで清潔なのは
この組と MBON31 → PAM11 だけ。GAL4 は 3 本、LexA は 2 本から選べる。

### 「特異性」の読み方 — 数が大きいほど良い

**特異性 = max(0, 3 − Quality)。** Quality は Shuai 2024 / Meissner 2024 が各系統に付けた
品質の評点で、**1 が最良**。これを「大きいほど良い」向きに直したのが特異性である
（`match_drivers.py`）。

| 特異性 | 元の Quality | 意味 |
|---|---|---|
| **2** | 1 | **最良。これ以上は無い** |
| 1 | 2 | 中 |
| **0** | 3 以上 | **いちばん悪い** |

**「特異性2」は「余計な型を 2 つ標識する」という意味ではない。**
余計に標識する型は `(+MBON01,MBON03)` のように括弧で書いてある。
**MB319B にはそれが無い。つまり MBON07 だけを標識する、最良評点の系統である。**

| 系統 | 標識する型 | 細胞数 | 特異性 |
|---|---|---|---|
| **MB319B**〈GAL4〉 | **MBON07 のみ** | 2 | **2（最良）** |
| **SL86050**〈LexA〉 | **PPL106 のみ** | 1 | **2（最良）** |
| SL86062〈LexA〉 | PPL106 のみ | 1 | 2。ただし**「発現が弱い」と注記** |
| SS01246〈GAL4〉 | PPL101 ＋ PPL106 ＋ ExR2 | 4 | **0（最悪）** |
| MB328B〈GAL4〉 | PPL103 ＋ PPL105 ＋ PPL106 | 3 | **0（最悪）** |

ただし**この評点と型の一覧は、注釈されている中枢神経系の細胞型についてのもの**で、
まばらな系統外発現がゼロであることまでは保証しない。

### SS01246 / MB328B を使っていたら、論理は破綻していた

**使わないので杞憂ではある。だが「使えない」ことは確かめておく価値があった。**
これらは**下流を GAL4 にする逆向きの構成**でしか出てこない系統で、
余計に標識する型が **MBON07 のすぐ近くを通っている。**

hemibrain の中心線で測った（0.5 µm 間隔、1 µm 以内のケーブル長、両側平均）。

| MBON07 との関係 | 接触 1 µm | 最短距離 | 既存シナプス |
|---|---|---|---|
| **PPL106（目標）** | 44 µm | 0.10 µm | **0** |
| **PPL101**（SS01246 が巻き込む） | **26 µm** | **0.16 µm** | 0 |
| **PPL103**（MB328B が巻き込む） | **62 µm** | **0.05 µm** | 0 |
| **PPL105**（MB328B が巻き込む） | **255 µm** | **0.06 µm** | **14（結合している）** |

**PPL103 は目標より接触が長く、PPL105 は 6 倍近い。**
オーガナイザーを載せれば、**目標より先にそちらにシナプスができてもおかしくない。**

破綻の中身は深刻である。

- **PPL101 = PPL1-γ1pedc（MB-MP1）** は嫌悪記憶の教師信号そのもの。
  ここに配線ができたら、記憶が α3 由来なのか γ1 由来なのか**区別できない。**
- **PPL105 は MBON07 と既に 14 シナプスある**ので、そもそも「0 の組」ですらない。
- ExR2 は hemibrain のこのデータセットに入っていないので**未測定**。

**つまり下流に GAL4 を置く構成は、この組では採れない。**
**MB319B〈GAL4〉＋ SL86050〈LexA〉で正しい。** 心配したこと自体が、その選択の裏付けになる。

**下流に SL86050 を選んでおくと、MBON02 → PPL106 と系統を共有できる**
（`results/plan_three_pairs.md` 6 節）。上流の GAL4 を差し替えるだけで 2 組目が走る。

### コンストラクト

上流が GAL4 なので、オーガナイザーの向きは素直。

| 側 | 入れるもの | 役割 |
|---|---|---|
| **上流 MBON07**〈GAL4〉 | **UAS-オーガナイザーの前側** | 接着の本体 |
| | **UAS-Kirre** | **シナプス形成の効率を上げる補助** |
| | UAS-CsChrimson | 段階 B' の存在証明（トラック 1 のみ） |
| **下流 PPL106**〈LexA〉 | **LexAop-オーガナイザーの後側** | 接着の本体 |
| | LexAop-GCaMP | 段階 B の読み出し |
| 全体 | **`tub-GAL80ts`** | **段階 C で必須**（6.2 節） |

**Sns も Hbs も入れない（2026-11-23 訂正）。**
**外来の Kirre はそれ自体が導入するシナプスオーガナイザーと働いてシナプス形成に関与する**ので、
IRM の相手役を下流に乗せる必要は無い。Kirre は**前側に足す補助**であって、
接着の本体はオーガナイザーのほうである。
（周囲のニューロンに内在の Sns/Hbs がほとんど無いことは
[receptor_check.md](receptor_check.md) 2.5 節で確かめたが、**これは
「外来 Kirre が横取りされないか」への答えであって、構成要素の話ではない。**）

`tub-GAL80ts` は温度でオーガナイザーの発現を切れるので、
**遺伝子型が同じきょうだいを「配線あり／なし」に分けられる。**
発生期の配線変化も、飼育環境の匂いによる飽和も、これで同時に片付く。

## 5. 段階

> **2026-11-23 追記。オーガナイザーが光スイッチ型である場合、下の段階 B' は使えない。**
> **CsChrimson と接着スイッチが同じ赤色帯を使う**ので、同じ個体で独立に制御できない。
> **常時接着型（光ドメイン無し）のオーガナイザーを使うトラック 1** と、
> **光スイッチ型で成虫期に作るトラック 2** に分ける。
> 下の段階 A〜C はトラック 1 の手順として読む。
> 波長の衝突、発色団、730 nm で壊す実験、進め方は
> **[optical_organizer.md](optical_organizer.md)** にまとめた。


### 段階 A — 解剖。シナプスができたか

光も匂いも使わない。syb-GRASP ＋ Brp で、PPL106 の SLP(R)・SIP(R) 側の後シナプス部位を数える。

| 群 | 上流 MB319B〈GAL4〉 | 下流 SL86050〈LexA〉 | 役割 |
|---|---|---|---|
| **①完全** | オーガナイザーの前側 ＋ Kirre | オーガナイザーの後側 ＋ GCaMP | 本番 |
| **②下流のみ** | なし | オーガナイザーの後側 ＋ GCaMP | 片側だけ。陰性が予想 |
| **③効果器のみ** | なし | GCaMP だけ | 背景 |
| **①の 18°C 同腹** | 同じ遺伝子型。発現しない | 同じ | **遺伝子型が同一の陰性対照** |

**① > ①の 18°C 同腹** が出れば成立。②は念のための確認で、関門ではない。

> **結合しない変異体の群は置かない。** 陰性対照は
> **トラック 1 では GAL80ts の 18°C 同腹、トラック 2 では光を当てない同腹**で作れる。
> どちらも遺伝子型が完全に同一なので、変異体を作るより強い
> （[optical_organizer.md](optical_organizer.md)）。
> なお **Kirre は接着の本体ではなく、前側に共発現してシナプス形成の効率を上げるための補助**である。

### 段階 B' — CsChrimson。先にやる存在証明

**匂いの実験より先に、強制活性で記憶ができることを示す。**

理由は単純で、**匂いの実験が陰性だったとき、原因が区別できなくなるから**である。

| | 原因 |
|---|---|
| シナプスができなかった／下流を駆動できなかった | B' で分かる |
| シナプスはできたが匂いによる発火が弱かった | B' が陽性なら、こちら |

手順は、**赤色光で MBON07 を活性化しながら匂い A を提示 → 24 時間後に A と B の選択**。
retinal 給餌あり／なしの同腹で、遺伝子型を揃えた光対照が作れる。

### 段階 B — 生理。匂いで下流が動くか

下流に GCaMP。**匂い A を提示して PPL106 の応答を見る。**

| 群 | 予想 |
|---|---|
| ①完全（31°C） | **応答が変わる**（増えるか減るかは 3 節のとおり未定） |
| ①の 18°C 同腹 | 変わらない |
| ③効果器のみ | 変わらない |

ここが陽性なら、鎖の **匂い → 上流 → シナプス → 下流** まで繋がったことになる。
残るのは記憶だけ。

### 段階 C — 行動。匂いだけで記憶ができるか

**これが本番。訓練は「匂い A を嗅がせる」だけ。試験は 24 時間後の A と B の二択。**
手順は 6 節に分けて書いた。

## 6. 段階 C の手順

### 6.0 普通の条件づけと、どこが違うか

普通の嗅覚条件づけは **CS（匂い）と US（電気ショック）を実験者が対提示する**。
ここでは **US にあたるものが配線である。** 違いはこの一点から全部出てくる。

| | 普通の条件づけ | この実験 |
|---|---|---|
| US | 実験者が与える電気ショック | **人工シナプス経由の PPL106 駆動** |
| 対提示 | 実験者がタイミングを決める | **匂いが来れば自動的に起きる** |
| 訓練していない個体 | 作れる（US を与えない） | **作れない。嗅げば訓練になる** |
| US の強さ | 電圧で調節できる | **調節できない**（上流の発火しだい） |

ここから 3 つの帰結が出る。**6.1〜6.3 はその対処**である。

### 6.1 「訓練していない対照」は、匂いを入れ替えて作る

嗅がせないわけにいかないので、**同じ匂い対の、どちらを嗅がせたかで 2 群に分ける。**
これは嗅覚条件づけで**相反設計（reciprocal design）**として確立した手法で、
匂いそのものの好き嫌い（naive bias）が相殺される。

- **群 A**: OCT を 曝露 → OCT 対 MCH の二択
- **群 B**: MCH を 曝露 → OCT 対 MCH の二択

**記憶指数 PI = (曝露した匂いを避けた個体数 − 避けなかった個体数) / 全個体数** を
群 A と群 B で求めて平均する。
**曝露が選好を動かしていなければ PI は 0 になる。** 符号は 3 節のとおり未定なので、
**0 から有意に離れるかどうかを見る。**

匂いは **OCT（3-オクタノール）と MCH（4-メチルシクロヘキサノール）**を使う。
標準的な対であり、**餌にも飼育環境にも含まれない**ので、
「飼育中に既に訓練されている」心配が無い。

> **「匂いの無い環境で飼育する」は現実には無理**（餌の酵母とプロピオン酸が強く匂う）。
> 必要なのは **試験に使う匂いに対して素朴であること**だけなので、OCT / MCH を使えば足りる。
> 飼育環境の匂いが常時 PPL106 を駆動して α3 を飽和させる問題は、次の 6.2 で切る。

### 6.2 GAL80ts — 遺伝子型が同じ対照が作れる

**これが段階 C でいちばん効く仕掛け。**

`tub-GAL80ts` を入れておくと、**18°C ではオーガナイザーが出ず、31°C で出る。**
つまり **同じ遺伝子型のきょうだいを、温度だけで「配線あり／なし」に分けられる。**

| | 18°C のまま | 31°C に移した |
|---|---|---|
| オーガナイザー / Kirre | 出ない | 出る |
| 人工シナプス | **無い** | **ある** |
| 遺伝子型 | **同一** | **同一** |

遺伝的背景の差が原理的に入らないので、**別系統を対照に立てるより強い。**
段階 B' の retinal 給餌あり／なしと同じ考え方で、こちらは**オーガナイザー側**に効く。

同時に 2 つの問題も片付く。

- **発生期の配線変化**。羽化後に温度を上げれば、成虫になってからシナプスができる。
- **飼育環境の匂いによる飽和**。配線がある期間を数日に限れば、
  その間の曝露だけが効く。

**誘導にかける日数は段階 A で決める。** 解剖で ① > 18°C 同腹 が出る最短の日数をそのまま使う。

### 6.3 曝露と試験のタイミング

**α3 は蛋白合成依存の長期記憶の区画である。** だから設計を LTM 側に寄せる。

| 段取り | 内容 | ねらい |
|---|---|---|
| 飼育 | 18°C（GAL80ts でオフ） | 発生期に配線を作らない |
| 羽化後 | 31°C に移して N 日（N は段階 A の最短） | 成虫期に配線を作る |
| 馴化 | 清浄空気の中で 1 時間 | 直前の匂い履歴を消す |
| **曝露** | **1 分の匂い提示**。① 単回 ② **15 分間隔で 5 回** | LTM には間隔訓練が要る可能性 |
| 試験 | **3 分後 / 3 時間後 / 24 時間後**（別個体） | STM / MTM / **LTM** |

**間隔訓練を入れるのは、Aso & Rubin 2016 が 4 日記憶に 10 回の間隔訓練を要したから。**
単回で出なくても、間隔訓練で出る可能性がある。逆に単回で出たら、それ自体が強い結果になる。

**予想: 24 時間後にだけ差が出る。3 分後には出ない。**
これが α3 を経由した証拠になる。
**3 分後にも差が出たら、α3 以外の経路が動いている**ので、解釈をやり直す。

### 6.4 群の構成

**遺伝子型は 2 つ、温度は 2 つ。4 群。**

| | 遺伝子型 | 18°C | 31°C |
|---|---|---|---|
| **①完全** | MB319B>前側+Kirre ／ SL86050>後側 ／ tub-GAL80ts | **主要な対照**（遺伝子型が同一） | **本番** |
| **③効果器のみ** | オーガナイザーなし | 対照 | 温度そのものの対照 |

それぞれに相反設計（OCT 曝露 / MCH 曝露）が付くので、
**1 つの試験時点あたり 8 条件。** 試験時点が 3 つなので 24 条件。

**主要な比較は「①の 31°C 対 ①の 18°C」の 1 本。** 遺伝子型が同一なので、ここが本体。
③は温度そのものの影響を見るためだけに置く。

**それでも多いので、単回曝露・24 時間だけで予備を回し、差が出てから広げる。**

### 6.5 対照が否定するもの

| 対照 | 否定できるもの |
|---|---|
| **18°C の同腹** | **遺伝的背景、温度以外のすべて**（いちばん強い） |
| ②下流のみ（片側だけ） | 下流側だけで勝手に接着が起きていないこと |
| ③効果器のみ | 31°C そのものの影響 |
| 相反設計（OCT / MCH 入れ替え） | 匂いの好き嫌い |
| 無曝露（清浄空気だけ） | 配線があるだけで選好が動かないこと |
| **別の匂い対で試験**（曝露は OCT、試験は別の 2 つ） | **記憶が匂い特異的であること** |
| **シクロヘキシミド**（蛋白合成阻害） | **24 時間の差が本当に LTM であること** |
| 3 分後の試験 | 短期記憶が動いていないこと |
| 上流を MBON07 以外に替える | MBON07 であることの必要性 |

**シクロヘキシミドは安くて決定的。** α3 の記憶は蛋白合成依存なので、
24 時間の差が消えれば本物の LTM、消えなければ別の何かである。

### 6.6 もう 1 つの読み出し — MBON14 の匂い応答

行動だけだと「記憶ができた」の証拠が間接的になる。**痕跡を直接見る手がある。**

**α3 区画の読み出しニューロンは MBON14（MBON-α3）**で、
PPL106 が α3 に 1,955 の出力を持っている。記憶が書かれたなら、
**曝露した匂いに対する MBON14 の応答が抑圧されるはず**である。

| 測るもの | 予想 |
|---|---|
| MBON14 の OCT 応答（OCT を曝露した個体） | **下がる** |
| MBON14 の MCH 応答（同じ個体） | 変わらない |
| 18°C の同腹 | どちらも変わらない |

**行動と生理が同じ向きを指せば、主張がはるかに強くなる。**
MBON14 には別の系統が要るので後回しでよいが、
**行動で差が出た直後にこれを取るのが、いちばん費用対効果が高い。**

### 6.7 匹数

標準的な T-maze に合わせる。**1 つの PI は 50〜100 匹の相反する 2 群から 1 つ出る。**
**1 条件あたり PI を 8〜12 個**取れば、通常の効果量なら検出できる。
予備実験（単回曝露・24 時間・3 遺伝子型 × 2 温度）で **PI 約 60 個、ハエ約 5,000 匹**。

検定は、**まず「①の 31°C」の PI が 0 と違うか**（一標本）、
次に **①の 31°C 対 ①の 18°C**（これが主要な比較）、
そのうえで ③ との比較。多重比較の補正を入れる。

### 6.8 つまずきそうなところ

| 懸念 | どうなるか | 手当て |
|---|---|---|
| 31°C がハエに負担 | 全体の成績が落ちる | 29°C に下げる。日数を延ばして補う |
| 誘導中の飼育環境の匂いで飽和 | 本番の曝露が効かない | 誘導期間を短くする。誘導中は清浄空気で飼う |
| MBON-α1 の応答が曝露のたびに弱まる | 間隔訓練が効かない | 単回曝露の結果と比べる。段階 B で応答の持続を見ておく |
| オーガナイザー・Kirre の発現が MBON07 本来の出力を乱す | ①の基礎行動が変わる | 18°C の同腹で切り分け。素朴な匂い選好を先に測る |
| 効果が小さい | 差が出ない | 段階 B' の強制活性でどれだけ出たかを目安に、曝露回数を増やす |

### 6.9 ついでに測ると面白いこと

**配線が常時あることは、裏返せば予測になる。**
**特定の匂いの中で数日飼ったハエは、実験者が訓練しなくてもその匂いへの選好が変わっているはずである。**

誘導中（31°C の N 日間）に OCT を薄く流した群と、清浄空気で飼った群を比べればよい。
**ここで差が出れば、人工シナプスが日常的に働いている証拠になる。**
T-maze の訓練より自然な条件なので、出たときの主張は強い。

## 7. 比較の相手 — MBON02 → PPL106

下流が同じ細胞（bodyId 331662710）で、**LexA 系統も共有できる**。
上流の性格が逆なので、並べると意味が出る。

| | MBON07 → PPL106 | MBON02 → PPL106 |
|---|---|---|
| 上流の区画 | α1（報酬性 LTM の読み出し） | β2β'2a |
| KC 率 | **86%** | 47% |
| 膜（同じ PPL106 に対して） | **6,333 voxel / 72%** | **289 voxel / 18%** |
| 立ち位置 | 本命 | 同じ下流に別の匂い情報を入れたらどうなるか |

**膜で 22 倍の差があるので、MBON02 は成功率が低い。**
だが系統の追加コストが上流 1 本だけなので、走らせる価値はある。

## 8. 否定されたときに何が言えるか

| 段階 | 陰性の意味 | 次の手 |
|---|---|---|
| A: ① ≒ 18°C 同腹 | 接着が作れていない | 接触 37 µm では足りない。MBON04 → PPL105（93 µm）へ |
| B': 強制活性でも記憶が出ない | シナプスはできたが放出部位になっていない | Dsyd-1 の補強。PPL106 の受容体を確認 |
| B: 匂いで下流が動かない | 匂いによる MBON07 の発火が弱い | 上流を MBON01（KC 46%）に替える。または強い匂いで再試 |
| C: 単回曝露で差が出ない | 1 回では足りない | **間隔訓練（15 分間隔で 5 回）に切り替える**（6.3 節） |
| C: 生理は動くが、間隔訓練でも記憶が出ない | **PPL1-α3 の発火だけでは記憶が書けない** | **これは陰性ではなく発見。** KC 活動との時間的一致が要ることの証拠になる |
| C: 24 時間の差がシクロヘキシミドで消えない | 蛋白合成依存の LTM ではない | 別の機構。3 時間後の値と合わせて読み直す |
| C: 3 分後にも差が出る | α3 以外の経路が動いている | 18°C の同腹と③で切り分け |
| C: 18°C の同腹でも差が出る | 配線と無関係な要因 | **設計の前提が崩れる。** GAL80ts の漏れを疑う |

**段階 C の最後の行が重要**で、ここが陰性でも「DAN を駆動するだけでは記憶にならない」
という結論が残る。**どちらに転んでも言えることがある設計になっている。**
