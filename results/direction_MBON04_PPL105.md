# MBON04 と PPL105 のどちら向きを先にやるか — 伝達物質と放出部位から決める

2026-11-22。再現は

```
python - <<'PY'   # neuprint の属性を見るだけ（scratchpad の nt3.py / nt4.py と同じ）
from neuprint import Client; import os
c = Client("neuprint.janelia.org", dataset="male-cns:v1.0",
           token=os.environ["NEUPRINT_APPLICATION_CREDENTIALS"])
print(c.fetch_custom("MATCH (n:Neuron) WHERE n.type IN ['MBON04','PPL105'] "
                     "RETURN n.type, n.consensusNt"))
PY
```

当初の見立ては「**PPL105 → MBON04** は嫌悪刺激が直接行動に出るので T-maze で測れて単純、
**MBON04 → PPL105** はフィードバックで記憶形成に効くので複雑」だった。
伝達物質と領域別のシナプス数を調べると、**実現可能性の順番が逆**だった。

## 0. 結論

| | MBON04 → PPL105 | PPL105 → MBON04 |
|---|---|---|
| 接触領域での**上流の放出** | **1,118**（SIP 538 + SMP 580） | **221**（SIP 169 + SMP 52）＝ 全出力の 8% |
| 接触領域での**下流の受け** | 2,390（SIP 1,443 + SMP 947） | 4,947（SIP 1,189 + SMP 3,758） |
| 基準⑤（上流が接触領域で出力） | **満たす** | 5 分の 1 しかない |
| 伝達物質 | グルタミン酸（おそらく抑制性） | ドーパミン（volume transmission） |
| 判定 | **本命。配線として素直** | 作れはするが上流側に無理がある |

**行動実験で測るなら MBON04 → PPL105。** しかも測る課題は「記憶の獲得」ではなく
**消去・長期記憶・二次条件づけ**に絞られる。

## 2. PPL105 の正体 — α2・α'2 の教師信号

hemibrain の領域別シナプス数（出力）。

| 細胞型 | 主な出力先 | 読み |
|---|---|---|
| **PPL105** | **α2(R) 1,486 ／ α'2(R) 827** | キノコ体 **垂直ローブ α2・α'2** の PPL1。古典名では PPL1-α'2α2（MB-V1）に相当するはず（照合は必要） |
| PPL106 | **α3(R) 1,955** | **タンパク合成依存の嫌悪 LTM** の区画 |
| PAM11 | α1(R) 2,389 | = PAM-α1。接近記憶の LTM |

α'2α2 は**嫌悪記憶の想起と長期記憶**の区画で、短期記憶の γ1pedc（PPL101）とは役割が違う。
つまり「PPL105 を叩けば嫌悪になる」は半分しか正しくない。
**PPL105 の役割は US そのものより記憶の保持・想起の側に寄っている。**
T-maze の 3 分後記憶では差が出にくく、**24 時間後の LTM** で見るべき。

## 3. 接触領域で、どちら向きに放出装置があるか

接触の位置は SIP(R) 41% ／ SMP(R) 31% ／ CRE(R) 10%
（[driver_overlap_PPL105_MBON04.md](driver_overlap_PPL105_MBON04.md) 3 節）。その 3 領域の内訳。

| 領域 | PPL105 出力 | PPL105 入力 | MBON04 出力 | MBON04 入力 |
|---|---|---|---|---|
| SIP(R) | 169 | 1,443 | **538** | 1,189 |
| SMP(R) | 52 | 947 | **580** | 3,758 |
| CRE(R) | **0** | 18 | 677 | 4,222 |
| （参考）α2(R) | 1,486 | 4,825 | 0 | 0 |
| （参考）β'2(R) | 0 | 0 | 6 | 7,099 |

読み方:

1. **MBON04 → PPL105**: 上流の放出 1,118、下流の受け 2,390。
   MBON04 の軸索終末（β'2 に樹状突起、SIP/SMP/CRE に出力）と
   PPL105 の樹状突起（SIP/SMP で入力 2,390）が向き合う、**教科書どおりの配置**。
2. **PPL105 → MBON04**: 下流の受けは 4,947 で十分だが、
   **上流の放出が 221 しかない**。PPL105 の全出力 2,475 のうち 8%。
   本体は α2・α'2 にある。**PPL105 の樹状突起に放出装置を作らせる**話になる。
3. **CRE の接触は捨てて良い。** PPL105 は CRE に出力 0・入力 18 でほぼ存在しない。
   実質は **SIP と SMP だけ**。

さらにドーパミンは volume transmission で、PPL105 が撒いたドーパミンは
すでに近傍に広がっている。**シナプスを 1 本足した効果が出にくい**ので、
PPL105 を上流にするのは「技術が働いたことを示す読み出し」としては不向き。

## 4. 行動実験の設計

### 本命: MBON04 → PPL105

これは **MBON → DAN フィードバック**そのもの。既知の役割は 3 つに絞られる。
**獲得（acquisition）では差が出ないと予想する。**

| 課題 | 内容 | 予想 |
|---|---|---|
| **消去（extinction）** | 嫌悪条件づけ → CS 単独で再曝露 → 消去の速さ | **速くなる** |
| **長期記憶** | spaced training → **24 時間後** | **弱くなる** |
| 二次条件づけ | MBON→DAN が必須とされる課題 | 変化する |
| （対照）3 分後の STM | 標準の T-maze | **差が出ない** |

**符号の予測**: MBON04 はグルタミン酸で、ハエ中枢では GluClα 経由の**抑制性**になることが多い。
嫌悪の教師信号（PPL105）に抑制を足すので、**嫌悪 LTM が弱くなる／消去が速くなる**。

意味づけも素直。MBON04（β'2mp、接近・摂食系の出力）→ PPL105（嫌悪 LTM の教師信号）は、
**「接近側の出力が嫌悪の記憶を書き換える」ループを人工的に作る**ことになる。
これは消去の回路そのもの。

### PPL105 → MBON04 をやるなら、T-maze ではなく光 US で

強制シナプスは**常にある配線**なので、作っただけでは嫌悪刺激が自動的に効くようにはならない。
PPL105 を能動的に駆動する必要がある。

- **匂い + PPL105 の CsChrimson 光刺激を US にして条件づけ** → T-maze。
  電気ショックより制御が効き、上流ドライバーにそのまま効果器を乗せられる（5 節）。
- 「直接の行動」を見たいなら T-maze（学習課題）ではなく、
  **光刺激そのものの価値を問う二択チャンバー**の方が素直。

### もうひとつの選択肢: MBON31 → PAM11

行動の切れ味だけなら、こちらが上かもしれない（[candidate_MBON31_PAM11.md](candidate_MBON31_PAM11.md)）。

- **MBON31 は GABA、PAM11 は PAM-α1。GABA → Rdl は受容体の存在がほぼ確実**（6 節のリスクが無い）
- **PAM-α1 は MBON-α1 との再帰ループが接近記憶の LTM に必須**（Ichinose 2015）。
  そこに GABA 抑制を足せば **接近 LTM が壊れる**、という向きの揃った大きな予測が立つ
- 確立した行動課題（spaced appetitive training → 24h memory）がそのまま使える
- EM の密着比 2.08 で合格済み

**「技術が働くことを行動で示す」なら MBON31 → PAM11、
「回路として面白い」なら MBON04 → PPL105** という棚分けが素直。

## 5. ドライバーは 2 系統で足りる

オーガナイザー 2 つで GAL4 と LexA を使い切ると CsChrimson/GCaMP の系統が無い、
と思いがちだが、**効果器を同じドライバーに相乗りさせれば足りる**。

| | 構成 |
|---|---|
| 上流 | **GAL4 ＞ UAS-オーガナイザー前側 ＋ UAS-CsChrimson** |
| 下流 | **LexA ＞ LexAop-オーガナイザー後側 ＋ LexAop-GCaMP6f** |

QF2/QUAS の第 3 系は不要。

### 両方向が同じ 2 系統で作れる

- PPL105 = **SS48817〈GAL4〉**（+FB2A）
- MBON04 = **SL86063〈split-LexA〉**（+MBON01, MBON03）

**どちらの向きもこの 2 系統で、オーガナイザーの前後を入れ替えるだけ。**
だから「どちらを選ぶか」ではなく、**両方作って比べるのが最強の対照**。
同じ細胞・同じ接触面で、強制シナプスの極性だけが違う。
片方で行動が変わり片方で変わらなければ、効果が配線由来だと言い切れる。

## 6. 先に片付けるべきこと — 受容体

**接着分子はシナプスの骨組みを作るが、後シナプス側に受容体がなければ
電気的には何も起きない。**「配線は増えたのに行動は変わらない」は解釈不能な結果になる。

| 向き | 確認するもの |
|---|---|
| MBON04 → PPL105 | PPL105 に **GluClα**（抑制性）か **DmGluRA** があるか |
| PPL105 → MBON04 | MBON04 に **Dop1R1 / Dop1R2 / Dop2R** があるか |

Fly Cell Atlas（Li 2022）と Davie 2018 の scRNA-seq で引ける。計算だけで済むので、
**ここを飛ばさない。**

## 7. 進める順番

1. **受容体チェック**（計算、1 日）
2. **syb-GRASP** で新しい活性帯ができたか（解剖）
3. **生理**: 上流 CsChrimson → 下流 GCaMP、オーガナイザー有／無。
   **ここが「できた」の最小証明**で、行動より先に取るべき
4. **行動**: 消去 → 24h LTM → 二次条件づけ
5. **対照**: naive odor avoidance、ショック反応性、走性。
   配線を変えた影響が入口の感覚や運動に出ていないか

## 8. MBON01/03 の件が行動の解釈に直結する

SL86063 は MBON01・MBON03 も標識する（[driver_overlap_PPL105_MBON04.md](driver_overlap_PPL105_MBON04.md)）。
**MBON01（γ5β'2a）は接近記憶と消去の中核**なので、
行動が変わったときに「MBON04 のせい」と言えなくなる。

いちばん強い対照は、**MBON01/03 を標識するが MBON04 を標識しないドライバー ＋ 同じオーガナイザー**。
空間的に MBON01/03 は PPL105 と 1 µm 以内の接触が 0 なので、
この対照は**何も起きないはず**。それが示せれば MBON04 単独の効果が確定する。
