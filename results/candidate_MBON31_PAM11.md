# 候補の検討: MBON31 → PAM11

2026-11-11。**膜の密着がプロジェクト全体で最高の候補。**
MBON07 → PPL106（`results/candidate_MBON07_PPL106.md`）と並行して進める想定。

- **MBON31** = MBON-α'1a（**GABA**、左右 1 個ずつ）
- **PAM11** = PAM-α1（ドーパミン、**左右 7 個ずつ**の集団）
- **接触** hemibrain で 25.2 µm、別個体（male-CNS）の左右で 23 / 18 µm
- **シナプス** 3 個体・両方向すべて 0
- **膜の密着 7,375 voxel / 77% — 全候補で最高、対照の 2.1 倍**

MBON31 自身の DAN への結合密度も低いので、
**「0 であること」の統計的な意外さは小さい**。この候補の強みは膜の密着と遺伝学。

## 4. 接触部位

### 細胞ごと（hemibrain）

| 上流 | 下流 | 接触 |

| MBON31 (894020730) | PAM11 (482762280) | 19.2 µm |

PAM11 は集団（male-CNS で左右 7 個ずつ）なので、
25.2 µm は複数の PAM11 細胞への接触の合計。代表ペアが 19.2 µm。

### 領域の内訳

```
接触の場所        SMP(R) 80%, CRE(R) 20%
MBON31 の出力     LAL(R) 44%, SMP(R) 24%, CRE(R) 21%, SIP(R) 5%
PAM11 の入力      a1(R) 54%, SLP(R) 21%, SMP(R) 21%, SIP(R) 2%
主領域 SMP(R) での数   MBON31 の出力部位 244 / PAM11 の入力部位 248
```

**ここが弱点。** MBON31 の出力の本体は LAL(R)（44%）で、接触領域 SMP(R) には 24%（244 部位）。
PAM11 の入力の本体も α1 区画（54%）で、SMP(R) は 21%（248 部位）。
**両者にとって接触部位は主戦場ではない。**
MBON04 ↔ PPL105（538 / 1,380）や AVLP478 → DNp06（1,667 / 3,169）に比べると一桁小さい。

## 6. 読み出し — ここが MBON07 → PPL106 に劣る

### PAM11 = PAM-α1 には前例がある

- Ichinose T, Aso Y, Yamagata N, Abe A, Rubin GM, Tanimoto H (2015)
  *eLife* 4:e10719 [10.7554/eLife.10719](https://doi.org/10.7554/eLife.10719)
  — **MB299B で PAM-α1 を阻害**。条件づけ直後 1 時間の阻害で報酬性長期記憶が
  損なわれ、22 時間後の阻害では損なわれない。
- Takemura SY, et al. (2017) *eLife* 6:e26975
  [10.7554/eLife.26975](https://doi.org/10.7554/eLife.26975)
  — **MB043C × CsChrimson** で PAM-α1 を光駆動し、記憶想起時の効果を測定。
- Yamagata N, Imanishi Y, Wu H, Kondo S, Sano H, Tanimoto H (2022)
  *Front Behav Neurosci* [10.3389/fnbeh.2022.986064](https://doi.org/10.3389/fnbeh.2022.986064)
  — MB299B で PAM-α1 特異的に CCHa2-R をノックダウンし、長期記憶特異の障害。

### MBON31 = MBON-α'1a には前例が無い

論文 15 本を検索して、行動実験の根拠となる記述は **0 本**。
最も近いのは Felsenberg J, et al. (2017) *Nature* 544:240
[10.1038/nature21716](https://doi.org/10.1038/nature21716) で 3 回言及されるだけ
（記憶の再評価の文脈）。系統 SS52050 / SS80896 の出所は
Rubin GM, Aso Y (2024) *eLife* [10.7554/eLife.90523](https://doi.org/10.7554/eLife.90523)
で、形態と系統の記載にとどまる。

**読み出しは PAM11 側（報酬性長期記憶）に置くしかない。**
MBON31 → PAM11 の新生シナプスが PAM-α1 の活動を抑えれば、
Ichinose 2015 の長期記憶課題で差が出ると予想できる。

## 9. MBON07 → PPL106 と同時に進める

2 つを並行して進めるのは筋が良い。

| | MBON07 → PPL106 | MBON31 → PAM11 |
|---|---|---|
| 区画 | α1（上流）→ α3（下流） | α'1（上流）→ α1（下流） |
| 伝達物質 | グルタミン酸 → ドーパミン | GABA → ドーパミン |
| 上流の系統 | MB319B〈GAL4〉 | SS52050〈GAL4〉 |
| 下流の系統 | SL86062〈LexA〉 | SL86059〈LexA〉 |
| U × D | 1 組 | 1 組 |
| 膜の密着 | 6,333 / 72%（対照の 2.44 倍） | 7,375 / 77%（2.08 倍） |
| 行動の読み出し | 上流・下流とも前例あり | 下流のみ |

- **交配は完全に独立**。4 つの系統はすべて別の細胞を狙うので、
  系統の取り合いが起きない。
- **読み出しの課題を共有できる**。どちらも Ichinose 2015 の報酬性長期記憶で読める
  （PPL106 は Jacob 2021 の pre-exposure 学習も使える）。
  同じ装置・同じプロトコルで 2 組を並べられる。
- **互いが対照になる**。MBON07 → PAM11（75 シナプス）は
  MBON31 → PAM11 の対照であり、同時に MBON07 側の「変わってはいけない結合」でもある。
  **2 組を同じ個体群で走らせると、この 1 本の結合が両方の内部対照になる。**

## 10. 残っている確認事項

1. **接触部位が両者にとって主戦場でない**（上流の出力 244 部位 / 下流の入力 248 部位）。
   分子が十分に並ぶかは実験で確かめるしかない。
2. PAM11 の GABA 入力が 4.2% と薄い。GABA-A（Rdl）の局在を見る。
3. PAM11 は左右 7 個ずつの集団なので、**どの PAM11 細胞と接しているか**を
   標本で確認する（hemibrain では 482762280 ほか複数と接触）。
4. MBON31 の行動実験の前例が無い。SS52050 で CsChrimson を駆動したときの
   ベースラインの行動を先に取っておくと、解釈がしやすい。
