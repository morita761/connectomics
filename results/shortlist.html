最終候補 — 3 個体で確かめた組（306 組）

hemibrain（雌・右半球）・male-cns（雄・全神経系）・FlyWire（雌・全脳）の 3 個体すべてで両方向のシナプスが 0 だった組。人工分子でシナプスを作らせる実験を想定した並び。
別個体での接触と接触領域まで確認した組に判定を付けている（「接触未確認」はこれから調べる分）。 上流と下流に別の分子を入れるには 2 つの発現系（GAL4 と LexA）が要るので、そこを判定の軸にしている。

判定の意味
  • ◎ … 上流と下流に別々の発現系（GAL4 と LexA）がそろい、両者がその領域で働いている … 上流と下流に別の人工分子を入れられる
  • ○ … 両側にドライバーはあるがどちらも GAL4。2 つ目の発現系（LexA・QF など）を作る必要がある
  • △ … 片側しかドライバーが無い、または無い
  • 要注意 … 上流がその領域でほとんど出力していない（放出できない場所での接触）
  • 接触未確認 … 別個体での接触をまだ計算していない

「上流出力 / 下流入力」は主な接触領域にある上流のシナプス前部位と下流のシナプス後部位の個数。 どちらも多いほど「通り道が重なっているだけ」ではない。
「比較」は同じ下流タイプに結合している別の上流タイプとその密度（シナプス/µm）。ここが大きいほど「結合できるのにしていない」と言える。
