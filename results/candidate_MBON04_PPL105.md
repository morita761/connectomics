# 本命候補: MBON04 ↔ PPL105（キノコ体案）

キノコ体の細胞どうしで人工分子によるシナプス強制形成を行うときの第一候補。2026-11-10 時点の調査をまとめる。

- **MBON04** = MBON-β'2mp_bilateral（キノコ体 β'2 区画の出力ニューロン、左右 1 個ずつ、グルタミン酸）
- **PPL105** = PPL1-α'2α2（α'2/α2 区画に投射するドーパミンニューロン、左右 1 個ずつ）
- **接触** hemibrain で 92.6 µm（MBON04 → PPL105 の向き）/ 82.9 µm（逆向き）
- **別個体（male-CNS）** 左右両半球で 32.9 / 37.8 µm — この調査全体で最も再現性が高い
- **シナプス** 3 個体・両方向すべて 0

**この組の最大の特徴は、同じ 2 細胞で両方向とも条件を満たすこと。**
向きを変えた対照実験を同一の細胞対で組める候補は、全探索でここだけだった。

## 1. なぜこの組か（「機械は揃っているのに、この相手だけ結合しない」）

PPL105 は MBON と盛んに結合しており、MBON04 は DAN と盛んに結合している。
それでも **MBON04 と PPL105 のあいだだけが 0** である。

### MBON → PPL105 の向き

| 組 | 接触 | シナプス | 1 µm あたり |
|---|---|---|---|
| **MBON04 → PPL105** | 92.6 µm | **0** | **0.000** |
| MBON06 → PPL105 | 563.9 µm | 102 | 0.181 |
| MBON15-like → PPL105 | 357.7 µm | 27 | 0.075 |
| MBON11 → PPL105 | 350.6 µm | 19 | 0.054 |
| MBON18 → PPL105 | 1824.7 µm | 17 | 0.009 |

### PPL105 → MBON の向き

| 組 | 接触 | シナプス | 1 µm あたり |
|---|---|---|---|
| **PPL105 → MBON04** | 82.9 µm | **0** | **0.000** |
| PPL105 → MBON13 | 2803.5 µm | 609 | 0.217 |
| PPL105 → MBON18 | 3904.2 µm | 449 | 0.115 |
| PPL105 → MBON19 | 2737.9 µm | 167 | 0.061 |

PPL105 は MBON 全般に **1,685 シナプス / 13 タイプ**を出し、MBON から **194 シナプス / 8 タイプ**を受けている
（hemibrain）。MBON04 はその両方のリストに入っていない。

### 決定的な対照: PPL107 は同じ細胞と両方向で結合している

PPL107 は PPL105 と**同じ PPL1 クラスター・同じ細胞体繊維（PDL05）**のドーパミンニューロンである。

| | hemibrain | male-CNS |
|---|---|---|
| MBON04 → PPL107 | **739** | **671** |
| PPL107 → MBON04 | **450** | **265** |
| MBON04 → PPL105 | **0** | **0** |
| PPL105 → MBON04 | **0** | **0** |

MBON04 が DAN 全般に出す出力は 1,230 シナプス / 20 タイプ、DAN 全般から受ける入力は
4,673 シナプス / 26 タイプ（hemibrain）。**「MBON04 が PPL1 の DAN と結合できない」わけではない。**
欠落はこの 1 組に限られる。

強制形成が成功したときの目標値は、近接から計算した期待値で
**MBON04 → PPL105 が 2.8 シナプス、PPL105 → MBON04 が 6.5 シナプス**。
PPL105 → MBON04 の向きは統計的にも有意な欠落（Poisson 検定 p = 0.0015）。

## 2. 伝達物質がかみ合う（両方向とも受容体がある）

| | 伝達物質 | 根拠 |
|---|---|---|
| MBON04 | **グルタミン酸** | male-CNS の consensusNt（予測も一致） |
| PPL105 | **ドーパミン** | 同上 |

重要なのは、**どちらの細胞も相手の伝達物質の入力をすでに受けていること**（male-CNS）。

| 受け手 | 入力の総数 | 内訳 |
|---|---|---|
| **PPL105** | 17,272 | アセチルコリン 83.3% / **グルタミン酸 10.1%（約 1,740 シナプス）** / ドーパミン 3.0% / GABA 2.7% |
| **MBON04** | 20,894 | アセチルコリン 56.8% / グルタミン酸 19.6% / GABA 10.3% / **ドーパミン 9.8%（約 2,050 シナプス）** |

- PPL105 のグルタミン酸入力は LHMB1 (292)、SMP086 (242)、SLP103 (193) など。
  → グルタミン酸受容体がある状態なので、MBON04 → PPL105 の新生シナプスは機能しうる。
- MBON04 のドーパミン入力は PAM05 (727)、PAM06 (677)、PPL107 (265) など。
  → ドーパミン受容体がある状態なので、PPL105 → MBON04 の新生シナプスも機能しうる。

ハエのグルタミン酸作動性 MBON は GluClα を介して**抑制性**に働くことが多い。
MBON04 → PPL105 は「DAN を抑える」入力、PPL105 → MBON04 は「MBON の出力を調節する」入力になると予想される。

## 3. 接触部位は「軸索終末 × 樹状突起」

### 細胞ごとの接触（hemibrain、MBON04 → PPL105 の向き）

| 上流 | 下流 | 接触 |
|---|---|---|
| MBON04_R (487925063) | PPL105_R (5813019513) | **56.7 µm** |
| MBON04_L (613079053) | PPL105_L (642516892) | 23.0 µm |
| MBON04_L | PPL105_R | 12.8 µm |
| MBON04_R | PPL105_L | 1.9 µm |

**4 通りの細胞の組み合わせすべてで接触している。** MBON04 が左右両方に投射する bilateral な細胞なので、
同側・対側の両方で出会う。同一個体の中でも 4 回再現していることになる。

### 領域の内訳

```
接触の場所         SIP(R) 97%, SMP(R) 2%, CRE(R) 1%
MBON04 の出力      SIP(R) 53%, SMP(R) 27%, CRE(R) 19%, SLP(R) 1%
PPL105 の入力      a2(R) 35%, a'2(R) 24%, SIP(R) 20%, SMP(R) 14%
PPL105 の出力      a2(R) 45%, a'2(R) 35%, SIP(R) 9%, a'1(R) 6%
主領域 SIP(R) での数   MBON04 の出力部位 538 / PPL105 の入力部位 1,380
```

接触は **SIP(R)** で起きている。MBON04 の軸索終末域の最大の領域（53%）であり、
PPL105 が樹状突起入力を受ける 3 番目の領域（20%、1,380 の後シナプス部位）でもある。
**両者が「出す側」「受ける側」として機能している場所で接している。** 通り道が偶然重なっただけではない。

なお接触はキノコ体のローブの**外**（SIP）である。MBON の軸索と DAN の樹状突起が出会う場所は
構造上ローブの外なので、MBON ↔ DAN の組はすべてこうなる。

## 4. ドライバー（発現系が 2 つそろう）

| 役割 | 系統 | 発現系 | 標識する型 | 特異性 | 出典 |
|---|---|---|---|---|---|
| MBON04 側 | **SL86063** | split-LexA | MBON01, MBON03, MBON04 | 2（理想） | Shuai 2024 eLife 94168 |
| PPL105 側 | **SS48817** | split-GAL4 | FB2A, PPL105 | 1 | 同上 |
| PPL105 側（代替） | MB059B | split-GAL4 | PPL105 (+ PPL103 が確率的) | 1 | 同上 |

MBON04 を単独で標識する split-GAL4（SS67728 / SS67755）はいちばんきれいだが、
それを使うと PPL105 側に GAL4 を回せない。PPL105 に LexA が無いので、**MBON04 側を LexA にする**構成しかない。
上流を MBON04、下流を PPL105 にする場合も逆向きの場合も、系統の組み合わせは同じ。

### 混同の確認（U × D がすべて 0 か）

上流ドライバーが標識する型の集合を U、下流ドライバーの集合を D としたとき、
**U × D の全組が 0** でなければ基準値が 0 にならない。

U = {MBON01, MBON03, MBON04}。

| D の中身 | hemibrain | male-CNS | 判定 |
|---|---|---|---|
| PPL105（目標） | 0 / 0 / 0 | 0 / **3** / 0 | ほぼ 0 |
| **FB2A**（SS48817 の相方） | **0 / 0 / 0** | **0 / 0 / 0** | **完全に 0** |
| PPL103（MB059B の確率的な相方） | 2 / 3 / 0 | **17** / 0 / 0 | 要注意 |

（数字は MBON01 / MBON03 / MBON04 の順。両方向の合計）

**SS48817 を使うのが正解。** FB2A は MBON01・MBON03・MBON04 のいずれとも 2 個体で完全に 0 なので、
U × D が全部 0 になる。MB059B は PPL105 単独に見えるが、PPL103 に確率的な発現があり
（Shuai 2024 の記載）、MBON01 → PPL103 が male-CNS で 17 シナプスある。これは基準値を汚す。

逆向き（PPL105 → MBON04）に使う場合も同じ系統で、U と D が入れ替わるだけなので同じ結論。

## 5. EM で確認した: 膜は直接向かい合っていて、グリアは挟まっていない

「接触」は骨格どうしが 1 µm 以内という近接判定なので、隙間にグリアの突起が入っている可能性が残る。
hemibrain のセグメンテーション（8 nm 等方、全ボクセルに物体 ID が付く）を
320×320×160 voxel 切り出して実体を数えた。

| 部位 | 直接隣接するボクセル | 間に何も無い表面点 |
|---|---|---|
| **MBON04 → PPL105（0 シナプス）** | **6,140** | **70%** |
| **PPL105 → MBON04（0 シナプス）** | **6,180** | **68%** |
| MBON04 → PPL107（739 シナプスある対照） | 7,871 | 63% |
| MBON04 → PPL107（対照、別の測定点） | 6,017 | 69% |
| PPL107 → MBON04（450 シナプスある対照） | 4,512 | 83% |
| PPL107 → MBON04（対照、別の測定点） | 4,285 | 83% |

**シナプスが 0 の組と、同じ細胞で 739 シナプスある組が、膜の密着度では区別できない。**
これは全脳の本命 MBON04 → FB4N（2,080 voxel / 56%）より明確な結果である。

膜（メッシュ）どうしの距離も測った: 50 nm 以内の頂点 5、100 nm 以内 20、200 nm 以内 143、500 nm 以内 575。
対照の MBON04 ↔ PPL107 は 50 nm 以内 126、100 nm 以内 673 で、対照のほうが広い面で近接しているが、
最接近部では両者とも隙間 0 nm（直接隣接）である。

### 間に入っていた物体

最良の測定点（voxel 16838, 26628, 11118）で、A と B のあいだに挟まっていた物体:

| 物体 ID | 正体 | 切り出し内の体積 |
|---|---|---|
| 796500184 | neuPrint に未登録の断片 | 0.044 µm³ |
| 5813021535 | **SLP230**（トレース済みの普通のニューロン、pre 2060 / post 3504） | 0.037 µm³ |
| 796500068 | 未登録の断片 | 0.019 µm³ |
| 796500193 | 未登録の断片 | 0.004 µm³ |
| 796500221 | 未登録の断片 | 0.002 µm³ |
| 796841381 | 未登録の断片 | 0.002 µm³ |

逆向きの測定点では CRE105（トレース済み、pre 492 / post 1995）などが現れた。
**名前の付いた普通のニューロンか、0.002〜0.044 µm³ の微小断片だけ。**
グリアのような膜の鞘があれば、正体不明の大きな物体として現れるはずだが、それが無い。

**結論: 結合が無いのは物理的な隔たりのせいではなく、分子的な理由である。**

## 6. 同じ動物の中に対照が置ける

強制形成の効果を測るとき、同じ脳の中に「変わってはいけない結合」が必要になる。
この組は対照の質が特に高い。

| 対照 | シナプス | 性質 |
|---|---|---|
| **MBON04 → PPL107** | 739 | **下流だけ違う。上流は同じ細胞・同じドライバー** |
| **PPL107 → MBON04** | 450 | **上流だけ違う。下流は同じ細胞・同じドライバー** |
| PPL105 → MBON13 | 609 | 上流は同じ細胞。下流だけ違う |
| MBON06 → PPL105 | 102 | 下流は同じ細胞。上流だけ違う |

PPL107 は PPL105 と同じクラスターなので、**同じ種類の細胞・同じ場所・同じ伝達物質**でありながら
片方は結合し片方は 0 という、理想的な内部対照になる。
染色・検出効率の個体差の正規化にも使える。

## 7. 読み出し

- 下流が DAN なので、**キノコ体の学習課題がそのまま使える**。
  PPL105 (PPL1-α'2α2) は α'2/α2 区画のドーパミン入力で、嫌悪記憶の形成・保持の文脈で
  繰り返し扱われてきた区画である。
- PPL105 → MBON04 の向きが成立すると、PPL105 が MBON04（β'2mp）の出力を直接調節する
  経路が新しくできる。MBON04 は PAM05/PAM06 から強いドーパミン入力を受けており
  （727 / 677 シナプス）、そこに別区画の DAN からの入力が加わる構成になる。
- MBON04 → PPL105 の向きが成立すると、β'2 の出力が α'2/α2 の DAN を抑える
  フィードバック経路が増える。MBON → DAN のフィードバックは記憶の更新・消去に
  関わると考えられている回路なので、1 本足す意味がある。
- 行動の読み出しは T 迷路の嗜好指数（Preference Index）と、
  光遺伝学で DAN を駆動したときの PI の変化。既に設計済みの PAM / PPL1 の
  競合実験（条件 A: 嫌悪、B: 報酬、C: 両方 → PI ≈ 0）が陽性対照として使える。

文献の裏付けは `results/literature/summary.md` と `results/refs_top_pairs.md` を参照。

## 10. 残っている確認事項

1. SS48817 の FB2A 側の発現が、使う効果器で問題にならないか（FB2A は扇状体 2 層の接線ニューロン）。
2. MB059B を使う場合、PPL103 への確率的発現を実際の標本で確認して除外できるか。
3. 導入する分子の向き（どちらを前側・後側にするか）。両方向が候補なので、
   同じ 2 細胞で向きを入れ替えた 2 系統を作れる。
4. グルタミン酸受容体のサブタイプ（GluClα か）と、ドーパミン受容体（Dop1R1/Dop1R2）を
   踏まえた生理の読み出し設計。
