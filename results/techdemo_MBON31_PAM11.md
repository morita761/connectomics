# 技術実証に MBON31 → PAM11 を選ぶ理由

2026-11-22。候補そのものの評価は [candidate_MBON31_PAM11.md](candidate_MBON31_PAM11.md)。
このページは **「人工接着分子が働いたことを行動で示す」という目的に限って**、
なぜこの組が最適かと、どう測るか。

- **MBON31** = MBON-α'1a（**GABA**、左右 1 個ずつ）
- **PAM11** = PAM-α1（ドーパミン、左右 7 個ずつの集団）
- シナプスは 3 個体・両方向すべて 0。接触 25.2 µm。**膜の密着は全候補で最高**

## 0. 要点 — 「技術が働いた」と言うのに必要な 5 条件

配線を足したこと**以外では説明できない**行動の差が要る。それには 5 つ揃う必要がある。

| 条件 | MBON31 → PAM11 | MBON04 → PPL105 |
|---|---|---|
| ① 下流に受容体が確実にある | **◎ GABA 入力 659 シナプス。Rdl は成虫ニューロンの 83% が出している** | ○ グルタミン酸入力 1,770。GluClα は 40% |
| ② 上流を混同なく光で駆動できる | **◎ SS52050 は MBON31 のみ。混同 0** | △ SL86063 は MBON01/03 も標識 |
| ③ 下流の行動の読み出しが確立している | **◎ PAM-α1 は報酬性 LTM に必須。時間窓まで分かっている** | △ PPL105（α'2α2）は確立度が低い |
| ④ 予測の向きが一つに決まる | **◎ GABA は Rdl でも GABA-B でも抑制** | ○ GluClα（抑制）か Nmdar（興奮）か決まらない |
| ⑤ 対照が同じ動物に置ける | ◎ MBON07→PAM11、MBON31→PAM06 | ○ |
| 膜の密着（EM） | **◎ 7,375 voxel / 77%、対照の 2.08 倍。全候補で最高** | ○ 6,140 / 70%、比 0.78 |

**③ と ④ が決定的。** ほかの候補は「差が出たら嬉しいが、出なかった理由がいくらでもある」。
この組は **差が出る向きと時間窓まで先に書ける。**

④ の根拠: グルタミン酸はイオン型の GluClα（抑制）とイオン型 Nmdar/KaiR1D（興奮）の
どちらが乗るかで符号が反転する。GABA は Rdl（GABA-A、抑制）でも
GABA-B（代謝型、抑制）でも**抑制**。
符号が反転しない伝達物質は GABA だけ（[receptor_check.md](receptor_check.md) 1 節）。

## 1. ゼロ結合のペアは、実は技術実証にいちばん向いている

ここが核心で、このプロジェクト全体の論理でもある。

対照（オーガナイザー無し）の個体で上流を光で叩いても、
**下流には何も届かない。結合が 0 だから。**

既存の結合を強める実験では「元の結合の効果」と「足した分の効果」を切り分けられない。
0 から作る実験では **ベースラインが構造的にゼロ**なので、
**差がそのまま新生シナプスの効果**になる。

「近接しているがシナプスが無い組」を探してきたのは、
強制形成しやすいからだけでなく、**対照が自動的に手に入るから**でもある。

## 2. 設計 — 常時ある配線に、光で時間解像度を与える

### 問題

強制シナプスは**常時ある**。発生期から PAM-α1 が抑えられていると、
行動の差が「記憶の障害」なのか「発生の異常」なのか分からない。

### 解決

**配線は常時、駆動は光で。**

Ichinose 2015 は **訓練直後 1 時間**を PAM-α1 が必要な窓として同定している
（22 時間後の阻害は効かない）。そこに光刺激を合わせる。

1. 糖報酬で **spaced training**（間隔をおいた反復訓練。報酬性 LTM の標準手順）
2. **訓練直後 1 時間だけ** MBON31 を CsChrimson で駆動
3. **24 時間後**に記憶を測る
4. 同じ個体群で **3 分後の短期記憶**も測る（3 節で効く）

### 予測

| | 光なし | **訓練後 1 時間だけ光** |
|---|---|---|
| オーガナイザーなし | 正常 LTM | 基準 |
| **オーガナイザーあり** | 正常 LTM | **LTM が落ちる** |

左の列が両方正常であることが重要。
**配線を作っただけでは行動は変わらず、駆動したときだけ変わる** —
これが「新生シナプスが機能している」の意味。

## 3. 唯一の交絡 — MBON31 は他の PAM にも出力している

MBON31 → DAN は **17 タイプ・271 シナプス**。PAM06 96、PAM05 69、PAM08 36、PAM02 21…
**PAM11 だけが 0**（だから候補になった）。

つまり MBON31 を光で叩くと、**既存の PAM05/06/08 への抑制も起きる。**
オーガナイザー無し + 光の対照でも行動が動く可能性がある。

### 対策 1: 比較は 2×2 の差分

同じ光条件でオーガナイザーの有無を比べる。既存の出力は両群に共通なので打ち消える。

### 対策 2: 短期記憶と長期記憶を両方測る — これが効く

**PAM-α1 は長期記憶に必須で、短期記憶には不要**（Ichinose 2015）。
一方 MBON31 の既存の相手である PAM05・PAM06 は β'2・γ4 区画で、**短期記憶の側**。

| 観察 | 説明 |
|---|---|
| STM も LTM も落ちる | 既存の PAM05/06 への抑制。**交絡** |
| **STM は変わらず LTM だけ落ちる** | **PAM-α1 だけが新しく抑えられた。新生シナプスの署名** |

**「どの記憶が落ちるか」まで予測が決まる。** 交絡では説明できない。
これが ④ の中身で、この組を推すいちばんの理由。

## 4. 行動の前に取る生理

| 役割 | 構成 |
|---|---|
| 上流 | **GAL4 ＞ UAS-オーガナイザー前側 ＋ UAS-CsChrimson** |
| 下流 | **LexA ＞ LexAop-オーガナイザー後側 ＋ LexAop-GCaMP6f** |

効果器をオーガナイザーと同じドライバーに相乗りさせれば **2 系統で足りる**。
QF2/QUAS の第 3 系は不要。

- MBON31 を光刺激 → PAM11 の GCaMP が **下がる**（GABA 抑制）
- オーガナイザー無しでは **動かない**

**これが取れた時点で「できた」。** 行動はその上の話。

注: PAM11 は左右 7 個ずつの集団で、hemibrain で MBON31 と接しているのは一部
（482762280 ほか）。**どの PAM11 細胞が応答するかを個別に記録すべき。**
接していない PAM11 細胞が**同じ視野の中の内部対照**になる。これは集団であることの利点。

## 5. 弱点

| | 中身 | 技術実証への影響 |
|---|---|---|
| 1 | 接触 25.2 µm は候補中で最短に近い。期待値 0.77 シナプス → 「0 であること」の意外さは小さい | **不利ではない。**「生物学的に欠落している」の主張は弱まるが、技術実証には関係ない |
| 2 | 接触領域 SMP(R) が両者の主戦場でない（上流の出力 244 部位 / 下流の入力 248 部位） | **リスク。** 分子が十分に並ぶかは実験で確かめるしかない |
| 3 | PAM11 の GABA 入力が 4.2%（659 シナプス）と薄い | 小。受容体はあるが密度は低い |
| 4 | **MBON31 の行動実験の前例が 0 本** | **要対策。** SS52050 × CsChrimson のベースライン行動を先に取る |
| 5 | PAM11 が集団なので、接していない細胞がノイズにもなる | 4 節のとおり内部対照にも使える |

**短い接触で作れたなら、むしろ技術の強さの証明になる。**
1 は候補としての弱点だが、技術実証という目的では逆に働く。

## 6. 交配

| 役割 | 系統 | 発現系 | 標識する型 |
|---|---|---|---|
| 上流 | **SS52050** | split-GAL4 | **MBON31 のみ** |
| 上流（代替） | SS80896 | split-GAL4 | MBON31 のみ |
| 下流 | **SL86059** | split-LexA | **PAM11 のみ** |
| 下流（代替） | SL86053 / SL86060 | split-LexA | PAM11 のみ／+PAM05 が稀に |
| 効果器（上流） | UAS-オーガナイザー前側 ＋ UAS-CsChrimson | | |
| 効果器（下流） | LexAop-オーガナイザー後側 ＋ LexAop-GCaMP6f | | |

**U = {MBON31}、D = {PAM11}。U × D は 1 組だけ。** 混同が原理的に存在しない。
これは MBON04 ↔ PPL105（MBON01・MBON03 が乗る）に対する明確な優位点。

対照は **オーガナイザー前側を結合しない変異体に差し替える**のが最も強い。
系統構成が同一なので、発現量も挿入位置も揃う。

## 7. MBON04 → PPL105 との役割分担

| | **MBON31 → PAM11** | **MBON04 → PPL105** |
|---|---|---|
| 目的 | **技術が働くことを示す** | **回路の意味を問う** |
| 読み出し | 報酬性 LTM の低下（向きも時間窓も既知） | 消去の加速・嫌悪 LTM の低下 |
| 予測の強さ | 強い | 中 |
| 混同 | **無い** | MBON01・MBON03 が乗る |
| 膜の密着 | **7,375 / 77%（対照の 2.08 倍）** | 6,140 / 70%（比 0.78） |
| 接触の長さ | 25 µm（短い） | **162 µm（長い）** |
| 伝達物質の符号 | **GABA = 抑制で確定** | グルタミン酸は未確定 |

**先に MBON31 → PAM11 で技術を立て、MBON04 → PPL105 で回路を問う** のが素直。
行動課題は両方 T-maze 系なので、装置とプロトコルを共有できる。

## 8. 前例

### PAM11 = PAM-α1 — 前例が十分にある

- Ichinose T, Aso Y, Yamagata N, Abe A, Rubin GM, Tanimoto H (2015)
  *eLife* 4:e10719 [10.7554/eLife.10719](https://doi.org/10.7554/eLife.10719)
  — **MB299B で PAM-α1 を阻害**。訓練直後 1 時間の阻害で報酬性長期記憶が損なわれ、
  22 時間後の阻害では損なわれない。**2 節の時間窓の根拠。**
- Takemura SY, et al. (2017) *eLife* 6:e26975
  [10.7554/eLife.26975](https://doi.org/10.7554/eLife.26975)
  — MB043C × CsChrimson で PAM-α1 を光駆動。
- Yamagata N, et al. (2022) *Front Behav Neurosci*
  [10.3389/fnbeh.2022.986064](https://doi.org/10.3389/fnbeh.2022.986064)
  — PAM-α1 特異的な CCHa2-R ノックダウンで長期記憶特異の障害。

### MBON31 = MBON-α'1a — 前例が無い

論文 15 本を検索して、行動実験の根拠となる記述は **0 本**。
系統 SS52050 / SS80896 の出所は Rubin GM, Aso Y (2024) *eLife*
[10.7554/eLife.90523](https://doi.org/10.7554/eLife.90523) で、形態と系統の記載にとどまる。

**だから 5 節の 4 が要対策。** ただし技術実証では
「上流に前例が無い」ことは弱点になりにくい。読み出しは下流（PAM-α1）に置くから。

関連論文の全体は [refs_top_pairs.md](refs_top_pairs.md)。

## 9. 残っている確認事項

1. ~~Sns / Hbs が近傍に無いか~~ → **済み。ニューロンで 3〜8% しかなく、無い。**
   ただし **内在 Kirre はニューロンの 55% にあった**ので、
   **Sns/Hbs を載せた細胞が周囲の内在 Kirre に掴まれる危険**が残る。
   対策は直交化か、片側だけの対照（[receptor_check.md](receptor_check.md) 2.5 節）。
   **構築の設計段階の判断で、この組に固有の問題ではない。**
2. 接触部位が両者にとって主戦場でない（上流 244 / 下流 248 部位）
3. SS52050 × CsChrimson のベースライン行動
4. どの PAM11 細胞が接しているかを標本で確認
5. **片側だけの対照**（下流に Sns/Hbs のみ、Kirre はどこにも入れない）を
   2 節の 2×2 に 1 群足す。内在 Kirre による余計な接着を直接測れる
