# 受容体と Kirre・Dsyd-1 をどう確認するか

2026-11-22。[direction_MBON04_PPL105.md](direction_MBON04_PPL105.md) 6 節で
「先に片付けるべきこと」と書いた受容体チェックを実際にやった。

**結論から言うと、問いと道具が逆だった。**

| 問い | 性質 | 解ける道具 |
|---|---|---|
| 下流に受容体があるか | **サブタイプ別**の問い | scRNA-seq では解けない。**コネクトームで解ける** |
| Kirre・Sns・Hbs・Dsyd-1 があるか | **クラス単位**の問い | **scRNA-seq で解ける** |

そして受容体は **全候補すでに合格していた。**

## 1. 受容体 — コネクトームが答えになっている

下流の細胞が「その伝達物質のシナプスをすでに何百本も受けている」なら、
**受容体は必ずある。** 新しく作る入力と同じ種類の入力を、その細胞はもう使っている。

male-cns:v1.0 で、各下流細胞の入力を上流の伝達物質別に数えた。

| 組 | 上流の伝達物質 | 必要な受容体 | 下流がすでに受けている同種の入力 | 判定 |
|---|---|---|---|---|
| **MBON31 → PAM11** | GABA | GABA-A (Rdl) / GABA-B | **659 シナプス（4.2%）** | ○ |
| **MBON04 → PPL105** | グルタミン酸 | GluClα / DmGluRA | **1,770（10.2%）** | ◎ |
| MBON07 → PPL106 | グルタミン酸 | 同 | 1,970（11.5%） | ◎ |
| PPL105 → MBON04 | ドーパミン | Dop1R1 / Dop1R2 / Dop2R | **2,055（9.8%）** | ◎ |
| AVLP478 → DNp06 | GABA | Rdl | 8,883（21.3%） | ◎ |
| MBON04 → FB4N | グルタミン酸 | GluClα | 2,849（23.8%） | ◎ |

内訳の全体（参考）:

| 下流 | 入力合計 | ACh | グルタミン酸 | GABA | ドーパミン |
|---|---|---|---|---|---|
| PAM11 | 15,876 | 82.2% | 7.3% | **4.2%** | 4.6% |
| PPL105 | 17,272 | 83.4% | **10.2%** | 2.8% | 3.0% |
| PPL106 | 17,120 | 83.4% | **11.5%** | 2.1% | 1.3% |
| MBON04 | 20,894 | 57.9% | 19.6% | 10.4% | **9.8%** |
| DNp06 | 41,753 | 72.4% | 5.8% | **21.3%** | 0.1% |
| FB4N | 11,963 | 56.5% | **23.8%** | 13.7% | 2.4% |

**受容体はどの候補でも障害にならない。**
scRNA-seq より確実でもある。受容体の転写産物は発現量が低くて dropout しやすく、
「検出されなかった」が「無い」を意味しない。
コネクトームの入力内訳は**機能しているシナプスを数えている**ので、この弱点が無い。

### ただし残る問い

コネクトームでは**受容体の種類**が分からない。符号と時間スケールが変わる。

| 伝達物質 | 速い（イオン型） | 遅い（代謝型） |
|---|---|---|
| GABA | **Rdl**（GABA-A、抑制） | GABA-B-R1/R2/R3（抑制） |
| グルタミン酸 | **GluClα**（抑制）／ Nmdar1・KaiR1D（興奮） | DmGluRA（抑制） |
| ドーパミン | — | Dop1R1・Dop1R2（興奮寄り）／ Dop2R（抑制） |

**グルタミン酸は符号が決まらない**のが問題。GluClα なら抑制、Nmdar なら興奮。
GABA は Rdl でも GABA-B でも**抑制**なので、**MBON31 → PAM11 は符号が一つに決まる**。
これが技術実証にこの組を推す理由のひとつ
（[techdemo_MBON31_PAM11.md](techdemo_MBON31_PAM11.md) 0 節）。

## 2. Kirre と Dsyd-1 — FlyBase で分かったこと

### Kirre

**FBgn0028369 / CG3653 / kin of irre。別名 duf, dumbfounded。**
遺伝子グループは **HBS-KIRRE 接着複合体**と **SNS-KIRRE 接着複合体**。

| 証拠 | 中身 |
|---|---|
| 成虫頭部 | 質量分析でタンパク検出（Aradska 2015） |
| 成虫視葉 | レポーター P{GawB}kirre-rP298 がメデュラ M2–M4 層。蛹後期から成虫まで |
| 成虫中枢脳 | **記載が無い** |
| 単一細胞 RNA-seq | **三齢幼虫の飛翔筋前駆細胞だけ**（Zappia 2020）。成虫脳ニューロンは無し |
| Fly Cell Atlas | FlyBase の遺伝子ページには出てこない |

→ **中枢脳ニューロンではほぼ発現していないと見てよい。**
外来 Kirre の背景が低いので、接着の特異性という点では**好都合**。

**ただし確認すべきは Kirre だけではない。Kirre の結合相手は Sns と Hbs。**
近傍の細胞が Sns か Hbs を出していれば、
**外来 Kirre が意図しない相手に貼り付く。**
`sns` と `hbs` も一緒に引くべき。これが抜けると、
[driver_overlap_PPL105_MBON04.md](driver_overlap_PPL105_MBON04.md) で調べた
「ドライバーの標識範囲による混同」とは別種の交絡が残る。

### Dsyd-1

**FBgn0039883 / CG1976 / Rho GTPase activating protein at 100F。
別名 Syd-1, DSyd-1, RhoGAP100F, synapse defective-1。**

| 証拠 | 中身 |
|---|---|
| 成虫脳 in situ | **キノコ体に限局して発現**。前シナプスマーカー brp と共局在（Owald 2010） |
| 免疫染色 | 成虫キノコ体 calyx の Kenyon 細胞に、活性帯の点状シグナル（Christiansen 2011） |
| 成虫頭部 | ウエスタンで 195 kDa のタンパク |
| その他 | 胚 CNS、幼虫 NMJ、前蛹の足関節 |
| 単一細胞 RNA-seq | **記載が無い** |

→ **キノコ体系の細胞には native にある見込み。**
Dsyd-1 は前シナプスの活性帯を組み立てる因子なので、
**上流に「ある」方が都合が良い**（無いと接着しても放出部位が熟さない）。
MBON31・PAM11・MBON04・PPL105 はいずれも MB 系なので有利。

ただし Owald 2010 / Christiansen 2011 の記載は **Kenyon 細胞と calyx** についてで、
MBON や DAN で確認されたわけではない。

### どちらが「無い」と都合が良いか

| 分子 | 望ましい状態 | 理由 | 現状の見込み |
|---|---|---|---|
| **Kirre** | **両方の細胞に無い** | 外来 Kirre だけが接着を作る。背景があると特異性が落ちる | ○ 中枢脳で未検出 |
| **Sns / Hbs** | **近傍の細胞に無い** | あると外来 Kirre が余計な相手に貼る | **未確認。ここを引くべき** |
| **Dsyd-1** | **上流にある** | 活性帯を組めないと放出部位にならない | ○ 成虫 MB に発現 |

**つまり理想的な組み合わせ** — 接着分子は背景が無く、活性帯の因子は native にある。
ただし FlyBase の根拠は in situ とレポーターで、
MBON/DAN サブタイプ別には決まっていない。

## 3. scRNA-seq の引き方（クラス単位なら解ける）

### 使えるデータ

| データ | 中身 | 解像度 | 入口 |
|---|---|---|---|
| Fly Cell Atlas（head） | 成虫頭部 snRNA-seq、580k 核 / 15 組織 | >250 細胞型だが脳は広いクラス | SCope ／ flycellatlas.org |
| Davie 2018 *Cell* | 成虫脳 約 157,000 細胞 | クラスタ単位 | SCope |
| Croset 2018 *eLife* 34550 | 成虫中脳 | **KC・MBON・DAN のクラスタ注釈あり** | — |
| **Ma 2023 *Sci Adv* 9:eade8500** | TH-GAL4 で分取した DAN の scRNA-seq、9,025 細胞 / **24 の DAN クラスタ** | **DAN サブタイプに最も近い** | 本文の図 + Table S2 |

### Ma 2023 の限界（重要）

- **TH-GAL4 は PAM を 1 半球あたり 13 個しか標識しない。PAM の大半が入っていない。**
  → **PAM11 は引けない可能性が高い。**
- 名前つきサブタイプの割り当ては暫定。クラスタ 28 が
  「PPL1-α3 と PPL1-γ2α'2 に対応」とされる → **PPL106（α3）はここに入る見込み**。
  Nos を出すクラスタ 19・26 が PPL1-γ1pedc と PAM-γ5 とされる。
- 扱っている細胞表面分子は **dpr / DIP 族が中心**。
  **kirre・rst・sns・hbs は本文に出てこない。**
- 受容体も Rdl・GluCl・Dop1R1 等は本文に名前が出ない（GPCR 全般の議論のみ）。

### 引く遺伝子

| 用途 | 遺伝子 |
|---|---|
| 接着（オーガナイザー） | **kirre, rst, sns, hbs** |
| 活性帯 | **RhoGAP100F (Syd-1)**, liprin-alpha, brp, Unc-13, Rim |
| GABA 受容体 | **Rdl**, Lcch3, Grd, GABA-B-R1, GABA-B-R2, GABA-B-R3 |
| グルタミン酸受容体 | **GluClalpha**, mGluR (DmGluRA), Nmdar1, Nmdar2, KaiR1D, clumsy |
| ドーパミン受容体 | **Dop1R1, Dop1R2, Dop2R**, DopEcR |

### 公開 API は無い

- **atlasapprox**（api.atlasapprox.org）は `d_melanogaster` を持つが、
  臓器が antenna・gut・leg などで **brain / head が無い**。使えない。
- **FlyBase は scRNA-seq の値を自前で持たない。**
  EMBL-EBI の Single Cell Expression Atlas と DRscDB にリンクするだけで、
  遺伝子ページには値が出ない。
- → **SCope を手で引くのが現実的。** 自動化はできない。

## 4. scRNA-seq で決まらないときの代替 — こちらが本線

受容体も Kirre も、最終的には **in vivo のレポーターと機能**で決める方が速い。

1. **T2A-GAL4 / MiMIC-GFP ノックイン系統** — Rdl・Dop1R1・GluClα には既存の系統がある。
   ドライバーと掛けて共局在を見る。発現量ではなく「その細胞にあるか」が直接分かる。
2. **抗体染色** — Brp（nc82）は必須。新生シナプスの活性帯を見る標準。
3. **RNAi ノックダウン + 行動** — 「受容体があるか」ではなく
   「その受容体が効いているか」を直接問える。最終的な証明はこれ。
4. **そもそも生理の実験が答えになる** —
   上流 CsChrimson → 下流 GCaMP で応答が出れば、受容体は「ある」。

→ **受容体チェックは候補の順位づけに使うもので、プロジェクトを止める関門ではない。**
[direction_MBON04_PPL105.md](direction_MBON04_PPL105.md) 7 節の順番のうち、
1（受容体）は 1 節で済み、**残るのは Sns / Hbs の確認だけ**。
