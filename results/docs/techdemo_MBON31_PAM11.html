技術実証に MBON31 → PAM11 を選ぶ理由

2026-11-22。候補そのものの評価は candidate_MBON31_PAM11.md。 このページは 「人工接着分子が働いたことを行動で示す」という目的に限って、 なぜこの組が最適かと、どう測るか。

  • MBON31 = MBON-α'1a（GABA、左右 1 個ずつ）
  • PAM11 = PAM-α1（ドーパミン、左右 7 個ずつの集団）
  • シナプスは 3 個体・両方向すべて 0。接触 25.2 µm。膜の密着は全候補で最高

0. 要点 — 「技術が働いた」と言うのに必要な 5 条件

配線を足したこと以外では説明できない行動の差が要る。それには 5 つ揃う必要がある。

条件 MBON31 → PAM11 MBON04 → PPL105
① 下流に受容体が確実にある ◎ GABA 入力 659 シナプス。Rdl は成虫ニューロンの 83% が出している ○ グルタミン酸入力 1,770。GluClα は 40%
② 上流を混同なく光で駆動できる ◎ SS52050 は MBON31 のみ。混同 0 △ SL86063 は MBON01/03 も標識
③ 下流の行動の読み出しが確立している ◎ PAM-α1 は報酬性 LTM に必須。時間窓まで分かっている △ PPL105（α'2α2）は確立度が低い
④ 予測の向きが一つに決まる ◎ GABA は Rdl でも GABA-B でも抑制 ○ GluClα（抑制）か Nmdar（興奮）か決まらない
⑤ 対照が同じ動物に置ける ◎ MBON07→PAM11、MBON31→PAM06 ○
膜の密着（EM） ◎ 7,375 voxel / 77%、対照の 2.08 倍。全候補で最高 ○ 6,140 / 70%、比 0.78

③ と ④ が決定的。 ほかの候補は「差が出たら嬉しいが、出なかった理由がいくらでもある」。 この組は 差が出る向きと時間窓まで先に書ける。

④ の根拠: グルタミン酸はイオン型の GluClα（抑制）とイオン型 Nmdar/KaiR1D（興奮）の どちらが乗るかで符号が反転する。GABA は Rdl（GABA-A、抑制）でも GABA-B（代謝型、抑制）でも抑制。 符号が反転しない伝達物質は GABA だけ（receptor_check.md 1 節）。

1. ゼロ結合のペアは、実は技術実証にいちばん向いている

ここが核心で、このプロジェクト全体の論理でもある。

対照（オーガナイザー無し）の個体で上流を光で叩いても、 下流には何も届かない。結合が 0 だから。

既存の結合を強める実験では「元の結合の効果」と「足した分の効果」を切り分けられない。 0 から作る実験では ベースラインが構造的にゼロなので、 差がそのまま新生シナプスの効果になる。

「近接しているがシナプスが無い組」を探してきたのは、 強制形成しやすいからだけでなく、対照が自動的に手に入るからでもある。

2. 設計 — 3 段階に分け、片側だけの対照を最初に置く

二つの問題を同時に解く必要がある。

問題 解決
強制シナプスは常時ある。発生期から PAM-α1 が抑えられていると、行動の差が「記憶の障害」なのか「発生の異常」なのか分からない 配線は常時、駆動は光で。 時間解像度を光で与える
内在 Kirre が成虫ニューロンの 55% にある。ただし周囲に Sns/Hbs が無いので掴む相手がいない（receptor_check.md 2.5 節） 片側だけの対照（群③）で確認する。関門ではない

だから A 解剖 → B 生理 → C 行動 の 3 段階にして、 内在 Kirre の問題を 段階 A（いちばん安い段階）で決着させる。

2.0 遺伝子型 — 5 群

オーガナイザーの極性は 上流に Kirre、下流に Sns/Hbs とする。 内在 Kirre には相手（Sns/Hbs）がいないので、外来 Kirre を載せる側が安全な側。 Sns/Hbs 側は避けられない弱点なので、そこに対照を当てる。

群 上流 SS52050〈GAL4〉 下流 SL86059〈LexA〉 役割
①完全 Kirre ＋ CsChrimson Sns/Hbs ＋ GCaMP 本番
②変異 結合しない変異 Kirre ＋ CsChrimson Sns/Hbs ＋ GCaMP オーガナイザーの陰性対照。 系統構成が①と同一なので発現量も挿入位置も揃う
③下流のみ CsChrimson だけ Sns/Hbs ＋ GCaMP 内在 Kirre が Sns/Hbs を掴むかを直接測る。今回の発見への対照
④上流のみ Kirre ＋ CsChrimson GCaMP だけ 外来 Kirre が内在 Sns/Hbs に貼るか。陰性が予測（Sns 8% / Hbs 3%）。予測の検算
⑤効果器のみ CsChrimson だけ GCaMP だけ 光刺激そのものの効果。 MBON31 の既存出力（3 節）の分

2.1 段階 A: 解剖 — 内在 Kirre をここで片付ける

光は使わない。①〜⑤を並べて形だけを見る。

測るもの 方法
MBON31–PAM11 間に活性帯ができたか syb-GRASP（活性帯依存）＋ Brp（nc82）
PAM11 が余計な入力を得ていないか PAM11 の後シナプス部位の総数と樹状突起の形

判定:

比較 意味
① > ② オーガナイザーが MBON31–PAM11 の接着を作った。本題の成立
③ ≒ ⑤ 内在 Kirre は効いていない。先へ進んでよい
③ > ⑤ 内在 Kirre が Sns/Hbs を掴んでいる。 段階 B に進む前に直交化する（NEPH1–nephrin などに置換）
④ ≒ ⑤ 予測どおり。外来 Kirre 側は安全

③ は念のための確認であって、関門ではない。 周囲のニューロンに Sns/Hbs が無い以上 （receptor_check.md 2.5 節）、内在 Kirre には掴む相手がいないので ③ は陰性に出るはずである。ここが陽性に出たときだけ、段階 C の前に対処する。 逆に白なら、以降の対照は②と⑤だけで足りる。

2.2 段階 B: 生理 — ①②③に光を当てる

  • MBON31 を光刺激 → PAM11 の GCaMP が 下がる（GABA 抑制）
  • ②では動かない（オーガナイザーが結合しない）
  • ③でも動かない（MBON31 側に外来 Kirre が無いので MBON31–PAM11 の接着が無い）

①だけが応答する。これが取れた時点で「できた」。 行動はその上の話。

2.3 段階 C: 行動 — 2×3

Ichinose 2015 は 訓練直後 1 時間を PAM-α1 が必要な窓として同定している （22 時間後の阻害は効かない）。そこに光刺激を合わせる。

  1. 糖報酬で spaced training（間隔をおいた反復訓練。報酬性 LTM の標準手順）
  2. 訓練直後 1 時間だけ MBON31 を CsChrimson で駆動
  3. 24 時間後に記憶を測る
  4. 同じ設計で 3 分後の短期記憶も測る（3 節で効く）

光の対照は遺伝子型を増やさずに作れる。 CsChrimson は餌の retinal（全トランスレチナール）が無いと働かない。 だから 同腹の retinal 給餌あり／なしで比べれば、遺伝子型は完全に同一になる。 遺伝的背景の差が原理的に入らないので、群を増やすより強い。

群 retinal なし（光が効かない） retinal あり ＋ 訓練後 1 時間だけ光
⑤効果器のみ 正常 STM / 正常 LTM MBON31 の既存出力の分だけ動く（STM が動きうる）
②変異 正常 STM / 正常 LTM ⑤と同じであるべき
①完全 正常 STM / 正常 LTM STM は変わらず、LTM だけ落ちる

読み方は 2 本立て。

  • 左の列が 3 群すべて正常であること — 配線を作っただけでは行動は変わらない。
  • 右の列で①だけが②・⑤から外れること — しかも LTM 選択的に（3 節）。

この二つが揃って初めて「新生シナプスが機能している」と言える。

2.4 どの段階で何が否定されるか

段階 黒が出たときの意味 次の手
A: ① ≒ ② 接着そのものが作れていない 接触 25 µm では足りない。接触の長い組（MBON04 ↔ PPL105、162 µm）へ
A: ③ > ⑤ 内在 Kirre が交絡する 直交化してから A をやり直す
B: ①が応答しない 接着はできたが放出部位になっていない Dsyd-1 の補強、または Rdl の局在を確認
C: 左の列が動く 配線を作っただけで行動が変わった（発生の影響） 成虫期に限った発現（GAL80ts など）に切り替える
C: 右の列で STM も落ちる MBON31 の既存出力による交絡 3 節。②との差分で切り分ける

A と B はどちらも行動より安く、しかも否定されたときの次の手が決まっている。

3. 唯一の交絡 — MBON31 は他の PAM にも出力している

MBON31 → DAN は 17 タイプ・271 シナプス。PAM06 96、PAM05 69、PAM08 36、PAM02 21… PAM11 だけが 0（だから候補になった）。

つまり MBON31 を光で叩くと、既存の PAM05/06/08 への抑制も起きる。 オーガナイザー無し + 光の対照でも行動が動く可能性がある。

対策 1: 比較は①と②の差分

同じ光条件でオーガナイザーの有無（①と②）を比べる。 既存の出力は両群に共通なので打ち消える。⑤はその既存の出力の分を直接測る群。

対策 2: 短期記憶と長期記憶を両方測る — これが効く

PAM-α1 は長期記憶に必須で、短期記憶には不要（Ichinose 2015）。 一方 MBON31 の既存の相手である PAM05・PAM06 は β'2・γ4 区画で、短期記憶の側。

観察 説明
STM も LTM も落ちる 既存の PAM05/06 への抑制。交絡
STM は変わらず LTM だけ落ちる PAM-α1 だけが新しく抑えられた。新生シナプスの署名

「どの記憶が落ちるか」まで予測が決まる。 交絡では説明できない。 これが 0 節の条件④の中身で、この組を推すいちばんの理由。

4. 発現系と、生理で気をつけること

効果器をオーガナイザーと同じドライバーに相乗りさせれば 2 系統で足りる。 QF2/QUAS の第 3 系は不要（2.0 節の表がその構成）。

役割 構成
上流 GAL4 ＞ UAS-Kirre ＋ UAS-CsChrimson
下流 LexA ＞ LexAop-Sns/Hbs ＋ LexAop-GCaMP6f

段階 B の判定は 2.2 節。ここでは記録のときの注意だけ。

注: PAM11 は左右 7 個ずつの集団で、hemibrain で MBON31 と接しているのは一部 （482762280 ほか）。どの PAM11 細胞が応答するかを個別に記録すべき。 接していない PAM11 細胞が同じ視野の中の内部対照になる。これは集団であることの利点。

5. 弱点

中身 技術実証への影響
1 接触 25.2 µm は候補中で最短に近い。期待値 0.77 シナプス → 「0 であること」の意外さは小さい 不利ではない。「生物学的に欠落している」の主張は弱まるが、技術実証には関係ない
2 接触領域 SMP(R) が両者の主戦場でない（上流の出力 244 部位 / 下流の入力 248 部位） リスク。 分子が十分に並ぶかは実験で確かめるしかない
3 PAM11 の GABA 入力が 4.2%（659 シナプス）と薄い 小。受容体はあるが密度は低い
4 MBON31 の行動実験の前例が 0 本 要対策。 SS52050 × CsChrimson のベースライン行動を先に取る
5 PAM11 が集団なので、接していない細胞がノイズにもなる 4 節のとおり内部対照にも使える

短い接触で作れたなら、むしろ技術の強さの証明になる。 1 は候補としての弱点だが、技術実証という目的では逆に働く。

役割 系統 発現系 標識する型

U = {MBON31}、D = {PAM11}。U × D は 1 組だけ。 混同が原理的に存在しない。 これは MBON04 ↔ PPL105（MBON01・MBON03 が乗る）に対する明確な優位点。

群①〜⑤（2.0 節）は、この 2 つのドライバーと UAS / LexAop 側の 3 通りの組み合わせで全部作れる。 ドライバーは増えないので、交配の系統数は実質 1 本（変異 Kirre）増えるだけ。

対照のとり方で強い順:

  1. オーガナイザーを結合しない変異体に差し替える（群②）。 系統構成が同一なので、発現量も挿入位置も揃う
  2. retinal の給餌あり／なし（2.3 節）。遺伝子型が完全に同一になるので、 光の対照としてはこれが最強。群を増やさずに作れる
  3. 片側だけ（群③④）。オーガナイザー自体の副作用を測る
  4. 効果器だけ（群⑤）。既存の出力の分を測る

1 と 2 を組み合わせると、遺伝的背景の差が入る余地がほぼ無くなる。

8. 前例

PAM11 = PAM-α1 — 前例が十分にある

  • Ichinose T, Aso Y, Yamagata N, Abe A, Rubin GM, Tanimoto H (2015) eLife 4:e10719 10.7554/eLife.10719 — MB299B で PAM-α1 を阻害。訓練直後 1 時間の阻害で報酬性長期記憶が損なわれ、 22 時間後の阻害では損なわれない。2 節の時間窓の根拠。
  • Takemura SY, et al. (2017) eLife 6:e26975 10.7554/eLife.26975 — MB043C × CsChrimson で PAM-α1 を光駆動。
  • Yamagata N, et al. (2022) Front Behav Neurosci 10.3389/fnbeh.2022.986064 — PAM-α1 特異的な CCHa2-R ノックダウンで長期記憶特異の障害。

MBON31 = MBON-α'1a — 前例が無い

論文 15 本を検索して、行動実験の根拠となる記述は 0 本。 系統 SS52050 / SS80896 の出所は Rubin GM, Aso Y (2024) eLife 10.7554/eLife.90523 で、形態と系統の記載にとどまる。

だから 5 節の 4 が要対策。 ただし技術実証では 「上流に前例が無い」ことは弱点になりにくい。読み出しは下流（PAM-α1）に置くから。

関連論文の全体は refs_top_pairs.md。

9. 残っている確認事項

  1. ~~Sns / Hbs が近傍に無いか~~ → 済み。ニューロンで 3〜8% しかなく、無い。 ただし 内在 Kirre はニューロンの 55% にあったので、 Sns/Hbs を載せた細胞が周囲の内在 Kirre に掴まれる危険が残る （receptor_check.md 2.5 節）。 → 群③として段階 A に組み込んだ（2.0〜2.1 節）。 構築の設計段階の判断で、この組に固有の問題ではない。
  2. 接触部位が両者にとって主戦場でない（上流 244 / 下流 248 部位）。 → 段階 A で ① ≒ ② なら、ここが原因（2.4 節）
  3. SS52050 × CsChrimson のベースライン行動。 群⑤がこれに当たるので、 段階 C と同じ個体群で取れる
  4. どの PAM11 細胞が接しているかを標本で確認（4 節）
  5. Kirre のタンパクが本当に神経の表面に出ているか。 転写産物が 55% でも、細胞外ドメインが表面に無ければ群③は陰性になる。 抗体かタグ付きノックインで見ておくと、群③の結果を解釈しやすい
