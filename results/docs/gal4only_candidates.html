両方 GAL4 しかない組のうち、行動・生理の意味があるもの

2026-11-10。対象は results/shortlist_final.csv で 「上流にも下流にも split-GAL4 はあるが、どちらにも LexA が無い」32 組。 そのうち別個体でも接触が再現し、上流もその領域で出力している 9 組を詳しく見た。

0. 結論

上位 3 組は、これまでの本命（MBON04 ↔ PPL105、MBON04 → FB4N）より 行動の読み出しがはっきりしている。

（順位は 5 節の EM を通したあとのもの）

順位 組 読み出し なぜ意味があるか
1 AVLP478 → DNp06 熱回避のナビゲーション 下行ニューロンに抑制を 1 本足す。同じ AVLP の仲間は 8,666 シナプスを送っているのに、AVLP478 だけ 0。膜の密着は対照と同等。LexA の当てもある
2 MBON30 → oviIN 産卵数（数えられる） 記憶・価数の出力を、産卵回路で唯一の抑制ハブにつなぐ。LexA の当てもある
3 MBON21 → FB4X （FB4X の行動は未報告） 膜の密着が、結合している対照の 10 倍。読み出しだけが弱い
✕ ~~PLP022 → DNp10~~ 前肢のリーチング・翅のはばたき 読み出しは良いが EM で落ちた（対照の 1/30）
5 PS161 → DNa04 飛翔中の操舵 同じ PS の仲間は 6,795 シナプスを送っているのに PS161 だけ 0
6 VES012 → DNb05 （DNb05 の行動は未報告） 下行ニューロンだが機能が未記載
7 DL4_adPN → LHPV6c1 生来の匂い行動 外側角は Dolan 2019 の行動スクリーンの枠組みが使える
8 MBON31 → SMP503 — SMP503 の素性が不明。GABA 受容体も 8.3% と薄い
✕ ~~ExR2 → LAL098~~ 覚醒・移動 EM で落ちた（対照の 1/6〜1/10。results/candidate_ExR2_LAL098.md）

下行ニューロン（DN）を下流に持つ組が有利なのは、 DN の活動変化がそのまま特定の運動として出るから。 本プロジェクトの弱点（FB4N や LAL098 に行動実験の前例が無い）を正面から埋められる。

2. 受容体はあるか、同じ仲間は結合しているか

下流が「その伝達物質をすでに受けているか」と、 「同じ接頭辞の仲間からどれだけ入力を受けているか」を male-CNS で数えた。 後者が大きいほど「その場所で結合できないわけではない」と言える。

組 下流の入力の総数 上流と同じ伝達物質の割合 同じ仲間からの入力 判定
AVLP478 → DNp06 41,753 GABA 21.2% AVLP* から 8,666 ◎ 最良
PS161 → DNa04 17,294 ACh 55.7% PS* から 6,795 ◎
PLP022 → DNp10 21,235 GABA 24.5% PLP* から 1,645 ○
MBON30 → oviIN 52,915 グルタミン酸 12.0% MBON* から 171 △
VES012 → DNb05 34,753 ACh 69.8% VES* から 669 △
MBON21 → FB4X 8,622 ACh 62.6% MBON* から 307（MBON30 → FB4X が 259） ○
DL4_adPN → LHPV6c1 6,456 ACh 54.3% DL* から 121（兄弟の DA4l_adPN が 281） ○
MBON31 → SMP503 9,772 GABA 8.3% MBON* から 117 ✕

AVLP478 → DNp06 が際立っている。 DNp06 は AVLP の細胞から 8,666 シナプスを受けており、 GABA 入力も 21.2% ある。受け皿も機構もそろっているのに、AVLP478 からだけ 0。 PS161 → DNa04 も同じ構図（PS* から 6,795 あるのに PS161 からは 0）。

3. 行動の読み出し

AVLP478 → DNp06

  • DNp06 の抑制は熱回避のナビゲーションに影響する。 Jouandet GC, et al. (2023) Rapid threat assessment in the Drosophila thermosensory system. Nat Commun 10.1038/s41467-023-42864-5 — 熱回避で、温度受容の TLHON の下流として DNp06 を遺伝的に抑えたときの ナビゲーションの表現型を調べている。
  • 新しくできるのは GABA（抑制）→ DN なので、「逃避・回避の出にくさ」として読める。
  • DNp06 の主な入力は LPLC1 (2,773)、LPLC2 (1,719)、LC4 (1,152) というルーミング検出の視覚投射ニューロン。 つまり DNp06 は視覚的な接近刺激に対する回避の出口にあたる。

MBON30 → oviIN

  • oviIN は産卵回路で唯一の抑制ニューロン。pC1 から oviDN と oviEN への フィードフォワード抑制を担い、産卵の開始を止める側にいる。 Wang F, et al. (2020) Neural circuitry linking mating and egg laying in Drosophila females. Nature 10.1038/s41586-020-2055-9
  • oviIN は複数回路の統合ハブとされ、すべての oviDN サブタイプに前シナプスを持つ。 Weber-Langstaff RA, et al. (2025) The oviposition inhibitory neuron is a potential hub of multi-circuit integration in the Drosophila brain. eNeuro 10.1523/ENEURO.0123-25.2025
  • MBON30 は記憶・価数の出力で、行動実験の前例が 6 本ある （Aso 2014 eLife 04580、Sitaraman 2015、Jacob 2021 Curr Biol ほか）。
  • 読み出しは産卵数。数えられる・時間分解能がとれる・個体あたりのサンプルが多い、という点で 本プロジェクトで最も扱いやすい指標。 「学習した匂いの価数が産卵の判断に影響するか」を、シナプスを 1 本足して問うことになる。
  • 弱点: oviIN が MBON から受ける入力は全体で 171 シナプスしかない。 「その場所で MBON と結合できる」という対照が弱い。

PLP022 → DNp10

  • DNp10 の活性化は前肢のリーチングと翅のはばたきを誘導する。 Cande J, Namiki S, Qiu J, Korff W, Card GM, Shaevitz JW, Stern DL, Berman GJ (2018) Optogenetic dissection of descending behavioral control in Drosophila. eLife 7:e34275 10.7554/eLife.34275
  • DNp10 は正面から接近する速い暗い物体によく応答する。 Ache JM, et al. (2019) State-dependent decoupling of sensory and motor circuits under anesthesia. Nat Neurosci 10.1038/s41593-019-0413-4
  • 新しくできるのは GABA → DN。ルーミングに対する反応の出にくさとして読める。

PS161 → DNa04

  • DNa04 は中心複合体から方向の情報を受け、飛翔中の操舵に関わるとされる （MANC のコネクトーム解析）。読み出しは旋回・角速度。
  • 接触は 62 µm、別個体で 10〜21 µm と上位 3 組より短い。

DL4_adPN → LHPV6c1

  • 外側角は生来の匂い行動の中枢で、Dolan MJ, et al. (2019) eLife 10.7554/eLife.43079 が 82 の LH 細胞型に対する split-GAL4 と行動スクリーンを整備している。 LHPV6c1 個別の行動データは見つからなかった。

読み出しが立たないもの

  • DNb05: 視覚の糸球体と嗅覚の糸球体の両方に投射する珍しい DN だが、行動の報告は無い。
  • FB4X: 論文 3 本のみ、行動実験の記述なし。
  • SMP503: 論文 1 本のみ。素性が不明。

4. LexA の当て

発現系が 2 つにならないのがこの 32 組の共通の弱点。 ヘミドライバー断片まで降りると、上位のうち 3 組に当てがある （results/hemidriver_lexa_report.md）。

組 LexA にする側 断片 備考
AVLP478 → DNp06 下流 DNp06 VT019018-LexA SS02256 と SS01047 という独立な 2 系統が同じ断片を AD 側に持つ
MBON30 → oviIN 下流 oviIN VT026347-LexA SS65423 の AD 側
MBON21 → FB4X 上流 MBON21 GMR11C07-LexA SS81353 の DBD 側。PAM10 も標識する（PAM10 ↔ FB4X は 0 で確認済み）
DL4_adPN → LHPV6c1 上流 DL4_adPN VT033006-LexA SS10228 と SS32214 が共有
PLP022 → DNp10 — 無し SS01049 と SS01580 が VT031084 を共有するが LexA 版が無い
PS161 → DNa04 — 無し SS02384 = GMR47D05 ∩ VT047755

AVLP478 → DNp06 と MBON30 → oviIN は、読み出しと LexA の当ての両方がそろう。

5. 膜の密着（EM）— ここで 1 組落ちる

hemibrain のセグメンテーション（8 nm 等方）を 320×320×160 voxel 切り出し、 同じ下流に実際に結合している細胞を対照に置いて数えた。

組 最接近の隙間 直接隣接 間に何も無い 膜の頂点 <50 nm 対照との比
AVLP478 → DNp06（0 シナプス） 45 nm 4,915 64% 8 0.90
└ 対照 LPLC1 → DNp06（714 シナプス） 45 nm 5,483 57% 3 —
MBON21 → FB4X（0 シナプス） 0 nm 4,119 59%（別の点で 80%） 11 10.0
└ 対照 MBON30 → FB4X（178 シナプス） 0 nm 410 27% 29 —
MBON30 → oviIN（0 シナプス） 0 nm 2,148 58% 17 0.65
└ 対照 SMP052 → oviIN（614 シナプス） 0 nm 3,293 66% 116 —
PLP022 → DNp10（0 シナプス） 45 nm 339 57% 7 0.03
└ 対照 PS088 → DNp10（188 シナプス） 0 nm 10,750 72% 37 —

判定

  • AVLP478 → DNp06 ◎ — 714 シナプスある対照とほぼ同じだけ密着している。
  • MBON21 → FB4X ◎ — 結合している対照より 10 倍密着している。 MBON30 は FB4X に 178 シナプス作っているのに密着は 410 voxel / 27% しかなく、 MBON21 は 0 シナプスなのに 4,119 voxel / 59%。接触の質では MBON21 のほうが上。
  • MBON30 → oviIN ○ — 対照の 65%。採用した他の候補（MBON04 → FB4N は 2,080）と同水準。
  • PLP022 → DNp10 ✕ — 対照の 1/30。ExR2 → LAL098 と同じ落ち方。 骨格の接触 51 µm は、膜の近さを表していなかった。

EM を通すと順位が変わる。 接触の長さでは MBON30 → oviIN（142 µm）が上だったが、 膜の密着では AVLP478 → DNp06 と MBON21 → FB4X のほうが確か。

6. 次にやること

  1. AVLP478 → DNp06 を本命として詰める。読み出し（熱回避のナビゲーション）、 特異性（AVLP* から 8,666 あるのに 0）、膜の密着（対照と同等）、 LexA の当て（VT019018、独立な 2 系統が共有）のすべてがそろう。
  2. VT019018-LexA と VT026347-LexA の標識細胞を FlyLight の画像で確定する。 断片 1 つでは U（または D）が広がるので、U × D の混同を取り直す必要がある。
  3. MBON30 → oviIN は産卵という独立した読み出しなので、 キノコ体案（学習課題）と並行して進められる。
  4. 残り 5 組（PS161 → DNa04、VES012 → DNb05、DL4_adPN → LHPV6c1、 MBON31 → SMP503、PLP022 → DNp10）は LexA の当てが無いか読み出しが弱い。 split-GAL4 → split-LexA の変換を前提にするなら PS161 → DNa04 が次点。
