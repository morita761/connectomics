# SL86063 が一緒に標識する MBON01・MBON03 は、PPL105 とどこまで近いか

2026-11-22。再現は
`python view_group.py --data data/hemibrain_mb_all.pkl --source PPL105 --others MBON04 MBON01 MBON03 --out ...`

PPL105 → MBON04 の下流ドライバー **SL86063〈split-LexA〉は MBON01・MBON03・MBON04 の
3 型を標識する**。つまり後側のシナプスオーガナイザーは 3 型すべてに乗る。
**MBON01・MBON03 が PPL105 の近くを通っていれば、そこにも意図しないシナプスができる。**
その危険がどれだけあるかを調べた。

## 0. 結論

**危険は小さい。ただしゼロではない。**

| 問い | 答え |
|---|---|
| もともと PPL105 と MBON01・MBON03 はつながっているか | **ほぼつながっていない**（3 個体で最大 3 シナプス） |
| 1 µm 以内まで近づくか | **MBON04 だけ。MBON01・MBON03 は 0 µm** |
| 3 µm まで広げると | MBON01 が 9 µm、MBON03 が 28 µm。**MBON04（1,204 µm）の 3% 以下** |
| 近づく場所は同じか | **違う。** MBON04 との接触は SIP(R) が中心、MBON01・MBON03 は SMP(R)・CRE(R) |

**1 µm（この解析で「接触」としている基準）では、PPL105 に接しているのは MBON04 だけ。**
MBON01 と MBON03 は 1 本も接していない。

## 1. もともとつながっているか — ほぼつながっていない

| 組 | hemibrain | male-CNS | FlyWire 783 |
|---|---|---|---|
| PPL105 → MBON01 | 0 | 0 | 0 |
| MBON01 → PPL105 | 0 | 0 | 0 |
| PPL105 → MBON03 | 0 | **1** | 0 |
| MBON03 → PPL105 | 0 | **3** | 0 |
| PPL105 → MBON04（目標） | 0 | 0 | 0 |
| MBON04 → PPL105 | 0 | 0 | 0 |

**6 通り × 3 個体で、0 でないのは male-CNS の MBON03 ↔ PPL105 だけ**（計 4 シナプス）。
この 2 型はコネクトームの基準（5 シナプス以上を「結合」とする）では未結合である。

**基準値は 0 のまま使える。** 強制形成でできたシナプスは、どの型からでも
「増えた分」としてそのまま数えられる。

## 2. 空間的な近さ — 細胞ごと

hemibrain の中心線どうしの距離で測った。**最短距離**は 2 細胞がいちばん近づくところ、
**接触**はその距離以内にある中心線の長さ（両側の平均）。

| PPL105 | 相手 | 最短距離 | 接触 1 µm | 接触 3 µm | 接触 5 µm |
|---|---|---|---|---|---|
| PPL105_R | **MBON04_R** | **0.12 µm** | **84.8 µm** | 631.2 µm | 1,217.9 µm |
| PPL105_R | **MBON04_L** | **0.08 µm** | **46.2 µm** | 284.4 µm | 661.8 µm |
| PPL105_L | **MBON04_L** | **0.12 µm** | **29.5 µm** | 252.7 µm | 518.0 µm |
| PPL105_L | **MBON04_R** | 0.79 µm | 1.9 µm | 35.8 µm | 154.2 µm |
| PPL105_R | MBON01_R | 1.36 µm | **0** | 9.1 µm | 35.6 µm |
| PPL105_R | MBON03_L | 1.69 µm | **0** | 28.4 µm | 125.7 µm |
| PPL105_R | MBON03_R | 4.52 µm | **0** | 0 | 7.0 µm |
| PPL105_L | MBON03_R | 5.54 µm | **0** | 0 | 0 |
| PPL105_L | MBON01_R | 6.43 µm | **0** | 0 | 0 |
| PPL105_L | MBON03_L | 9.72 µm | **0** | 0 | 0 |

型でまとめると:

| 相手 | 接触 1 µm | 接触 3 µm | MBON04 に対する比（3 µm） |
|---|---|---|---|
| **MBON04**（目標） | **162.4 µm** | **1,204.2 µm** | — |
| MBON01 | **0 µm** | 9.1 µm | **0.8%** |
| MBON03 | **0 µm** | 28.4 µm | **2.4%** |

**MBON04 は PPL105 と 0.08〜0.12 µm まで接するのに対し、MBON01・MBON03 は
いちばん近いところでも 1.4〜1.7 µm 離れている。** 桁が違う。

シナプス間隙は約 20 nm（0.02 µm）なので、**1.4 µm は「シナプスができる距離」ではない**。
人工分子は膜どうしを架橋するもので、1 µm 以上の隙間を埋めることはできない。

## 3. 近づく場所も違う

接触点がどの脳領域にあるかを数えた。

| 組 | 1 µm 以内の点の場所 | 3 µm 以内の点の場所 |
|---|---|---|
| PPL105 × MBON04 | SIP(R) 41%, SMP(R) 31%, CRE(R) 10% | SIP(R) 47%, SMP(R) 25%, CRE(R) 5% |
| PPL105 × MBON01 | （接触なし） | **SMP(R) 100%** |
| PPL105 × MBON03 | （接触なし） | **SMP(R) 54%, CRE(R) 45%** |

**狙っている接触の主戦場は SIP(R)**（MBON04 の軸索終末と PPL105 の樹状突起が重なる場所）。
MBON01・MBON03 が PPL105 に近づくのは SMP(R) と CRE(R) で、**別の場所**である。

ただし MBON04 との接触も SMP(R) に 25〜31% あるので、
**SMP(R) では 3 つの MBON がいずれも PPL105 の数 µm 以内を通っている**ことになる。
ここが唯一の注意点。

## 5. どう読むか

### 使ってよい理由

1. **1 µm 以内で接しているのは MBON04 だけ。** 人工分子が働く距離（シナプス間隙 20 nm 程度）で
   考えれば、MBON01・MBON03 は候補にすら入らない。
2. **もともとの結合がほぼ 0** なので、基準値が汚れない。増えた分がそのまま効果になる。
3. 近づく場所が違う（SIP 対 SMP・CRE）。

### それでも残る注意点

1. **SMP(R) では 3 型とも PPL105 の数 µm 以内を通る。** 1 µm 以内ではないが、
   突起は個体ごとに少しずつ違うので、個体によっては接触する可能性がある。
   **実験後に SMP(R) で MBON01・MBON03 と PPL105 のシナプスが増えていないかを確認すべき。**
2. hemibrain は右半球だけで、MBON01 は 1 細胞しか入っていない。
   左側の MBON01 は測れていない。male-CNS で測り直すと確度が上がる。
3. これは**中心線（骨格）どうしの距離**で、膜どうしではない。
   MBON04 については EM で膜の密着を確かめた（6,180 voxel / 68%）が、
   MBON01・MBON03 については測っていない。1 µm 以内の接触が無いので
   測る意味は薄いが、SMP(R) の近接部を 1 点だけ測れば完全に片が付く。

### 逆向き（MBON04 → PPL105）でも同じ

接触は向きを持たないので、この表はそのまま逆向きにも使える。
逆向きでは SL86063 が**上流**に来るので、前側のオーガナイザーが MBON01・MBON03 に乗る。
やはり 1 µm 以内で PPL105 に接しているのは MBON04 だけなので、結論は変わらない。

なお逆向きの下流ドライバーは SS48817〈GAL4〉（FB2A + PPL105）を勧めている。
FB2A は MBON01・MBON03・MBON04 のいずれとも 2 個体で完全に 0 なので、
こちらの混同も無い（`results/candidate_MBON04_PPL105.md` 4 節）。
