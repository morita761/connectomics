近接するがシナプスを作らないニューロンの探索

ショウジョウバエのコネクトーム 3 個体（hemibrain・FlyWire・male-CNS）を突き合わせて、 膜は接しているのにシナプスが 1 つも無いニューロンのペアを探す。 人工接着分子で結合を強制的に作らせる実験の標的を選ぶのが目的。

いま進めている方針

匂いを嗅がせるだけで、本来できないはずの記憶を作る。 上流の MBON が匂いに応答し、その活動が人工シナプスを通って下流のドーパミンニューロンを駆動すれば、 電気ショックも砂糖も与えずに連合記憶ができる。これが成立すれば、 人工シナプスが感覚入力を教師信号に変換したことになる。

条件は 6 つ — 両方向でシナプス 0 ／ 3 個体で 0 ／ EM で膜が接している ／ GAL4 と LexA の 2 系統が使える ／ 上流がその場所で出力している ／ 上流が匂いで駆動される（最後の 1 つが今回加わった軸）。

どれがうまくいくか分からないので、3 組を並行して準備する。

① MBON07 → PPL106〈本命〉 6 条件すべてを満たす唯一の組。匂い駆動 86%・膜 6,333 voxel。
専用の設計ページ（解剖 → 強制活性 → 生理 → 行動） ② MBON02 → PPL106〈比較〉 下流が本命と同じ細胞。LexA 系統を共有できる。
膜は本命の 1/22 ③ MBON04 → PPL105〈保険〉 膜はいちばん確かだが匂い駆動は 20%。
