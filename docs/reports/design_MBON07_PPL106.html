匂いだけで記憶を作る: MBON07 → PPL106 の設計

2026-11-23。results/plan_three_pairs.md で第一候補に決まった組の実験設計。 解剖・遺伝学・EM の根拠は candidate_MBON07_PPL106.md にある。 ここは何をどう測るかだけを書く。

0. この組で何を主張するか

匂いを嗅がせるだけで、電気ショックも砂糖も与えずに、24 時間残る記憶を作る。

これが成立すれば、人工シナプスが感覚入力を教師信号に変換したことになる。 強制活性ではなく自然な刺激で動くので、「配線を足したら脳が新しい計算をした」と言える。
上流 MBON07 = MBON-α1。グルタミン酸。入力の 86% が KC
下流 PPL106 = PPL1-α3。ドーパミン。α3 区画に 1,955 の出力
接触 SLP(R) 70%、SIP(R) 30%。37 µm（hemibrain）、左右とも 19 µm（male-CNS）
シナプス 3 個体で両方向 0
膜 6,333 voxel / 72%。結合している対照の 2.44 倍
系統 MB319B〈GAL4〉× SL86062〈LexA〉。U × D = 1 組

1. なぜこの組か — 鎖の最初の環が他より強い

新しい基準は、匂い → 上流 → 人工シナプス → 下流 → 記憶という鎖を要求する。 鎖の最初の環（匂いが上流を駆動するか）は、上流の入力のうち KC が占める割合で見られる。

上流 KC 入力 / 全入力 KC 率
MBON07 25,650 / 29,682 86%
MBON02 16,964 / 36,085 47%
MBON04 6,649 / 33,084 20%

MBON07 の発火は、ほぼそのまま「いま何の匂いがしているか」である。 しかも入力は α1(R) に 28,927 と、ほぼ 1 区画に集中している。 ノイズの少ない匂い信号を人工シナプスに乗せられる。

2. 回路としての意味 — 区画をまたぐフィードバックを作る

キノコ体の区画には、その区画の MBON が、その区画の DAN に返すループがある。

既存のループ シナプス 働き
MBON07(α1) → PAM11(α1) 75（male-CNS 74） 報酬性 LTM の固定化（Ichinose 2015）
MBON14(α3) → PPL106(α3) 47 α3 区画内のフィードバック
MBON07(α1) → PPL106(α3) 0 無い。これを作る

区画内のフィードバックは普通にあるのに、区画をまたぐものは無い。 作ろうとしているのは、α1 の読み出しが α3 の教師に口を出す経路である。

意味が通る。α1 は報酬性 LTM の区画、α3 は長期記憶そのものに関わる区画なので、 「報酬記憶の読み出しが、別の長期記憶系に書き込む」ことになる。

MBON07 が DAN を駆動できること自体は既に分かっている。 PAM11 に 75 シナプス作っている。 「この細胞は DAN とシナプスを作れないから 0 なのだ」という逃げ道は無い。

3. 符号は読めない。読めなくても実験は立つ

不確実性が 2 つ重なっている。正直に書く。

不確実性 1 — グルタミン酸の符号

PPL106 は既に 1,960 シナプス（11.6%）のグルタミン酸入力を受けているので受容体はある。 だが GluClα（抑制性）か Nmdar・KaiR1D（興奮性）かは分からない。

不確実性 2 — PPL1-α3 自体の価数が単純でない

報告 内容
Takemura 2017 PPL1-α3 単独の光活性化が、匂い提示なしで接近反応を生じる
Tsao 2018 PPL1-α3 の活性化が酵母探索を促進
Jacob 2021 PPL1-α3 の阻害が pre-exposure 由来の忌避を接近に反転させる

「PPL1 だから罰」ではない。 α3 は γ1pedc や α'2α2 とは違う。 長期記憶が残るかどうかのゲートに近い働きをしている可能性がある。

だから主張を「記憶ができる」に置く

人工シナプスが 匂い提示中の PPL106 予想される結果
興奮性 発火が増える 提示した匂いに 24 時間の記憶がつく
抑制性 発火が減る 同じく記憶がつく（符号は逆）

どちらでも「本来つかないはずの記憶がつく」。符号が変わるだけである。 PPL1-DAN は自発発火しているので（Huang 2018 が PPL105 で 6〜10 Hz を実測）、 発火が下がること自体が信号になる。

予測を「嫌悪記憶ができる」と書いてはいけない。 「提示した匂いへの選好が、対照の匂いに対して動く」と書く。 動く向きは結果である。

4. 構成 — 系統とコンストラクト

系統（この組の最大の長所）

役割 系統 発現系 標識する型
上流 MBON07 MB319B split-GAL4 MBON07 のみ
上流（代替） MB319C / MB323B split-GAL4 MBON07 のみ
下流 PPL106 SL86062 split-LexA PPL106 のみ
下流（代替） SL86050 split-LexA PPL106 のみ

U × D = 1 組。混同が原理的に存在しない。 本計画の候補でここまで清潔なのは この組と MBON31 → PAM11 だけ。GAL4 は 3 本、LexA は 2 本から選べる。

下流に SL86050 を選んでおくと、MBON02 → PPL106 と系統を共有できる （results/plan_three_pairs.md 6 節）。上流の GAL4 を差し替えるだけで 2 組目が走る。

コンストラクト

上流が GAL4 なので、オーガナイザーの向きは素直。

  • UAS-Kirre（上流 MBON07）
  • LexAop-Hbs（下流 PPL106）。Sns より Hbs を選ぶ — 全 22 クラスで最大 5% と背景がいちばん低い（receptor_check.md 2.5 節）
  • 読み出し用に LexAop-GCaMP（段階 B）
  • 存在証明用に UAS-CsChrimson（段階 B'）

内在の Sns/Hbs は周囲のニューロンに無いので、外来 Kirre が横取りされる心配は無い。 留保は「外来 Kirre の過剰発現が内在 sns/hbs を誘導しないか」だけなので、 過剰に強いドライバーは避ける。

5. 段階

段階 A — 解剖。シナプスができたか

光も匂いも使わない。syb-GRASP ＋ Brp で、PPL106 の SLP(R)・SIP(R) 側の後シナプス部位を数える。

群 上流 MB319B〈GAL4〉 下流 SL86062〈LexA〉 役割
①完全 Kirre Hbs ＋ GCaMP 本番
②変異 結合しない変異 Kirre Hbs ＋ GCaMP オーガナイザーの陰性対照
③下流のみ なし Hbs ＋ GCaMP 内在 Kirre の確認（陰性が予想）
④効果器のみ なし GCaMP だけ 背景

① > ② が出れば成立。 ③ は念のための確認で、関門ではない。

段階 B' — CsChrimson。先にやる存在証明

匂いの実験より先に、強制活性で記憶ができることを示す。

理由は単純で、匂いの実験が陰性だったとき、原因が区別できなくなるからである。

原因
シナプスができなかった／下流を駆動できなかった B' で分かる
シナプスはできたが匂いによる発火が弱かった B' が陽性なら、こちら

手順は、赤色光で MBON07 を活性化しながら匂い A を提示 → 24 時間後に A と B の選択。 retinal 給餌あり／なしの同腹で、遺伝子型を揃えた光対照が作れる。

段階 B — 生理。匂いで下流が動くか

下流に GCaMP。匂い A を提示して PPL106 の応答を見る。

群 予想
①完全 応答が変わる（増えるか減るかは 3 節のとおり未定）
②変異 変わらない
④効果器のみ 変わらない

ここが陽性なら、鎖の 匂い → 上流 → シナプス → 下流 まで繋がったことになる。 残るのは記憶だけ。

段階 C — 行動。匂いだけで記憶ができるか

これが本番。

訓練: 匂い A を一定時間嗅がせる。それだけ。 試験: 24 時間後に A と B の二択。

群 予想
①完全 A への選好が B に対して動く
②変異 動かない
④効果器のみ 動かない

6. 段階 C の設計で、いちばん気をつけること

人工シナプスは常にある。 つまり ハエが嗅いだすべての匂いが訓練になる。 これは普通の条件づけと根本的に違う点で、設計に跳ね返る。

問題 対処
飼育環境の匂いで既に記憶ができている 匂いの無い環境で飼育する。 餌の匂いも管理する
「訓練していない」対照が作れない 匂い A を嗅がせた群と、匂い B を嗅がせた群を比べる。どちらも訓練されているが、互いの対照になる
発生期から配線があると回路が作り変わる GAL80ts で成虫期に限定する

逆に、これは強い予測を生む。 特定の匂いの中で飼ったハエは、実験者が訓練しなくてもその匂いへの選好が変わっているはずである。 これが出れば、人工シナプスが日常的に働いている証拠になる。狙って測る価値がある。

必要な対照

対照 何を否定するか
②変異 Kirre オーガナイザー以外の要因
匂い A 群 対 匂い B 群 匂いそのものの性質
3 分後・30 分後の試験 短期記憶が動いていないこと（α3 は長期側）
GAL80ts で成虫期限定 発生期の配線変化
上流を MBON07 以外に替える MBON07 であることの必要性

7. 比較の相手 — MBON02 → PPL106

下流が同じ細胞（bodyId 331662710）で、LexA 系統も共有できる。 上流の性格が逆なので、並べると意味が出る。

MBON07 → PPL106 MBON02 → PPL106
上流の区画 α1（報酬性 LTM の読み出し） β2β'2a
KC 率 86% 47%
膜（同じ PPL106 に対して） 6,333 voxel / 72% 289 voxel / 18%
立ち位置 本命 同じ下流に別の匂い情報を入れたらどうなるか

膜で 22 倍の差があるので、MBON02 は成功率が低い。 だが系統の追加コストが上流 1 本だけなので、走らせる価値はある。

8. 否定されたときに何が言えるか

段階 陰性の意味 次の手
A: ① ≒ ② 接着が作れていない 接触 37 µm では足りない。MBON04 → PPL105（93 µm）へ
B': 強制活性でも記憶が出ない シナプスはできたが放出部位になっていない Dsyd-1 の補強。PPL106 の受容体を確認
B: 匂いで下流が動かない 匂いによる MBON07 の発火が弱い 上流を MBON01（KC 46%）に替える。または強い匂いで再試
C: 生理は動くが記憶が出ない PPL1-α3 の発火だけでは記憶が書けない これは陰性ではなく発見。 KC 活動との時間的一致が要ることの証拠になる
C: 短期記憶も動く α3 以外の経路が動いている ②との差分で切り分け

段階 C の最後の行が重要で、ここが陰性でも「DAN を駆動するだけでは記憶にならない」 という結論が残る。どちらに転んでも言えることがある設計になっている。

9. 先に確かめること（安い順）

確認 方法 黒だったら
1 MBON07 の匂い応答 GCaMP、MB319B。Ichinose 2015 の枠組みがそのまま使える 上流を替える
2 PPL106 のグルタミン酸受容体の符号 既に PPL106 を駆動しているグルタミン酸入力源の符号から推定するのが早い。scRNA-seq は脱落が多い 符号の予測を捨てる（3 節のとおり、捨てても実験は立つ）
3 SL86062 と SL86050 の発現範囲 既知 片方を使う
4 MB319B の発現強度 既知 MB319C / MB323B に替える

  • 区画・ROI: hemibrain:v1.2.1 の roiInfo。MBON07 入力 α1(R) 28,927 / 出力 SLP(R) 818、PPL106 出力 α3(R) 1,955。
  • 伝達物質: male-cns:v1.0 の consensusNt。
  • EM: results/em_gap/best_per_pair.csv。hemibrain v1.2 セグメンテーション、8 nm 等方。
  • 系統・0 判定・接触: results/shortlist_final.csv、 candidate_MBON07_PPL106.md。
  • MBON07 = MBON-α1、PPL106 = PPL1-α3、MBON14 = MBON-α3、MBON02 = MBON-β2β'2a。
