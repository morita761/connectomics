受容体と Kirre・Dsyd-1 をどう確認するか

2026-11-22。direction_MBON04_PPL105.md 6 節で 「先に片付けるべきこと」と書いた受容体チェックを実際にやった。

結論から言うと、問いと道具が逆だった。

問い 性質 解ける道具
下流に受容体があるか サブタイプ別の問い scRNA-seq では解けない。コネクトームで解ける
Kirre・Sns・Hbs・Dsyd-1 があるか クラス単位の問い scRNA-seq で解ける

そして受容体は 全候補すでに合格していた。

1. 受容体 — コネクトームが答えになっている

下流の細胞が「その伝達物質のシナプスをすでに何百本も受けている」なら、 受容体は必ずある。 新しく作る入力と同じ種類の入力を、その細胞はもう使っている。

male-cns:v1.0 で、各下流細胞の入力を上流の伝達物質別に数えた。

MBON04 → PPL105 グルタミン酸 GluClα / DmGluRA 1,770（10.2%） ◎

受容体はどの候補でも障害にならない。 scRNA-seq より確実でもある。受容体の転写産物は発現量が低くて dropout しやすく、 「検出されなかった」が「無い」を意味しない。 コネクトームの入力内訳は機能しているシナプスを数えているので、この弱点が無い。

ただし残る問い

コネクトームでは受容体の種類が分からない。符号と時間スケールが変わる。

伝達物質 速い（イオン型） 遅い（代謝型）
GABA Rdl（GABA-A、抑制） GABA-B-R1/R2/R3（抑制）
グルタミン酸 GluClα（抑制）／ Nmdar1・KaiR1D（興奮） DmGluRA（抑制）
ドーパミン — Dop1R1・Dop1R2（興奮寄り）／ Dop2R（抑制）

グルタミン酸は符号が決まらないのが問題。GluClα なら抑制、Nmdar なら興奮。 GABA は Rdl でも GABA-B でも抑制なので、MBON31 → PAM11 は符号が一つに決まる。 これが技術実証にこの組を推す理由のひとつ （techdemo_MBON31_PAM11.md 0 節）。

2. Kirre と Dsyd-1 — FlyBase で分かったこと

Kirre

FBgn0028369 / CG3653 / kin of irre。別名 duf, dumbfounded。 遺伝子グループは HBS-KIRRE 接着複合体と SNS-KIRRE 接着複合体。

証拠 中身
成虫頭部 質量分析でタンパク検出（Aradska 2015）
成虫視葉 レポーター P{GawB}kirre-rP298 がメデュラ M2–M4 層。蛹後期から成虫まで
成虫中枢脳 記載が無い
単一細胞 RNA-seq 三齢幼虫の飛翔筋前駆細胞だけ（Zappia 2020）。成虫脳ニューロンは無し
Fly Cell Atlas FlyBase の遺伝子ページには出てこない

→ FlyBase の curated な記載には無い。ただしこれは「無い」証拠にならなかった。 Fly Cell Atlas の実データでは 成虫ニューロンの 55% が kirre を出していた（2.5 節）。 文献に記載が無かっただけである。

Kirre の結合相手は Sns と Hbs。 近傍の細胞が Sns か Hbs を出していれば、 外来 Kirre が意図しない相手に貼り付く。これは driver_overlap_PPL105_MBON04.md で調べた 「ドライバーの標識範囲による混同」とは別種の交絡。2.5 節で実データを見た。

Dsyd-1

FBgn0039883 / CG1976 / Rho GTPase activating protein at 100F。 別名 Syd-1, DSyd-1, RhoGAP100F, synapse defective-1。

証拠 中身
成虫脳 in situ キノコ体に限局して発現。前シナプスマーカー brp と共局在（Owald 2010）
免疫染色 成虫キノコ体 calyx の Kenyon 細胞に、活性帯の点状シグナル（Christiansen 2011）
成虫頭部 ウエスタンで 195 kDa のタンパク
その他 胚 CNS、幼虫 NMJ、前蛹の足関節
単一細胞 RNA-seq 記載が無い

→ キノコ体系の細胞には native にある見込み。 Dsyd-1 は前シナプスの活性帯を組み立てる因子なので、 上流に「ある」方が都合が良い（無いと接着しても放出部位が熟さない）。 MBON31・PAM11・MBON04・PPL105 はいずれも MB 系なので有利。

ただし Owald 2010 / Christiansen 2011 の記載は Kenyon 細胞と calyx についてで、 MBON や DAN で確認されたわけではない。

2.5 Fly Cell Atlas の実データ — Kirre は「ある」、Sns・Hbs は「無い」

FlyBase が FlyCellAtlas を 22 の高次クラスに集計したファイルを配っている。

python fca_expression.py kirre sns hbs rst RhoGAP100F Rdl GluClalpha Dop1R1

較正が先

値は「その遺伝子を出している細胞の割合」。床と天井を押さえないと読めない。

較正用 ニューロン 本来の場所 読み
twi（中胚葉） 0% — 床は 0〜1%
Act88F（飛翔筋） 1% 筋 2% 同
Hml（血球） 1% 血球 60% 同
Mhc（筋） 16% 筋 89% 転写産物が多い遺伝子は 16% まで漏れる
Yp1（脂肪体・卵黄） 20% 生殖 81% 同。20% まで漏れる
repo（グリア） 1% グリア 14% 真の陽性でも 14% しか出ない。感度は低い
elav（汎ニューロン） 68% — 神経の上限の目安

→ 15〜20% 以下は「無い」。50% を超えれば「ある」。 repo が 14% しか出ないので、この集計は保守的で、見落とす方向に偏っている。

結果

遺伝子 ニューロン 介在 運動 感覚 グリア 筋 判定
kirre 55% 46% 56% 65% 35% 15% ある。神経に偏っている
sns 8% 13% 20% 3% 8% 2% 無い（最大は nephrocyte 71%）
hbs 3% 4% 5% 1% 4% 0% 無い（全 22 クラスで最大 5%）

RhoGAP100F (Dsyd-1) 56% 57% 79% 56% 28% 4% ある。神経特異的

kirre が本物である根拠: 非神経の組織では 4〜12% なのに、神経系で 46〜65%。 漏れこみ（Yp1 型）なら組織間で平坦になるが、神経に偏っている。 sns が nephrocyte で 71% と出るのも既知の生物学（Sns = nephrin、 nephrocyte は腎の足細胞に相当）と合う。データ自体は信用できる。

訂正

前節で「Kirre は中枢脳ではほぼ発現していない」と書いたのは誤り。 FlyBase の curated な記載が無かっただけで、 実データでは成虫ニューロンの過半が出している。

設計に与える影響 — 危険な側が逆だった

IRM 族は Kirre・Rst（片側）× Sns・Hbs（反対側） で噛み合う。成虫脳では:

  • Kirre の側は載っているが、相手の Sns・Hbs が無い。 内在の Kirre は相手がいなくて遊んでいる。接着系として休眠している。
  • つまり 外来 Kirre を載せる側は比較的安全。 内在の相手がいないので余計に貼らない。
  • 逆に Sns か Hbs を載せた細胞は、内在 Kirre を持つ周囲のニューロン（55%）に 掴まれる危険がある。 しかも Dsyd-1 が 56% のニューロンにあるので、 掴まれた接触が放出部位に熟す材料もそろっている。
  • この危険は向きに依らない。 どちらの向きでも Sns/Hbs を載せた側が弱点。

対策

  1. 直交化する（本筋）。 内在 Kirre に噛まない対を使う。 哺乳類のオルソログ（NEPH1–nephrin）に替えるか、結合面を変異させて 外来の対どうしだけが噛むようにする。 構築の設計段階の判断なので、ハエの作業に入る前に決める。
  2. 片側だけの対照を必ず置く（安くて決定的）。 下流に Sns/Hbs だけを発現させ、Kirre 側はどこにも入れない個体を作る。 内在 Kirre が効いているなら、この個体だけで余計な接触やシナプスが出る。 出なければ心配は要らない。実験セットに入れるべき。
  3. 転写産物とタンパクは別。 FlyBase の curated なタンパクのデータには 中枢脳ニューロンの Kirre が無い。細胞外ドメインが表面に出ていなければ関係ない。 抗体かタグ付きノックインで表面のタンパクを見てから 1 を判断する。
  4. Hbs は全 22 クラスで最大 5% で、成虫ではほぼ検出されない。 Sns（nephrocyte 71%）より背景が低いので Sns より Hbs を選ぶのは小さな改善になる。 ただし 2 の危険は内在 Kirre 側の話なので、これでは消えない。

まとめ

分子 望ましい状態 実際 判定
Kirre 両方の細胞に無い ニューロンの 55% にある × 想定と逆
Sns / Hbs 近傍の細胞に無い ほぼ無い（3〜8%） ◎ 想定どおり
Dsyd-1 上流にある ニューロンの 56% にある ◎ 想定どおり

3 つのうち 2 つは好都合で、1 つは逆。 結論は「Sns/Hbs 側を直交化するか、片側だけの対照で確かめる」。

自動化できる経路

  • FlyBase の precomputed ファイルを使う。 https://s3ftp.flybase.org/releases/current/precomputed_files/genes/ の FlyCellAtlas_slimmed_gene_expression_*.tsv.gz（914 KB）に、 全遺伝子 × 22 クラスの「平均発現量 : 発現細胞の割合」が入っている。 これを引くのが fca_expression.py。2.5 節の表はこれで出した。 より細かいクラスタ単位が要るときは同じ場所の scRNA-Seq_gene_expression_*.tsv.gz（515 MB）。
  • 注意: ftp.flybase.org と ftp.flybase.net は応答しない。 s3ftp.flybase.org を使う。
  • atlasapprox（api.atlasapprox.org）は d_melanogaster を持つが、 臓器が antenna・gut・leg などで brain / head が無い。使えない。
  • FlyBase の遺伝子ページ自体には値が出ず、 EMBL-EBI の Single Cell Expression Atlas と DRscDB にリンクするだけ。
  • サブタイプ単位（PPL105 と PPL106 を分ける）はどの経路でも無理。 そこは 1 節のコネクトームか 4 節の遺伝学で。

4. scRNA-seq で決まらないときの代替 — こちらが本線

受容体も Kirre も、最終的には in vivo のレポーターと機能で決める方が速い。

  1. T2A-GAL4 / MiMIC-GFP ノックイン系統 — Rdl・Dop1R1・GluClα には既存の系統がある。 ドライバーと掛けて共局在を見る。発現量ではなく「その細胞にあるか」が直接分かる。
  2. 抗体染色 — Brp（nc82）は必須。新生シナプスの活性帯を見る標準。
  3. RNAi ノックダウン + 行動 — 「受容体があるか」ではなく 「その受容体が効いているか」を直接問える。最終的な証明はこれ。
  4. そもそも生理の実験が答えになる — 上流 CsChrimson → 下流 GCaMP で応答が出れば、受容体は「ある」。

→ 受容体チェックは候補の順位づけに使うもので、プロジェクトを止める関門ではない。 direction_MBON04_PPL105.md 7 節の順番のうち 1（受容体）は 1 節で、Sns / Hbs は 2.5 節で済んだ。

残っているのは計算ではなく構築の判断 — 2.5 節の対策 1（直交化するか）と 対策 3（Kirre のタンパクが本当に神経の表面に出ているか）。
