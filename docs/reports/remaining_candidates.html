まだ詰めていない候補の一覧

2026-11-11。これまでに詳しく検討したのは 4 組 （MBON04 ↔ PPL105、MBON04 → FB4N、ExR2 → LAL098、AVLP478 → DNp06）。 残りを段階別に並べる。

0. 結論

ある。しかも遺伝学だけで見れば、残りの 2 組がこれまでのどれより良い。

組 なぜ注目か
A MBON07 → PPL106 両側が単一タイプ・特異性 2。U × D が 1 組だけ。変換も断片 LexA も要らない
B MBON31 → PAM11 同じく U × D が 1 組。膜の密着 7,375 voxel / 77% はプロジェクト全体で最高
C MBON30 → oviIN 産卵という数えられる読み出し。LexA は断片（VT026347）
D MBON21 → FB4X 膜の密着が対照の 10 倍。読み出しが弱い
E VES012 → DNb05 ほか 3 組 膜をまだ測っていない

A と B は「いま手に入る系統だけで、今日から交配を始められる」唯一の候補。 MBON04 ↔ PPL105 は SL86063 が 3 タイプを標識し、AVLP478 → DNp06 は split-LexA への変換が要る。A と B にはその手間が無い。

A. MBON07 → PPL106

  • MBON07 = MBON-α1（グルタミン酸）
  • PPL106 = PPL1-α3（ドーパミン）
  • 接触 37.1 µm、別個体 18.8 / 19.4 µm、3 個体・両方向すべて 0
  • 膜の密着 6,333 voxel / 72%

遺伝学が完璧

上流 MBON07 MB319B / MB319C / MB323B split-GAL4 MBON07 のみ 2
下流 PPL106 SL86062 / SL86050 split-LexA PPL106 のみ 2

U = {MBON07}、D = {PPL106}。U × D は 1 組だけで、それが目標そのもの。 混同の心配が原理的に存在しない。GAL4 は 3 本、LexA は 2 本から選べる。

PPL106 は MBON14 (85)、MBON11 (62)、MBON29 (40) など 13 タイプの MBON から入力を受ける。 MBON07 だけが 0。 しかも MBON07 自身は PAM11 に 75 シナプスを作っているので、 「MBON07 が DAN と結合できない」わけではない。

PPL106 の入力の内訳（male-CNS、計 16,913）: アセチルコリン 84.2% / グルタミン酸 11.6%（約 1,960 シナプス） / GABA 2.2% / ドーパミン 1.3%。 MBON07 はグルタミン酸作動性なので、受容体がある状態。

読み出し

  • MBON07: Ichinose T, et al. (2015) eLife 4:e10719 10.7554/eLife.10719 — MB323B で MBON-α1 を操作。試験時のみの阻害で条件付け接近が大きく損なわれる。 報酬性長期記憶の α1 ループの中核。 Tsao CH, et al. (2018) eLife 7:e35264 — MB310C で GABA-A 受容体をノックダウンし 酵母探索行動の減少。
  • PPL106: Jacob PF, et al. (2021) Curr Biol 10.1016/j.cub.2021.05.056 — PPL1-α3 の阻害は pre-exposure 由来の忌避を接近に反転させる。 Takemura SY, et al. (2017) eLife 6:e26975 — PPL1-α3 単独の光遺伝学的活性化が、 匂い提示なしで接近反応を生じる。

両側に 1 細胞型を狙った行動実験の前例がある。 これは MBON04 ↔ PPL105 と同じ水準。

弱点

接触が 37 µm と短く、別個体でも 19 µm（MBON04 ↔ PPL105 は 93 µm / 33〜38 µm）。 期待シナプス数も小さいので、「0 であること」の意外さは劣る。

B. MBON31 → PAM11

  • MBON31 = MBON-α'1a（GABA）
  • PAM11 = PAM-α1（ドーパミン）
  • 接触 25.2 µm、別個体 17.6 / 23.0 µm、3 個体・両方向すべて 0
  • 膜の密着 7,375 voxel / 77% — プロジェクト全体で最高

両側から見て欠落している。 MBON31 は 17 タイプの DAN に出力するのに PAM11 だけ 0、 PAM11 は 8 タイプの MBON から入力を受けるのに MBON31 だけ 0。 これは MBON04 ↔ PPL105 と同じ構図で、A（MBON07 → PPL106）より強い。

PAM11 の入力（male-CNS、計 15,751）: アセチルコリン 82.7% / グルタミン酸 6.9% / ドーパミン 4.6% / GABA 4.2%（約 660 シナプス）。 GABA 受容体はあるが薄い。

読み出し

  • PAM11: Ichinose T, et al. (2015) eLife 4:e10719 — MB299B で PAM-α1 を阻害。 条件づけ直後 1 時間の阻害で報酬性長期記憶が損なわれ、22 時間後では損なわれない。 Takemura SY, et al. (2017) eLife 6:e26975 — MB043C × CsChrimson で光駆動。 Yamagata N, et al. (2022) Front Behav Neurosci — MB299B で CCHa2-R をノックダウン。
  • MBON31 には行動実験の前例が無い（論文 15 本、該当 0 本）。 最も近いのは Felsenberg 2017 Nature で 3 回言及されるだけ。

読み出しは PAM11 側（報酬性長期記憶）に置くしかない。 ここが A に劣る点。

MBON07 → PAM11 が同じ動物の対照になる

PAM11 は MBON07 から 74 シナプスを受けている。α1 区画のループ（Ichinose 2015）で、 MBON31 → PAM11 を作るときの「変わってはいけない結合」として使える。

MBON31 → SMP503 が浮上した

膜の密着だけで見れば最良の部類（5,314 / 70%、対照の 9.3 倍）で、 接触も 152 µm と全候補で最長、別個体でも 25〜55 µm 再現する。 足りないのは SMP503 の素性（論文 1 本のみ）と LexA の当て （SS01239 と SS32246 が GMR13F04 を共有するが LexA 版が無い）。 SMP503 が何をする細胞かが分かれば、一気に上位に来る。

どう選ぶか

  • いますぐ始めたい → MBON07 → PPL106。系統が全部そろっていて、混同が 1 組。
  • 接触の確かさを優先 → MBON04 ↔ PPL105（93 µm / 33〜38 µm）。
  • 行動を直接読みたい → AVLP478 → DNp06（運動）か MBON30 → oviIN（産卵）。 どちらも LexA に手を入れる必要がある。
  • 膜の密着だけで選ぶ → MBON31 → PAM11（7,375 / 77%）。

A と B を同時に進めるのが効率的。 どちらもキノコ体の α1・α3 区画で、 報酬性長期記憶という同じ行動課題（Ichinose 2015 の枠組み）で読める。 上流・下流とも別の細胞なので交配は独立に組める。
