使う予定の系統は BDSC にあるか

2026-11-23。bdsc.indiana.edu の在庫検索で 1 本ずつ引いた。 対象は plan_three_pairs.md の 3 組と、 candidate_MBON04_FB4N.md・ techdemo_MBON31_PAM11.md で使う系統。

0. 結論

どの組も、いま決めている構成のままでは BDSC だけでは揃わない。 足りないのは必ず split-LexA の側である。

組 上流 下流 BDSC だけで揃うか
MBON07 → PPL106（本命） MB319B ✕ SL86050 ✕ 揃わない
MBON02 → PPL106 SS01337 ✕ SL86050 ✕ 揃わない
MBON04 → PPL105 SL86063 ✕ MB058B ◎ 68278 揃わない
MBON04 → FB4N SL86063 ✕ SS66004 ◎ 89507 揃わない
MBON31 → PAM11 SS52050 ◎ 89438 SL86059 ✕ 揃わない

split-LexA は BDSC に 1 本も無い。 検索語 split-LexA でも 0 件。 出典の Shuai 2024 本文に、どこから入手するかが書いてある。

Fly strains can be requested from Janelia or the Bloomington stock center. Split-LexA expression data and fly strains are also available upon request from Aso lab. — eLife 94168

→ split-LexA は Aso 研（Janelia）に直接依頼する。 これが最初にやることになる。

ただし朗報がある。 名前の不一致で見落としていた BDSC 在庫の代替系統が見つかった（4 節）。 本命の上流 MB319B は、BDSC にある MB310C で置き換えられる。

2. 規則性 — 出典で決まる

調べていて気づいたが、在庫の有無は系統の名前ではなく出典で決まる。

出典 BDSC 番号帯
Aso 2014（キノコ体 split-GAL4 コレクション） ある 682xx〜683xx
Meissner 2024（eLife 98405、中枢神経系コレクション） ある 882xx〜895xx
Shuai 2024/2025（eLife 94168、連合学習コレクション） 無い —
Wolff 2024（eLife 104764） 部分的 SS66004 はあり、SS95185 は無し

本計画がいちばん頼っているのが Shuai 2024 のコレクションで、そこが丸ごと BDSC に無い。 MBON・DAN を 1 細胞型で狙える系統が多いのはこのコレクションなので、仕方のない面はある。

3. split-LexA をどう手に入れるか

3 組すべてで split-LexA が要る。 どの組も「上流と下流に別の分子を入れる」ので、 GAL4 と LexA の両方が必要で、LexA 側はこのコレクションにしかない。

要る split-LexA どの組で 代替
SL86050（PPL106） MBON07 →・MBON02 → の両方 無い（5 節）
SL86063（MBON04+01+03） MBON04 → PPL105・MBON04 → FB4N 自作なら改善の余地あり（5 節）
SL86059（PAM11） MBON31 → PAM11 無い

Aso 研への依頼が最初の一歩になる。 同じ依頼で 3 本まとめて頼めるので、手間は 1 回分で済む。

4. 名前の不一致で見落としていた BDSC 在庫

data/driver_lines*.csv には、区画名で書かれた系統が 50 本ある （MBON-α1、PPL1-α'2α2 のように）。照合は hemibrain の型名（MBON07、PPL105）で 走っているので、この 50 本は一度も候補に出てこなかった。 candidate_MBON04_PPL105.md で MB058B が漏れていたのと同じ原因である。

しかもこの 50 本はすべて Aso 2014 のコレクション — つまり BDSC にある側である。 見えていなかったのが、よりによって注文できる系統だった。

拾い直すと、こうなる。

目標 見落としていた系統 標識 特異性 BDSC
MBON07 MB310C MBON-α1 のみ 2 ◎ 68313
MBON02 MB399B MBON-β2β'2a のみ 1 ◎ 68369
PPL105 MB058B PPL1-α'2α2 のみ 2 ◎ 68278（既出）
PAM11 MB043C PAM-α1 のみ 2 ◎ 68363
MBON31 MB050B MBON-α'1 ＋ MBON-α2sc 2 ◎ 68365
PPL106 MB060B α'2α2 ＋ α'3 ＋ α3 ＋ γ2α'1（4 型） 2 ◎ 68279

MB310C は本命の上流をそのまま置き換えられる。 MBON-α1 だけを標識する quality 1 の系統で、Tsao 2018 が MBON-α1 特異的として使った実績もある （results/candidate_MBON07_PPL106.md 6 節）。

MB399B も MBON02 の上流に使える（特異性 1 なので SS01337 と同格）。

PPL106 だけは代わりが無い。 MB060B は 4 型を標識し、 そのうち PPL1-γ2α'1 と PPL1-α'2α2 は MBON07 のすぐ近くを通っている （それぞれ 62 µm、255 µm — plan_three_pairs.md 8.5 節）。使えない。

MBON04 → PPL105 ／ MBON04 → FB4N

役割 第一希望 BDSC で代替
上流 MBON04〈LexA〉 SL86063（+MBON01,03） 無い。Aso 研に依頼

下流 FB4N〈GAL4〉 SS66004 ◎ 89507 —

下流は両方 BDSC にある。上流の split-LexA だけが足りない。

自作する手もある。 Shuai 2024 は 「split-GAL4 の DBD を LexA の DBD に置き換えれば split-LexA になる」と書いている。 MBON04 だけを標識する split-GAL4（SS67728 ◎ 88330 / SS67755 ◎ 88263）を変換すれば、 MBON01・MBON03 を含まない「きれいな MBON04 split-LexA」が作れる。 これは入手の回避策であると同時に、MBON04 → FB4N で見つかった 「MBON01 が FB4N と 4.3 µm 接している」問題をまるごと消す （candidate_MBON04_FB4N.md 4 節）。やる価値はある。

6. まとめ — 次にやること

  1. Aso 研（Janelia）に split-LexA を依頼する。 SL86050・SL86063・SL86059 の 3 本。 論文の記載どおり「upon request」なので、まとめて 1 通で足りる。
  2. 並行して BDSC に注文できるものを出す。 68313（MB310C、本命の上流）・68278（MB058B）・89507（SS66004）・89438（SS52050）。 68369（MB399B）と 88330/88263（SS67728/SS67755）も要るなら一緒に。
  3. MBON04 split-LexA の自作を検討する。 SS67728 から DBD を差し替える。 入手の保険であると同時に、混同がひとつ消える。
  4. ~~解析側を直す。~~ 2026-11-23 対応済み。 common/driver_names.py を足して、区画名と hemibrain 型名を突き合わせるようにした。 対応表は hemibrain の instance 名（MBON07(a1)_R のように両方を持っている）から 自動で作り、data/compartment_to_type.csv に置いてある。47 件。 区画名 40 種のうち 35 種に対応が付いた。 残り 5 種（PAM-γ4 など）は hemibrain 側が 1 区画を複数の型に分けていて 一対一に決まらないので、取り違えるより拾わないほうを選んだ。

あわせて、調べた BDSC の在庫番号を data/bdsc_stocks.csv に入れ、 同点なら在庫のあるほうを先に出すようにした。一覧の表示にも 〈BDSC 68313〉 が出る。

直した結果、推奨が変わった枠:

目標 直す前 直した後
MBON07〈GAL4〉 MB319B MB310C〈BDSC 68313〉
MBON02〈GAL4〉 SS01337 MB399B〈BDSC 68369〉
PPL105〈GAL4〉 MB059B MB058B〈BDSC 68278〉

4 枠すべてで、BDSC にある系統が先頭に来るようになった。 PPL106 と MBON04 の LexA 側は変わらない（代わりが無い）。
