候補の検討: ExR2 ↔ LAL098

2026-11-10。ヘミドライバーの照合で救えた 5 組のうち、別個体での接触が最も良かった組を詰めた。

  • ExR2 = PPM3-EB-DAN/ring（楕円体に投射するドーパミンニューロン、左右 2 個ずつ）
  • LAL098 = 側方付属葉のニューロン（GABA 作動性、左右 1 個ずつ）
  • 接触 hemibrain で 103 µm、別個体（male-CNS）で 47 / 77 µm — この調査全体で最高
  • シナプス 3 個体・両方向すべて 0

0. 結論を先に

第一候補には推さない。膜の密着が、結合している対照に明らかに届かない。

ただし向きは逆（LAL098 → ExR2）のほうが良いことが分かった。 この向きなら上流が接触領域で 76% 出力し、下流に受容体もある。 捨てるには惜しいので、条件付きの第 3 候補として残す。

3. 特異性の評価 — ここは弱い

「機械は揃っているのに、この相手だけ結合しない」と言えるかを調べた。言い切れない。

上流側: ExR2 は LAL のニューロンと結合できる

組 接触 シナプス 1 µm あたり
ExR2 → LAL184 948 µm 44 0.046
ExR2 → LAL202 399 µm 6 0.015
ExR2 → LAL085 1001 µm 3 0.003
ExR2 → LAL098 103 µm 0 0.000

ExR2 は LAL 全般に 152 シナプス / 41 タイプ（hemibrain）、288 シナプス / 58 タイプ（male-CNS）を出している。 「ExR2 が LAL の細胞と結合できない」わけではない。

ただし結合の密度そのものが低い（最大でも 0.046/µm）。 103 µm の接触に対して ExR2 自身の実績から期待されるのは 0.3〜4.7 シナプスであって、 解析の基準値 6.8 より小さい。0 であること自体が、それほど珍しくない。 MBON04 → PPL105（92.6 µm で比較相手は 0.18/µm）とは事情が違う。

下流側: LAL098 は ExR からほとんど入力を受けていない

組 hemibrain male-CNS
ExR8 → LAL098 3 0
ExR6 → LAL098 1 2
LAL098 → ExR6 5 17
ExR2 ↔ LAL098 0 / 0 0 / 0

「同じ場所の同じ種類の細胞は結合している」という対照が立たない。 LAL098 と ExR 群の結合は全体に 0〜17 シナプスしかない。 MBON04 ↔ PPL105 で PPL107 が 739/450 シナプスという強い対照になったのとは対照的。

LAL098 の入力の内訳（male-CNS、計 6,599）: アセチルコリン 62.3% / グルタミン酸 17.2% / GABA 15.7% / ドーパミン 1.5%。主な入力は LAL124 (775, グルタミン酸)、LAL081 (437)、LAL170 (366)。

5. 読み出し

  • ExR2 = PPM3-EB ドーパミンニューロン。覚醒・移動活性に関わる前例がある （PPM3 の刺激で移動活性が上がる、R2 リングニューロンの Dop1R1 がエタノール誘発性の 過活動に必要、など）。概日リズムのピークやエタノール曝露に伴う覚醒を促すとされる。 ただし ExR2 単独を狙った行動実験は見つからなかった。
  • LAL098 は文献が無い。 側方付属葉は中心複合体から胸部の運動中枢へ信号を中継する領域で、 操舵・移動に関わるとされるが、LAL098 個別の報告は無い。
  • 読み出しを置くなら ExR2 側の覚醒・移動活性（活動量、睡眠、旋回）になる。 LAL098 → ExR2 の向きで GABA 入力が 1 本増えると、ExR2 の活動が下がる方向に働くはず。

キノコ体の候補（MBON04 ↔ PPL105）と比べると、読み出しの設計は明らかに苦しい。

8. それでも残す理由と、次にやること

  1. LAL098 → ExR2 の向きは、上流の出力（76%）と下流の受容体（GABA 19.7%）がそろっている。 この 2 つは MBON04 ↔ PPL105 と同水準。
  2. 膜の密着は中間値で、却下した組（289 voxel / 18%）よりは明らかに良い。 測定点を増やせば評価が変わる可能性がある（今は 1 組あたり 2 点）。
  3. VT045661 の標識細胞を確定すれば、混同の判定ができる。

次の一手は、救えた残り 4 組（MBON30 → oviIN、MBON21 → FB4X、AVLP478 → DNp06、 DL4_adPN → LHPV6c1）を同じ EM の測定にかけること。 膜の密着で足切りすれば、接触の長さに惑わされずに順位がつく。 MBON30 → oviIN は接触 142 µm・別個体 36〜68 µm で、上流 MBON30 のドライバー SS76094 は特異性 2。
