キノコ体の細胞どうしで強制シナプス形成を行う案

2026-11-10 の吟味。結論は 成立する。全脳を探すより候補が多く、質も上回る。 19 組を 4 条件で判定して 4 組が残り、第一候補は MBON04 → PPL105。

※ 「キノコ体の細胞どうし」であって「キノコ体のローブの中で」ではない。 残った組の接触はすべて SIP・SMP・SLP で起きている（6 節・8 節）。

1. なぜキノコ体に限るのか

上流と下流に別々の人工分子を入れるには、独立した発現系が 2 つ要る（GAL4 と LexA）。 集めた 4,045 系統のうち LexA は 20 系統・12 型しかなく、その 12 型はすべてキノコ体の細胞だった。

MBON01 MBON03 MBON04 MBON07 MBON11 MBON12 PAM11 PPL101 PPL106 SLP400 SMP108 SMP348

全脳を探すと、見つかる組の大半は相手がキノコ体の外なので LexA が無く、実験にならない。 探索をキノコ体の中に閉じれば、上流も下流もこの 12 型から選べる。

補足（2026-11-10 追記）: この「20 系統・12 型」は「1 つの細胞型だけを狙える split-LexA」に 限った数である。範囲を広げると、キノコ体の外にも LexA は存在する （GMR-LexA 約 1,400 系統、VT-LexA、遺伝子ノックイン LexA、グリアの repo/alrm/wrapper-LexA など)。 ただしどれも 1 断片が数個〜数十の細胞型を標識するので、本実験の 「U × D のすべての組が 0」という条件を満たすかは系統ごとに画像で確認する必要がある。 また Shuai 2024 は split-GAL4 → split-LexA の変換を 34 系統で試して 22 系統成功しており、 このボトルネックは「作れば解ける」種類の制約である。 詳細は results/lexa_catalog.md と data/lexa_lines_nonmb.csv。 つまりキノコ体に限るのは「現存系統だけで考えたときの最短経路」であって、原理的な制約ではない。

2. 絞り込みの経過

キノコ体内部で接触 20 µm 以上・両方向ゼロ ……………… 392 組
  → 2 つの発現系がそろう ………………………………… 53 組
  → FlyWire でもゼロ ……………………………………… 43 組
  → 型単位で数え直してもゼロ …………………………… 37 組
  → male-CNS でもゼロ …………………………………… 22 組
  → ドライバーの混同が無害（下記）…………………… 19 組

型単位の数え直しは必須だった。キノコ体のデータは細胞を間引いて取得しているので、 間引いた細胞でゼロでも型全体ではゼロでない組が 6 つ混ざっていた （PAM07↔MBON01、MBON01↔PAM14、PAM11↔PAM05）。

ドライバーの混同の判定も必須だった。多くの系統は目的の細胞以外も標識する。 正しい基準はこうである:

上流のドライバーが標識する型の集合を U、下流のが標識する集合を D とすると、 U × D のすべての組み合わせが 0 でなければならない。

上流側の分子は U の全細胞に、下流側の分子は D の全細胞に乗るので、 U のどれかから D のどれかへ既存のシナプスがあれば基準値が 0 でなくなる。 逆に U どうし・D どうしの既存結合は読み出しに混ざらない（前側と後側の分子が揃わない）。

この基準で 22 組を調べると、使えないのは 3 組だけだった。

組 問題
MBON21 → MBON03 一緒に標識される MBON04 へ MBON21 が 383 シナプス
MBON04 → MBON15-like 一緒に標識される MBON03 から MBON15-like へ 182 シナプス
MBON03 → MBON21 一緒に標識される MBON01 から MBON21 へ 29 シナプス

一時期「1 型しか標識しない系統だけ」という厳しすぎる条件で 12 組に絞っていたが、 それだと SL86063（MBON01・03・04）を使う組がすべて落ちてしまう。 たとえば PPL105 → MBON04 は、U={PPL105} × D={MBON01, MBON03, MBON04} の 3 通りを調べて既存シナプスは合計 1 本（male-CNS の PPL105 → MBON03）で、実質無害である。

5. できないこと: KC → MBON

キノコ体で最も「記憶を書き込む」操作らしいのは KC（記憶を蓄える細胞）→ MBON を繋ぐことだが、 これは現状では無理。

KC のドライバーはクラス単位（αβ・α'β'・γ）でしか無く、EM の亜型を撃ち分けられない。 クラスごと標識すると、結合している兄弟亜型が混ざって基準値がゼロでなくなる。

組 本人 クラス全体
KCg-m → MBON33 467 γ 全体 1,482
KCa'b'-ap1 → MBON22 17 α'β' 全体 51
KCab-p → MBON13 0 αβ 全体も 0

唯一クラス全体でゼロなのは KCab-p → MBON13 だが、これは別個体での接触再現に失敗している。

6. 注意点

  1. DAN → MBON は解釈が弱い。 キノコ体でのドーパミンの正規の作用点は KC の前シナプス終末 （DopR / DAMB）であって、MBON への直接シナプスではない。直接の DAN→MBON シナプスは 存在するが機能的役割の確立度が低く、「PAM/PPL1 同時照射と等価」とは言いにくい。
  2. MBON31 → PAM11 は既に機能的に繋がっている可能性がある。 MBON-α'1 → PAM-α1 は 報酬の長期記憶のループとして報告がある（Ichinose 2015）。コネクトームで直接シナプスを 調べると α'1 の MBON はすべて PAM-α1 と 0〜2 で、報告されたループは間接的なものらしい。 データとしては矛盾しないが、既に機能的に結合している回路に線を足すことになるので、 表現型をこの操作に帰属させにくい。避けるのが無難。
  3. 残った 4 組はすべて SIP・SMP・SLP での接触で、キノコ体のローブの中ではない （8 節末尾）。MBON の軸索と DAN の樹状突起が出会うのはローブの外なので、 MBON → DAN の組は構造上そうなる。

7. 19 組を 4 つの条件で判定した結果

すべての組を同じ条件で測り直した（欠損なし）。条件は次の 4 つ。

  1. 膜の密着 — 最接近点でセグメンテーションを 8 nm 等方で切り出し、 A と B のボクセルが直接隣接する数と、間に何も無い表面点の割合（em_gap_check.py）
  2. 別個体での接触 — male-CNS の左右両半球での接触長
  3. 接触領域での活動 — その領域で上流が出力し、下流が入力を受けているか
  4. ドライバーの混同 — U × D のすべての組の既存シナプス数

この表から分かったこと

  • 膜の密着だけでは決まらない。 PPL101 → MBON01 は密着が 1 位（7,677 voxel / 81%） なのに、接触領域が ROI 一覧の外で上流の出力も下流の入力も 0。 神経束を並走しているだけの密着で、別個体でも再現しない。
  • 接触長だけでも決まらない。 PPL106 → PAM12 は接触 137 µm と最長で別個体でも 14〜25 µm 再現するが、その領域での上流の出力が 94 しかない。
  • 4 つの条件はどれも別の失敗モードを捕まえている。 15 組が落ちた理由は 「膜」2 組、「別個体」9 組、「上流の出力」4 組とばらけている。

第一候補は MBON04 → PPL105。 接触の長さ、別個体での再現（このプロジェクト全体で最高）、 上流の出力のどれでも最良か最良に近い。膜の密着も本物のシナプス部位を上回る。 MBON04 はグルタミン酸作動性（抑制性）、PPL105 はドーパミン作動性。 MBON → DAN のフィードバックは記憶の再評価・消去を駆動する回路として報告があり （Felsenberg 2018）、解釈の土台がある。

同じ 2 細胞の逆向き PPL105 → MBON04（全脳の探索でも ◎ だった組）も条件を満たすので、 向きを変えた対照実験を同じ細胞対で組めるのが強み。

詳細な検討は results/candidate_MBON04_PPL105.md（特異性・伝達物質・接触形状・ ドライバーの混同・EM・対照・読み出し）。EM と 3D のリンクは results/em_links_MBON04_PPL105.md。

ただしドライバーの質では MBON07 → PPL106 が勝つ（2026-11-10 追記）

組 上流の系統 下流の系統 U × D の組数
MBON04 → PPL105 SL86063（LexA、MBON01+03+04 を標識） SS48817（GAL4、FB2A+PPL105） 6 組（最大 3 シナプス・実質 0）
MBON07 → PPL106 MB319B（GAL4、MBON07 のみ・特異性 2） SL86062（LexA、PPL106 のみ・特異性 2） 1 組だけ

MBON07 → PPL106 は両方が単一タイプ・特異性 2 の系統で、混同の心配が原理的に無い。 接触の長さ（37 µm）と別個体での再現（19 µm）では MBON04 ↔ PPL105 に劣るが、 膜の密着は同等（6,333 / 72%）で、行動の読み出しも両細胞に前例がある （MBON07: Ichinose 2015、Tsao 2018 / PPL106: Takemura 2017、Jacob 2021）。 「きれいな遺伝学を優先するなら MBON07 → PPL106、接触の確かさを優先するなら MBON04 ↔ PPL105」 という整理になる。文献は results/refs_top_pairs.md。

接触の場所について

MBON04 ↔ PPL105 の接触は SIP（上前大脳）で 95〜97% であり、キノコ体のローブの中ではない。 MBON の軸索と DAN の樹状突起が出会うのはローブの外なので、MBON → DAN の組は構造上そうなる。 「キノコ体の細胞どうし」ではあるが「キノコ体の中で」ではない点に注意。 ローブの中で接触している組（MBON11 ↔ MBON33 の γ1、PPL103 → MBON07 の α1、 PPL106 → MBON17 の α'3）は、いずれも他の条件で落ちた。

9. 全脳の本命（MBON04 → FB4N）との比較

同じ MBON04 が上流になる 2 案を並べる。

下流 扇状体 4 層の接線ニューロン PPL1 クラスターの DAN
接触（hemibrain） 109 µm 93 µm
別個体での接触 10〜29 µm 33〜38 µm
膜の密着 2,080 voxel / 56% 6,140 voxel / 70%
接触領域 SMP、上流出力 308 / 下流入力 1,968 SIP、上流出力 538 / 下流入力 1,380
ドライバーの混同 U×D すべて 0 既存 3 シナプス
伝達物質 Glu → Glu（FB4N は Glu 入力を 24% 受ける） Glu → DA
行動の読み出し FB4N は文献に無い。PFL3 まで 2 シナプス 嗅覚条件づけの PI がそのまま使える
解釈の土台 MBON → 扇状体（ナビゲーション） MBON → DAN（記憶の再評価・消去）

データの質ではキノコ体案（MBON04 → PPL105）が上回る。 別個体での接触再現が 3 倍以上、 膜の密着が 3 倍、接触領域での上流の出力も多い。 行動の読み出しが確立している点でも有利。

全脳案の利点は、下流が扇状体という別系統の回路なので「キノコ体の中の話」に閉じないこと。 両方を進めるなら、上流が同じ MBON04 なので 同じ LexA 系統（SL86063）を共有できる。
