ヘミドライバー断片の LexA 版を使って、落ちた組を救う

2026-11-10。再現は python hemidriver_lexa.py。一覧は results/hemidriver_lexa.csv。

0. 結論

9 組中 5 組が救える。

系統まるごとの GMR-LexA では 1 組も救えなかったが（results/gmr_lexa_report.md）、 split-GAL4 を構成する 2 つの断片のうち片方に LexA 版があるかを見ると話が変わる。

結果
調べた split-GAL4 69 系統（LexA が無くて落ちた 32 組のドライバー）
ヘミドライバーが分かったもの 60 系統
片方の断片に LexA 版があるもの 7 系統
それで救える組 6 組（うち接触が再現し上流も出力している上位の組が 5 組）

1. 考え方

split-GAL4 は 2 つのエンハンサー断片の積でできている。

SS49882 = VT045661-GAL4.DBD  ∩  VT039475-p65.AD
          ↑ この断片に LexA 版（Ecol\lexA[VT045661]）がある

積の片側だけを使うと、標識する細胞は増える（特異性は落ちる）。 しかし「LexA が無いので発現系が 2 つにならない」という壁は、それで外れる。 元の split-GAL4 がその細胞を標識している以上、片側の断片も必ずその細胞を含む。

最後の 1 組（LAL098 → DNb01）は別個体での接触が 2〜4 µm しかないので落ちたまま。

【追記】ExR2 ↔ LAL098 は EM で落ちた。 膜の密着が、同じ ExR2 が 44 シナプスを作っている LAL184 との対照の 1/6〜1/10 しかない（直接隣接 1,348〜3,692 対 8,153、最接近の隙間 45 nm 対 0 nm）。 接触の長さが再現しても、膜が接しているとは限らないという例。 詳細と、向きを逆（LAL098 → ExR2）にしたほうが良い理由は results/candidate_ExR2_LAL098.md。 残り 4 組も同じ EM の測定にかけてから順位をつけるべき。

3. 混同（U × D）は、分かる範囲ではすべて 0

断片だけを使うと標識する細胞の集合 U（または D）が広がるので、 U × D のすべての組が 0 という条件を取り直す必要がある。 いま中身が分かっている分について neuPrint で数え直した。

MBON30 ↔ oviIN 0 / 0 0 / 0 目標
ExR2 ↔ LAL098 0 / 0 0 / 0 目標

分かっている混同はすべて 0。ただし下の限界を読むこと。

4. 限界 — ここから先は画像を見ないと決まらない

断片が標識する細胞の全体（U または D の中身）は、まだ分かっていない。

  • VFB に細胞型の注釈があるのは GMR11C07 だけ（PAM10）。 VT045661・VT033006・VT026347・VT019018 には注釈が無い。
  • したがって上の「混同 0」は、分かっている相手に限った話である。 断片が他に何十という細胞型を標識していれば、その中に既存結合があるかもしれない。

確かめるには FlyLight の発現画像を見て、標識細胞を数え上げるしかない。

NeuronBridge なら hemibrain の骨格から光学画像を逆引きできるので、 「この断片の発現に、どのコネクトームの細胞が含まれるか」を半自動で出せる。 VFB にはコネクトームのニューロンと系統の発現パターンを結ぶ has_similar_morphology_to_part_of という関係があり（NBLAST の結果）、 実際に DNb05 と SS01051 の発現パターンが結ばれている。これを使えば U の推定を自動化できる。

5. 実務上の注意

  1. 断片の LexA 版は活性が違うことがある。Pfeiffer 2010 は 「LexA は GAL4 より転写活性化因子として弱い」と報告している。 表記も lexA::GAD / lexA::p65 / lexA::VP16 と混在しており、強さが異なる。 今回見つかった 5 つは Ecol\lexA[VT045661]、Ecol\lexA[p65.VT033006]、 Ecol\lexA[GAD.VT026347]、Ecol\lexA[GAD.VT019018]、Ecol\lexA[GMR11C07] の形。
  2. 在庫の確認が必要。FlyBase に allele として登録があっても、 配布系統があるとは限らない。BDSC / VDRC に照会すること。
  3. split-LexA への変換と比べる。断片 1 つの LexA は特異性が落ちるので、 Shuai 2024 の方法で split-GAL4 をそのまま split-LexA に変換するほうが 特異性は保てる（成功率 22/34）。断片の LexA は「今すぐ試せる」利点がある。

6. 使ったデータ

  • ヘミドライバーの構成: VirtualFlyBrain neo4j MATCH (n:Individual:Split)-[:INSTANCEOF]->(c) — split-GAL4 の試料が属する 「P{A-GAL4.DBD} ∩ P{B-p65.AD} expression pattern」クラスから断片名を取る。
  • LexA 版がある断片: VirtualFlyBrain solr の Ecol\lexA[...] allele 名 190 件 （GMRxxxxx / VTxxxxxx、GAD. p65. DBD. などの接頭辞を吸収）。
  • 候補ペア: results/shortlist_final.csv
  • 混同の数え直し: neuPrint hemibrain:v1.2.1 / male-cns:v1.0
