上位候補ペアの細胞について、行動実験を行っている論文

2026-11-10 作成。lit_search.py で Europe PMC を検索し、 オープンアクセス論文は本文全体、それ以外は要旨を対象に 「細胞名・系統名」「操作（光遺伝学・活動阻害など）」「行動（学習・選好など）」の 3 つがそろう文を探した結果。生データは results/literature/<タイプ>.csv、 根拠の文は results/literature/summary.md。

python lit_search.py PPL105 PPL106 MBON07 PAM11 MBON33 MBON04 MBON11 MBON31 FB4N --max-papers 200

注意: 語の一致で拾っているので、最終的な判断は論文本体で確認すること。

読み出しの観点では MBON04 ↔ PPL105 が最も恵まれている。 両方の細胞に行動実験の前例があり、同じ論文（Tsao 2018、Aso 2016）が両方を扱っている。

MBON31 → PAM11 は上流側（MBON31）に行動実験の前例が無い。 15 本のうち 行動の根拠がある論文は 0 本で、最も関連するのは Felsenberg 2017 Nature で 3 回言及されるだけ。 下流の PAM11 には Ichinose 2015 eLife という決定的な論文があるので、 読み出しは PAM11 側（報酬性長期記憶）に置くしかない。

FB4N（全脳本命の下流）は 3 本しかなく、すべて形態の記載。 行動の前例が無い点は変わらない。

MBON31 = MBON-α'1a — 行動実験の前例が無い

15 本中、行動の根拠がある論文は 0 本。最も近いのは:

  • Felsenberg J, Barnstedt O, Cognigni P, Lin S, Waddell S (2017) Re-evaluation of learned information in Drosophila. Nature 544:240–244. 10.1038/nature21716 — 言及 3 回。 記憶の再評価（extinction）の回路。MBON → DAN のフィードバックを扱う論文群の中核。
  • Rubin GM, Aso Y (2024) New genetic tools for mushroom body output neurons in Drosophila. eLife 10.7554/eLife.90523 — MBON の新しい系統（MBON31 の系統 SS52050 / SS80896 の出所）。形態と系統の記載。

この組を進めるなら、読み出しは PAM11 側（報酬性長期記憶）に置く。 MBON31 → PAM11 の新生シナプスが PAM-α1 の活動を変えれば、 Ichinose 2015 の長期記憶課題で差が出ると予想できる。

6. 再現方法

python lit_search.py PPL105 PPL106 MBON07 PAM11 MBON33 MBON04 MBON11 MBON31 FB4N --max-papers 200

細胞型と論文上の名前・系統名の対応は lit_search.py の TARGETS にある。 新しい細胞を追加するときは、neuPrint の instance 名 （例 PPL105(a'2a2) → PPL1-α'2α2）と data/driver_lines.csv の Descriptive Cell Type 列から別名を作る。取得した本文は data/literature_cache/ に残る。
