「匂いだけで、本来できない記憶を作る」で 3 組を選び直す

2026-11-23。新しい基準での再評価。 再現は python -c での neuPrint 問い合わせ（9 節）と results/em_gap/best_per_pair.csv。

これまでの基準は 膜が接しているかを軸にしていた。 今回の基準は違う。上流が自然な刺激（匂い）に応答し、その活動が人工シナプスを通って 下流のドーパミンニューロンを駆動し、本来その刺激だけでは作られない連合記憶ができる。

この基準を入れると、上流が匂いでどれだけ駆動されるかという、これまで測っていなかった量が効いてくる。 測った。結論が変わった。

0. 結論

組 匂い駆動（KC 入力率） 膜の接触（EM） 判定
MBON07 → PPL106 86% 6,333 voxel / 72% ◎ 両方を満たす唯一の組。第一候補
MBON02 → PPL106 47% 289 voxel / 18% △ 膜が足りない。同じ下流で 22 倍の差
MBON04 → PPL105 20% 6,140 voxel / 70% △ 匂いで駆動されない。新基準では落ちる

3 組を並行して準備する、という判断自体は妥当。 ただし 3 組は対等ではない。 MBON07 → PPL106 が本命で、残り 2 つは性格の違う保険である。 しかも 2 つの弱点は別方向なので、保険としては噛み合っている。

  • MBON02 → PPL106 は 下流が本命と同じ。LexA 系統を共有でき、上流だけ差し替えれば走る。 弱点は膜。
  • MBON04 → PPL105 は 膜がいちばん確か。弱点は匂い駆動。 CsChrimson 側に寄せるならこちらが残る。

1. 新しい基準が実際に要求していること

鎖はこうなる。

匂い A → KC → 上流 MBON が発火 → 【人工シナプス】→ 下流 DAN が発火
       → ドーパミン放出が KC-MBON シナプスに当たる → 匂い A の記憶ができる

電気ショックも砂糖も使わない。 匂いを嗅がせるだけで記憶ができれば、 「人工シナプスが教師信号を作った」ことの証明になる。これは強い主張である。

鎖の各環が別々の条件を要求する。

環 要求 これまで測っていたか
匂い → 上流 上流が KC から直接入力を受けている 測っていなかった
上流 → 下流 膜が接していて、オーガナイザーが働く 測っていた（EM）
上流 → 下流 伝達の符号が、下流を駆動する向き 未確定（5 節）
下流 → 記憶 その DAN の区画に記憶ができると分かっている 文献で確認済み
記憶 → 行動 T-maze で読める 確立

最初の環が新しい。測った。

2. 上流は匂いでどれだけ駆動されるか — KC 入力率

キノコ体のニューロン（KC）が匂いを表現しているので、 ある MBON が匂いにどれだけ素直に応答するかは、その MBON の入力のうち KC が占める割合で近似できる。 hemibrain:v1.2.1 の全入力シナプスを数えた。

上流の候補 区画 KC 入力 全入力 KC 率 読み方
MBON07 α1 25,650 29,682 86% ほぼ純粋な匂い読み出し
MBON02 β2β'2a 16,964 36,085 47% 半分
MBON01 γ5β'2a 26,871 58,842 46% 半分
MBON30 — 8,415 18,417 46% 半分
MBON21 γ4γ5 8,290 21,398 39% 半分以下
MBON31 α'1a 4,767 13,443 35% 半分以下
MBON04 β'2mp_bilateral 6,649 33,084 20% 匂い以外の入力が 8 割
MBON33 γ2γ3 1,482 9,103 16% 匂い読み出しではない

MBON07 は桁が違う。 入力の 86% が KC なので、この細胞の発火はほぼそのまま 「いま何の匂いがしているか」である。人工シナプスに乗せる信号として、これ以上きれいなものはない。

MBON04 は 20%。 これまで本命だったが、この基準では下から 2 番目になる。 入力の 8 割が KC 以外（他の MBON、修飾系、中心複合体系）なので、 匂いを嗅がせても MBON04 が確実に発火するとは言えない。 匂い提示で記憶を作る設計には向かない。

注意: KC 率は上限の指標である。KC 率が高ければ匂いに応答する可能性が高い、 という向きには使えるが、実際の応答強度・選択性はカルシウムイメージングで測るしかない。 ただし MBON-α1 の匂い応答は既に報告がある（Ichinose 2015 ほか）ので、 MBON07 については測定済みと言ってよい。

3. 膜が接しているか — MBON02 の弱点

EM（hemibrain v1.2 セグメンテーション、8 nm 等方、320×320×160 voxel 切り出し）。

MBON07 → PPL106 と MBON02 → PPL106 は下流が同じ細胞（bodyId 331662710）なので、 対照を挟まずに直接比べられる。これは比より強い比較である。

組 下流 bodyId 接触 voxel 間に何も無い面の割合 最小隙間
MBON07 → PPL106 331662710 6,333 72% 45 nm
MBON02 → PPL106 331662710（同じ細胞） 289 18% 64 nm
MBON04 → PPL105 5813019513 6,140 70% 45 nm

同じ 1 個の PPL106 に対して、MBON07 は MBON02 の 22 倍の面積で接している。 「間に何も無い面」の割合も 72% 対 18% で、MBON02 は接触点の 8 割でグリアか別の突起が割り込んでいる。

骨格レベルの接触長（MBON02 → PPL106 は 25 µm、MBON07 → PPL106 は 37 µm）では 1.5 倍の差にしか見えないが、膜で見ると 22 倍になる。 results/plan_mushroom_body.md が MBON02 → PPL106 を「✕ 膜」としていたのはこの数字による。

人工接着分子は膜どうしを架橋するものなので、ここは効く。 MBON02 を落とす理由にはならないが（接触はゼロではない）、 同じ労力をかけて成功率が低いことは認識しておくべきである。

6 条件すべてを満たすのは MBON07 → PPL106 だけ。

5. 符号の問題 — 3 組とも Glu → DA である

male-cns:v1.0 の consensusNt で確認した。

型 伝達物質
MBON07 / MBON02 / MBON04 すべてグルタミン酸
PPL105 / PPL106 すべてドーパミン

つまり 3 組とも「グルタミン酸 → ドーパミンニューロン」で、同じ符号の問題を抱えている。 ハエのグルタミン酸は受容体で符号が反転する。

  • GluClα（塩素チャネル）→ 抑制性
  • Nmdar・KaiR1D（陽イオン）→ 興奮性

下流に受容体があること自体は確定している（PPL106 は既に 1,970 シナプス（11.5%）の グルタミン酸入力を受けている — results/receptor_check.md）。 どちらの受容体かが分からない。

それでも実験は死なない

どちらに転んでも「本来できない記憶」はできる。符号が変わるだけである。

人工シナプスが 匂い提示中の PPL106 できる記憶 根拠
興奮性だったら 発火が増える 嫌悪記憶（PPL1 本来の向き） 素直
抑制性だったら 発火が減る 報酬記憶（罰の消失として読まれる） PPL1 は自発発火している

後者は憶測ではない。Huang 2018 は PPL105 の自発発火を実測して 6〜10 Hzとしている （results/refs_top_pairs.md）。PPL1-DAN は静かな細胞ではなく、 常に発火していて、それが下がること自体が信号になる。 罰の消失が報酬として働く回路は既に報告がある（McCurdy 2021 ほか）。

だから予測は「嫌悪記憶ができる」ではなく「匂い A への選好が、どちらかに動く」とすべきである。 対照（オーガナイザー無し・時間的に対応しない匂い提示）との差分で判定する。 向きが読めないことは、この実験の弱点ではない。向きが読めることを前提にした主張をしなければよい。

これは results/techdemo_MBON31_PAM11.md 0 節で MBON31 → PAM11 を推した理由の裏返しでもある。 あちらは GABA なので Rdl も GABA-B も抑制性で、符号が一意に決まる。 新基準では MBON31 の KC 率が 35% と低いので上流としては落ちるが、 「符号が読める」点では今も唯一の組である。

6. 3 組を並行して準備するときに、実際に要るもの

系統

組 上流 下流 共有できるか
MBON07 → PPL106 MB319B〈GAL4〉[特異性2] SL86050〈LexA〉[特異性2] —
MBON02 → PPL106 SS01337〈GAL4〉[特異性1] SL86050〈LexA〉[特異性2] 下流が本命と同じ
MBON04 → PPL105 SL86063〈LexA〉(+MBON01,03)[特異性2] MB058B〈GAL4〉[特異性0] 共有なし

MBON07 と MBON02 は下流の LexA 系統 SL86050 を完全に共有できる。 上流の GAL4 を差し替えるだけなので、2 組目の追加コストは系統 1 本である。 しかも下流が同一細胞なので、2 組の比較がそのまま「上流を変えると何が変わるか」の実験になる。

ここが落とし穴 — 3 組目だけオーガナイザーの向きが逆になる

オーガナイザーの極性は固定で、上流に Kirre、下流に Sns/Hbs（results/receptor_check.md）。

組 上流の発現系 必要なコンストラクト
MBON07 → PPL106 GAL4 UAS-Kirre ＋ LexAop-Sns/Hbs
MBON02 → PPL106 GAL4 UAS-Kirre ＋ LexAop-Sns/Hbs（上と同じ）
MBON04 → PPL105 LexA LexAop-Kirre ＋ UAS-Sns/Hbs（逆向き。別に作る）

前 2 組は UAS/LexAop のコンストラクトを完全に共有できる。3 組目だけ両方を作り直す必要がある。 3 組を並行させるときの実コストは「3 倍」ではなく、「2 組分 ＋ コンストラクト一式の作り直し」である。

この点だけで、3 組目を MBON04 → PPL105 にするか、別の GAL4-上流の組にするかを 考え直す価値がある。（results/shortlist_final.csv には上流 GAL4 の組が他にもある）

7. CsChrimson は「予備プラン」ではなく、陰性結果を読むための対照

匂いだけの実験が失敗したとき、原因は 2 つある。

  1. 人工シナプスができなかった／下流を駆動できなかった
  2. シナプスはできたが、匂いによる上流の発火が弱すぎた

匂いの実験だけでは、この 2 つを区別できない。 だから CsChrimson が要る。

実験 何を示すか 位置づけ
CsChrimson で上流を強制活性 → 記憶ができるか 人工シナプスが教師信号を作れること 先にやる。存在証明
匂いだけ → 記憶ができるか 自然な感覚入力でも足りること 本番。新規性はここ

順序は CsChrimson が先。 これが陰性なら匂いの実験をする意味が無いし、 陽性なら匂いの実験が陰性でも「シナプスはできたが匂いの駆動が弱い」と言い切れる。 予備プランに降ろすのではなく、本番の前段に置くのが正しい。

なお CsChrimson は餌の retinal が無いと働かないので、 同腹の retinal 給餌あり／なしで遺伝子型を揃えた光対照が作れる （results/techdemo_MBON31_PAM11.md 2.3 節と同じ手）。

8. 勧める順序

  1. MBON07 → PPL106 を本命として立てる。 6 条件すべてを満たす唯一の組。 MB319B〈GAL4〉＋ SL86050〈LexA〉。
  2. MBON02 → PPL106 を同時に走らせる。 下流の LexA が同じなので追加コストが小さく、 同一細胞に対する上流の比較になる。膜が弱いことは承知のうえで。
  3. 3 組目は保留して考え直す。 MBON04 → PPL105 は膜は確かだが 匂い駆動が 20% で新基準に合わず、コンストラクトも作り直しになる。 CsChrimson 主体の技術実証を残すなら、符号が一意に決まる MBON31 → PAM11（results/techdemo_MBON31_PAM11.md）のほうが筋が通る。

先に確かめるべきこと（安い順）

確認 方法 これが黒なら
1 MBON07 の匂い応答 GCaMP、MB319B 上流を MBON01（KC 46%）に替える
2 PPL106 のグルタミン酸受容体が GluClα か Nmdar か scRNA-seq は脱落が多い。PPL106 を既に駆動しているグルタミン酸入力源の符号から推定するほうが早い 符号の予測を捨て、両方向の行動変化を見る設計にする
3 SL86050 が PPL106 以外に何を標識するか 既知[特異性2] 混同の評価
4 MBON02 → PPL106 の EM を別個体で male-cns 289 voxel が個体差なら復活、再現なら落とす
